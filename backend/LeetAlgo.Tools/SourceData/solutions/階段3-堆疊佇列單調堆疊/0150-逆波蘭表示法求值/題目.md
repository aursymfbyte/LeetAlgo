# 150. 逆波蘭表示法求值

- 難度：中等
- 連結：https://leetcode.com/problems/evaluate-reverse-polish-notation/

## 題目

給你一個字串陣列 `tokens`，它是一個用「逆波蘭表示法」（後綴表示法，運算子寫在兩個運算元的後面）寫成的算式。請算出這個算式的值，並以整數回傳。

說明：

- 運算子只有 `'+'`、`'-'`、`'*'`、`'/'` 四種。
- 每個運算元可能是一個整數，也可能是另一段算式算出來的結果。
- 兩個整數相除時，結果一律往 0 的方向截斷（例如 `-7 / 2` 得到 `-3`）。
- 不會出現除以 0 的情況。
- 輸入保證是合法的逆波蘭表示法算式。
- 最終答案和所有中間結果都能用 32 位元整數表示。

## 範例

**範例 1：**

```text
輸入：tokens = ["2","1","+","3","*"]
輸出：9
解釋：先算 2 + 1 = 3，再算 3 * 3 = 9，也就是 ((2 + 1) * 3)。
```

**範例 2：**

```text
輸入：tokens = ["4","13","5","/","+"]
輸出：6
解釋：先算 13 / 5 = 2（截斷小數），再算 4 + 2 = 6，也就是 (4 + (13 / 5))。
```

**範例 3：**

```text
輸入：tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
輸出：22
解釋：對應的一般算式是 ((10 * (6 / ((9 + 3) * -11))) + 17) + 5。
9 + 3 = 12，12 * -11 = -132，6 / -132 往 0 截斷得 0，
10 * 0 = 0，0 + 17 = 17，17 + 5 = 22。
```

## 提示

- `1 <= tokens.length <= 10^4`
- `tokens[i]` 不是運算子 `"+"`、`"-"`、`"*"`、`"/"`，就是範圍在 `[-200, 200]` 內的整數
