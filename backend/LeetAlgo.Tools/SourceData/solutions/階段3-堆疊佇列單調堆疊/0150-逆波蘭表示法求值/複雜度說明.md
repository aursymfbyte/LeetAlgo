### 時間 O(n)

n 為 `tokens` 的長度，即數字與運算子的總數。

- 程式由左至右處理每個 token 一次，共 n 次。
- 每個 token 的工作量固定：
  - 數字：轉為整數後放入堆疊。
  - 運算子：從堆疊頂端取出兩個數，執行一次加減乘除，再將結果放回。
- 堆疊只在頂端放入與取出，每次皆為 O(1)，因此每個 token 為 O(1)，總計 **O(n)**。

### 空間 O(n)

- 額外記憶體為堆疊 `stack`。
- 最壞情況為前段連續出現大量數字、後段才出現運算子，例如 `1 2 3 4 + + +`，此時數字全部先存入堆疊，約 n / 2 個。
- n / 2 省略固定倍數後仍與 n 成正比，為 **O(n)**。
