設計題計算 `next` 單次呼叫的成本。n 為 `next` 的呼叫次數，即目前已輸入的價格天數。

### next：均攤 O(1)

- 每次呼叫 `next`，需將堆疊頂端所有「價格 <= 當天」的紀錄彈出，再將當天放入。
- 單次呼叫可能連續彈出多筆。例如價格連續下跌多天後出現一個最高價，該次需將先前的紀錄全部彈出，最壞為 O(n)。
- 每一天的價格只會放入堆疊一次、最多彈出一次，彈出後不會再放回。因此 n 次呼叫合計放入 n 次、彈出最多 n 次，總計最多約 2n 步。
- 2n 步平均分攤到 n 次呼叫，每次約 2 步。偶爾有一次成本較高、平均每次仍為固定時間的情形，稱為**均攤 O(1)**。

直覺寫法：每次從當天往前逐日計數，最壞每次 O(n)，n 次呼叫為 O(n²)。

### 空間 O(n)

- `prices` 與 `spans` 兩個堆疊高度相同。最壞情況為價格持續下跌，每一天都不會被彈出，各存 n 筆，合計 2n，省略固定倍數為 **O(n)**。
- C 版依題目的呼叫次數上限（10⁴）預先配置陣列，最多存放此數量，同樣計為 O(n)。
