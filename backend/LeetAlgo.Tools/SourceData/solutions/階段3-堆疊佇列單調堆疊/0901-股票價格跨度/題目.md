# 901. 股票價格跨度

- 難度：中等
- 連結：https://leetcode.com/problems/online-stock-span/

## 題目

請設計一個類別，每天收到一支股票的當日價格，並回傳這一天的「價格跨度」。

某一天的價格跨度定義為：從這一天開始往前數（包含這一天），連續有幾天的價格都小於或等於這一天的價格，取最多的天數。

舉例：

- 如果前四天的價格是 `[7,2,1,2]`，今天價格是 `2`，那麼從今天往前的 2、1、2、2 這四天都 `<= 2`，再往前的 7 就超過了，所以今天的跨度是 `4`。
- 如果前四天的價格是 `[7,34,1,2]`，今天價格是 `8`，那麼今天、2、1 這三天都 `<= 8`，再往前的 34 超過了，所以跨度是 `3`。

要實作 `StockSpanner` 類別：

- `StockSpanner()`：建立物件。
- `int next(int price)`：傳入今天的價格 `price`，回傳今天的價格跨度。

## 範例

**範例 1：**

```text
輸入：
["StockSpanner", "next", "next", "next", "next", "next", "next", "next"]
[[], [100], [80], [60], [70], [60], [75], [85]]
輸出：
[null, 1, 1, 1, 2, 1, 4, 6]
解釋：
next(100)：前面沒有資料，只有今天，回傳 1。
next(80)：前一天 100 比 80 高，回傳 1。
next(60)：前一天 80 比 60 高，回傳 1。
next(70)：今天和前一天的 60 都 <= 70，再往前的 80 太高，回傳 2。
next(60)：前一天 70 比 60 高，回傳 1。
next(75)：今天、60、70、60 這四天都 <= 75，再往前的 80 太高，回傳 4。
next(85)：今天、75、60、70、60、80 這六天都 <= 85，再往前的 100 太高，回傳 6。
```

## 提示

- `1 <= price <= 10^5`
- `next` 最多呼叫 `10^4` 次
