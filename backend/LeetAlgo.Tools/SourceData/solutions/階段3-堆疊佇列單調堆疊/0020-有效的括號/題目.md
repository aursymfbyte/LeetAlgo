# 20. 有效的括號

- 難度：簡單
- 連結：https://leetcode.com/problems/valid-parentheses/

## 題目

給你一個字串 `s`，裡面只會出現 `(`、`)`、`[`、`]`、`{`、`}` 這六種括號字元。請判斷這個字串的括號是否「有效」，有效就回傳 `true`，否則回傳 `false`。

有效的條件是：

- 每個左括號都必須由同一種類的右括號關上。
- 括號關上的順序要正確，也就是比較晚打開的左括號要比較早被關上。
- 每個右括號前面都必須有一個還沒被關上的、同種類的左括號跟它配對。

## 範例

**範例 1：**

```text
輸入：s = "()"
輸出：true
解釋：一組小括號正常配對。
```

**範例 2：**

```text
輸入：s = "()[]{}"
輸出：true
解釋：三組括號各自配對，彼此沒有交錯。
```

**範例 3：**

```text
輸入：s = "(]"
輸出：false
解釋：小括號被中括號關上，種類不同。
```

**範例 4：**

```text
輸入：s = "([])"
輸出：true
解釋：中括號完整包在小括號裡面，先關中括號再關小括號，順序正確。
```

**範例 5：**

```text
輸入：s = "([)]"
輸出：false
解釋：中括號還沒關上，小括號就先被關上了，兩組括號互相交錯。
```

## 提示

- `1 <= s.length <= 10^4`
- `s` 只由括號字元 `'()[]{}'` 組成
