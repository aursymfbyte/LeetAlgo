### 時間 O(n)

n 為字串 `s` 的長度。

- 程式由左至右走訪每個字元一次，最多 n 次。
- 每個字元的處理：
  - 左括號：放入堆疊頂端（push）。
  - 右括號：查 `opening_of` 取得對應的左括號，與堆疊頂端比較，再從頂端移除（pop）。
- 堆疊只在頂端放入或取出，不需移動其他元素，push、pop 皆為固定步數 O(1)；`opening_of` 僅 3 筆，查詢一次亦為 O(1)。
- 總計 n 次 × O(1) = **O(n)**。

### 空間 O(n)

- 額外記憶體主要為堆疊 `stack`。
- 最壞情況為字串全為左括號，例如 `((((`，每個字元都會放入堆疊，最多 n 個，為 **O(n)**。
- `opening_of` 固定 3 筆，不影響複雜度。
