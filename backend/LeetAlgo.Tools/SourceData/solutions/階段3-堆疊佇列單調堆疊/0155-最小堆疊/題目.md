# 155. 最小堆疊

- 難度：中等
- 連結：https://leetcode.com/problems/min-stack/

## 題目

設計一個堆疊類別 `MinStack`，除了一般的放入、取出、查看頂端之外，還要能隨時查出目前堆疊裡的最小值。每個方法都必須在 O(1) 時間內完成。

- `MinStack()`：建立一個空的堆疊。
- `void push(int value)`：把 `value` 放到堆疊頂端。
- `void pop()`：移除堆疊頂端的元素。
- `int top()`：回傳堆疊頂端的元素。
- `int getMin()`：回傳目前堆疊中所有元素的最小值。

## 範例

**範例 1：**

```text
輸入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]
輸出：
[null,null,null,null,-3,null,0,-2]
解釋：
建立空堆疊後，依序放入 -2、0、-3，堆疊由底到頂是 [-2, 0, -3]。
getMin() 此時最小的是 -3。
pop() 移除頂端的 -3，堆疊變成 [-2, 0]。
top() 頂端是 0。
getMin() 剩下的元素中最小的是 -2。
```

## 提示

- `-2^31 <= value <= 2^31 - 1`
- `pop`、`top`、`getMin` 呼叫時堆疊保證不是空的
- `push`、`pop`、`top`、`getMin` 加起來最多呼叫 `3 * 10^4` 次
