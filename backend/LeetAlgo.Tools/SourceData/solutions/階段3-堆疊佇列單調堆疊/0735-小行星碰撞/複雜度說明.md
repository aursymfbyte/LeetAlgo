### 時間 O(n)

n 為小行星數量，即 `asteroids` 的長度。

- 外層迴圈處理每顆小行星一次，共 n 次。
- 內部的 `while` 處理碰撞，每一圈只有兩種結果：
  - 堆疊頂端的小行星爆炸，被彈出。
  - 新加入的小行星爆炸（或兩顆同時爆炸），`alive` 變為 false，`while` 結束。
- 第二種情況每顆新小行星最多發生一次，合計最多 n 次。
- 第一種情況需計算彈出的總次數：每顆小行星最多放入堆疊一次，彈出後不會再放回，整個程式合計最多彈出 n 次。
- 所有 `while` 的圈數總和最多約 2n，加上外層的 n 次，總計 **O(n)**。

### 空間 O(n)

- 額外記憶體為堆疊 `stack`。
- 最壞情況為所有小行星往同一方向移動，皆不碰撞，全部留在堆疊中，共 n 顆，為 **O(n)**。
- 此堆疊最後直接作為答案回傳。
