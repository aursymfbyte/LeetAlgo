# 735. 小行星碰撞

- 難度：中等
- 連結：https://leetcode.com/problems/asteroid-collision/

## 題目

給你一個整數陣列 `asteroids`，代表排成一列的小行星，陣列下標就是它們在空間中由左到右的相對位置。

每個數字的絕對值是小行星的大小，正負號代表飛行方向：正數往右飛、負數往左飛。所有小行星的速度都一樣。

當兩顆小行星相遇時，比較小的那顆會爆炸消失；如果兩顆一樣大，就兩顆都爆炸。往同一個方向飛的小行星永遠不會相遇。

請回傳所有碰撞結束之後，還留下來的小行星（照原本的左右順序）。

## 範例

**範例 1：**

```text
輸入：asteroids = [5,10,-5]
輸出：[5,10]
解釋：10 和 -5 相撞，-5 比較小所以爆炸，10 留下。5 和 10 都往右飛，不會相撞。
```

**範例 2：**

```text
輸入：asteroids = [8,-8]
輸出：[]
解釋：8 和 -8 一樣大，相撞後兩顆都爆炸。
```

**範例 3：**

```text
輸入：asteroids = [10,2,-5]
輸出：[10]
解釋：-5 先撞到 2，2 比較小而爆炸；-5 接著撞到 10，-5 比較小而爆炸，只剩 10。
```

**範例 4：**

```text
輸入：asteroids = [3,5,-6,2,-1,4]
輸出：[-6,2,4]
解釋：-6 往左飛，先後撞爆 5 和 3，之後左邊沒有東西了，它就一直往左飛走。
右半邊的 -1 撞上 2，-1 比較小而爆炸。2 和 4 都往右飛，不會相撞。
```

## 提示

- `2 <= asteroids.length <= 10^4`
- `-1000 <= asteroids[i] <= 1000`
- `asteroids[i] != 0`
