### 時間 O(n)

n 為陣列 `nums` 的長度，k 為視窗大小。

- 外層迴圈走訪每個數一次，共 n 次。
- 迴圈內有一個從佇列尾端彈出元素的 `while`，形式上為兩層迴圈，需計算移除的總次數：
  - 每個下標只會放入佇列一次。
  - 移除（從尾端彈出，或滑出視窗時從前端彈出）後不會再放回，因此每個下標最多被移除一次。
  - 整個程式合計放入最多 n 次、移除最多 n 次。
- 雙端佇列（前後兩端皆可放入與取出的佇列）兩端操作皆為 O(1)，總計 n + n 次 O(1) 操作，為 **O(n)**。

暴力解：每個視窗掃描 k 個數尋找最大值，需 (n − k + 1) × k 次。n = 10⁵、k = 5 × 10⁴ 時約 25 億次，此寫法約 20 萬次。

### 空間：Python、C++ 是 O(k)，C、C# 是 O(n)

- 回傳的答案有 n − k + 1 個數，為題目要求的輸出，不計入額外空間。
- Python、C++ 使用真正的雙端佇列 `window`：滑出視窗的下標會立即從前端移除，佇列中的下標皆位於目前視窗內，最多 k 個，空間為 **O(k)**。
- C、C# 以一般陣列搭配 `head`、`tail` 兩個位置模擬佇列。從前端移除僅將 `head` 後移，已使用的格子不會重複利用，因此陣列需預先配置 n 格，空間為 **O(n)**。同一時間的有效元素仍最多 k 個，僅佔用的記憶體較多。
