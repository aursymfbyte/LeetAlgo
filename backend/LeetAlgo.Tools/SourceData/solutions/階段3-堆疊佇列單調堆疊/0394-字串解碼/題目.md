# 394. 字串解碼

- 難度：中等
- 連結：https://leetcode.com/problems/decode-string/

## 題目

給你一個經過編碼的字串 `s`，請回傳解碼後的字串。

編碼規則是 `k[encoded_string]`：中括號裡的內容要重複 `k` 次，`k` 一定是正整數。中括號可以一層包一層（巢狀）。

可以假設：

- 輸入一定合法，沒有多餘的空白，中括號都正確配對。
- 原始資料本身不含數字，數字只會用來表示重複次數 `k`，所以不會出現像 `3a` 或 `2[4]` 這種輸入。
- 解碼後的字串長度不會超過 `10^5`。

## 範例

**範例 1：**

```text
輸入：s = "3[a]2[bc]"
輸出："aaabcbc"
解釋："a" 重複 3 次得 "aaa"，"bc" 重複 2 次得 "bcbc"，接起來就是答案。
```

**範例 2：**

```text
輸入：s = "3[a2[c]]"
輸出："accaccacc"
解釋：先解內層 2[c] 得 "cc"，外層變成 3[acc]，重複 3 次得 "accaccacc"。
```

**範例 3：**

```text
輸入：s = "2[abc]3[cd]ef"
輸出："abcabccdcdcdef"
解釋："abc" 重複 2 次、"cd" 重複 3 次，最後接上沒有被括起來的 "ef"。
```

## 提示

- `1 <= s.length <= 30`
- `s` 由小寫英文字母、數字和中括號 `'[]'` 組成
- `s` 保證是合法的輸入
- `s` 裡所有整數的範圍都是 `[1, 300]`
