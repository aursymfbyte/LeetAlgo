# 84. 柱狀圖中最大的矩形

- 難度：困難
- 連結：https://leetcode.com/problems/largest-rectangle-in-histogram/

## 題目

給你一個整數陣列 `heights`，代表一張柱狀圖：每根柱子的寬度都是 1，`heights[i]` 是第 `i` 根柱子的高度，柱子之間緊緊相鄰。

請在這張柱狀圖裡找出能畫出的最大矩形（矩形要完全落在柱子範圍內），回傳它的面積。

## 範例

**範例 1：**

```text
輸入：heights = [2,1,5,6,2,3]
輸出：10
解釋：柱狀圖由左到右的高度如下（每個 # 代表一格）：

        #
      # #
      # #
      # #   #
  #   # # # #
  # # # # # #
  2 1 5 6 2 3

高度 5 和 6 這兩根相鄰的柱子，可以一起畫出高 5、寬 2 的矩形，面積 5 * 2 = 10，這是最大的。
```

**範例 2：**

```text
輸入：heights = [2,4]
輸出：4
解釋：可以用高度 4 的柱子單獨畫出 4 * 1 = 4，或用兩根柱子畫出高 2、寬 2 的矩形，面積也是 4。
```

## 提示

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`
