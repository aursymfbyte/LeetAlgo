### 時間 O(n)

n 為柱子數量，即 `heights` 的長度。

- 程式有三個迴圈，各執行 n 次：由左至右計算 `left`、由右至左計算 `right`、最後計算每根柱子的面積。
- 前兩個迴圈內另有一個彈出堆疊的 `while`，形式上為兩層迴圈，但不是 n²，需計算彈出的總次數：
  - 每根柱子在一次掃描中只會放入堆疊一次。
  - 彈出後不會再放回，因此每根柱子最多被彈出一次。
  - 一次掃描中所有 `while` 合計最多彈出 n 次。某一步可能連續彈出多個，但前面幾步相應地未彈出，總數不超過 n。
- 每次掃描為 n 次放入 + 最多 n 次彈出 = O(n)，三個迴圈合計仍為 **O(n)**。

暴力解：每根柱子向左右逐格尋找第一根較矮的柱子，最壞需 O(n²)。n = 10⁵ 時約 100 億步，此寫法僅需幾十萬步。

### 空間 O(n)

- `left` 與 `right` 兩個陣列各有 n 個數。
- 堆疊 `stack` 最多同時存放 n 個下標（例如柱子由矮到高排列時，一根都不會被彈出）。
- 合計約 3n，省略固定倍數後為 **O(n)**。
