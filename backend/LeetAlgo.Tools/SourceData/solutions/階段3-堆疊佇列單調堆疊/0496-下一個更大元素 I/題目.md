# 496. 下一個更大元素 I

- 難度：簡單
- 連結：https://leetcode.com/problems/next-greater-element-i/

## 題目

在一個陣列裡，數字 `x` 的「下一個更大元素」指的是：在同一個陣列中，位於 `x` 右邊、第一個比 `x` 大的數。

給你兩個沒有重複元素、下標從 0 開始的整數陣列 `nums1` 和 `nums2`，而且 `nums1` 的每個數都會出現在 `nums2` 裡。

對每個 `nums1[i]`，先在 `nums2` 裡找到同一個數的位置 `j`（也就是 `nums1[i] == nums2[j]`），再求出 `nums2[j]` 在 `nums2` 裡的下一個更大元素；如果右邊沒有比它大的數，答案就是 `-1`。

請回傳長度和 `nums1` 相同的陣列 `ans`，`ans[i]` 就是上面對 `nums1[i]` 求出的答案。

## 範例

**範例 1：**

```text
輸入：nums1 = [4,1,2], nums2 = [1,3,4,2]
輸出：[-1,3,-1]
解釋：
- 4 在 nums2 中右邊只有 2，沒有更大的數，答案 -1。
- 1 在 nums2 中右邊第一個比它大的是 3，答案 3。
- 2 在 nums2 的最後面，右邊沒有數，答案 -1。
```

**範例 2：**

```text
輸入：nums1 = [2,4], nums2 = [1,2,3,4]
輸出：[3,-1]
解釋：
- 2 在 nums2 中右邊第一個比它大的是 3。
- 4 在 nums2 的最後面，答案 -1。
```

## 提示

- `1 <= nums1.length <= nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 10^4`
- `nums1` 和 `nums2` 裡的整數各自都不重複
- `nums1` 的所有整數都會出現在 `nums2` 中

## 進階

你能想出時間複雜度 O(nums1.length + nums2.length) 的解法嗎？
