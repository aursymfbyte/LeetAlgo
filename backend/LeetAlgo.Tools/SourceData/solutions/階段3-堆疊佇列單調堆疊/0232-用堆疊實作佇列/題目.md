# 232. 用堆疊實作佇列

- 難度：簡單
- 連結：https://leetcode.com/problems/implement-queue-using-stacks/

## 題目

請只用兩個堆疊，做出一個先進先出（FIFO）的佇列 `MyQueue`，要支援一般佇列的操作：

- `MyQueue()`：建立一個空的佇列。
- `void push(int x)`：把 `x` 加到佇列的尾端。
- `int pop()`：移除佇列最前面的元素，並回傳它。
- `int peek()`：回傳佇列最前面的元素，但不移除。
- `boolean empty()`：佇列是空的就回傳 `true`，否則回傳 `false`。

限制：你只能使用堆疊的標準操作，也就是「從頂端放入」、「查看／取出頂端」、「取得大小」、「判斷是否為空」這幾種。如果你用的語言沒有內建堆疊，可以用串列或雙端佇列模擬，但只能用上面這些堆疊操作。

## 範例

**範例 1：**

```text
輸入：
["MyQueue", "push", "push", "peek", "pop", "empty"]
[[], [1], [2], [], [], []]
輸出：
[null, null, null, 1, 1, false]
解釋：
建立空佇列。
push(1) 之後佇列是 [1]。
push(2) 之後佇列是 [1, 2]（左邊是最前面）。
peek() 看最前面的元素，回傳 1。
pop() 取出最前面的 1 並回傳，佇列剩下 [2]。
empty() 佇列還有元素，回傳 false。
```

## 提示

- `1 <= x <= 9`
- `push`、`pop`、`peek`、`empty` 加起來最多呼叫 `100` 次
- 所有 `pop` 和 `peek` 的呼叫都保證合法（呼叫時佇列不是空的）

## 進階

你能讓每個操作的「均攤」時間複雜度都是 O(1) 嗎？也就是做 n 次操作的總時間是 O(n)，就算其中某一次操作比較久也沒關係。
