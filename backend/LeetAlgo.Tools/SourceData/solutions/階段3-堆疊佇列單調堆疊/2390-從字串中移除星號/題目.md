# 2390. 從字串中移除星號

- 難度：中等
- 連結：https://leetcode.com/problems/removing-stars-from-a-string/

## 題目

給你一個字串 `s`，裡面由小寫英文字母和星號 `*` 組成。

每一次操作，你可以：

- 挑一個星號。
- 把這個星號「左邊離它最近的非星號字元」刪掉，同時把這個星號本身也刪掉。

請把所有星號都用這種方式處理掉，回傳最後剩下的字串。

補充：

- 輸入保證每個星號都做得到上面的操作（左邊一定有字元可以刪）。
- 可以證明不管用什麼順序操作，最後的結果都一樣。

## 範例

**範例 1：**

```text
輸入：s = "leet**cod*e"
輸出："lecoe"
解釋：由左往右處理星號：
第 1 個星號刪掉它左邊最近的 't'，字串變成 "lee*cod*e"。
第 2 個星號刪掉 'e'，字串變成 "lecod*e"。
第 3 個星號刪掉 'd'，字串變成 "lecoe"。
已經沒有星號了，答案是 "lecoe"。
```

**範例 2：**

```text
輸入：s = "erase*****"
輸出：""
解釋：五個星號剛好把前面五個字母全部刪光，結果是空字串。
```

## 提示

- `1 <= s.length <= 10^5`
- `s` 由小寫英文字母和星號 `*` 組成
- 題目保證對 `s` 一定能完成上述操作
