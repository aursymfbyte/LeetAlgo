### 時間 O(n)

n 為字串 `s` 的長度。

- 程式由左至右走訪每個字元一次，共 n 次。
- 每個字元只做一件事：字母放入堆疊頂端，星號從頂端移除一個。堆疊只操作頂端，每次皆為 O(1)。
- 最後以 `"".join(stack)` 將剩餘字元串接為字串，堆疊最多 n 個字元，為 O(n)。
- 兩段相加：O(n) + O(n) = **O(n)**。

直覺寫法：每遇到一個星號，就從字串中間實際刪除兩個字元。字串刪除需將後方字元整段前移，最壞每次 O(n)，總計為 O(n²)。

### 空間 O(n)

- 額外記憶體為堆疊 `stack`。
- 最壞情況為字串中沒有星號，所有字元都放入堆疊，共 n 個，為 **O(n)**。
