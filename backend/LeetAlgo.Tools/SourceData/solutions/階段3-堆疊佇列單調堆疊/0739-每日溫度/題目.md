# 739. 每日溫度

- 難度：中等
- 連結：https://leetcode.com/problems/daily-temperatures/

## 題目

給你一個整數陣列 `temperatures`，`temperatures[i]` 是第 `i` 天的氣溫。請回傳一個同樣長度的陣列 `answer`：`answer[i]` 表示從第 `i` 天開始，要再等幾天才會遇到比當天更高的氣溫。如果之後都不會再出現更高的氣溫，`answer[i]` 就填 `0`。

## 範例

**範例 1：**

```text
輸入：temperatures = [73,74,75,71,69,72,76,73]
輸出：[1,1,4,2,1,1,0,0]
解釋：例如第 2 天是 75 度，要一直等到第 6 天的 76 度才更熱，所以等 4 天；
第 6 天的 76 度之後再也沒有更熱的日子，所以是 0。
```

**範例 2：**

```text
輸入：temperatures = [30,40,50,60]
輸出：[1,1,1,0]
解釋：氣溫每天都上升，前三天都只要等 1 天，最後一天之後沒有資料，填 0。
```

**範例 3：**

```text
輸入：temperatures = [30,60,90]
輸出：[1,1,0]
解釋：同樣是一路上升，最後一天填 0。
```

## 提示

- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`
