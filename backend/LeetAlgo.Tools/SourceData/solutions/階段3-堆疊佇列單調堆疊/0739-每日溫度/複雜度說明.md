### 時間 O(n)

n 為天數，即 `temperatures` 的長度。

- 外層迴圈走訪每一天一次，共 n 次。
- 內部的 `while` 將溫度低於當天的日子從堆疊彈出，形式上為兩層迴圈，需計算彈出的總次數：
  - 每一天只會放入堆疊一次。
  - 彈出（已求得答案）後不會再放回，因此每一天最多被彈出一次。
  - 整個程式合計放入 n 次、彈出最多 n 次。
- 每次放入、彈出、填寫答案皆為 O(1)，總計約 2n 次，省略固定倍數後為 **O(n)**。

暴力解：每一天向後逐日尋找第一個較暖的日子，最壞需 O(n²)。n = 10⁵ 時約 50 億步，此寫法約 20 萬步。

### 空間 O(n)

- 堆疊 `stack` 最壞需存放 n 個下標：例如溫度持續下降，每一天都沒有更暖的日子，全部留在堆疊中。
- 回傳的 `answer` 也有 n 個數，但為題目要求的輸出。僅堆疊即為 **O(n)**。
