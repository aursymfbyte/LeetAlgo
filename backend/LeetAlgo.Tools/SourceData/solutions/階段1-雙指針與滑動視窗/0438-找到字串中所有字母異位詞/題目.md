# 438. 找到字串中所有字母異位詞

- 難度：中等
- 連結：https://leetcode.com/problems/find-all-anagrams-in-a-string/

## 題目

給你兩個字串 `s` 和 `p`。如果一段字串跟 `p` 用到的字母完全相同、每個字母出現的次數也一樣（只是排列順序可能不同），就稱它是 `p` 的異位詞。

請找出 `s` 中所有是 `p` 的異位詞的子字串，回傳它們的起始下標。下標可以用任意順序回傳。

## 範例

**範例 1：**

```text
輸入：s = "cbaebabacd", p = "abc"
輸出：[0,6]
解釋：
從下標 0 開始的 "cba" 由 a、b、c 各一個組成，是 "abc" 的異位詞。
從下標 6 開始的 "bac" 也是 "abc" 的異位詞。
```

**範例 2：**

```text
輸入：s = "abab", p = "ab"
輸出：[0,1,2]
解釋：
從下標 0 開始的 "ab"、下標 1 開始的 "ba"、下標 2 開始的 "ab"，都是 "ab" 的異位詞。
```

## 提示

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 只包含小寫英文字母
