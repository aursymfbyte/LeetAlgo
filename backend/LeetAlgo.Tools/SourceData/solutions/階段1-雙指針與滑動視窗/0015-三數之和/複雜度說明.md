### 時間 O(n²)

n 為陣列 `nums` 的長度。

- 先排序，約 n log n 步。log n 為 n 反覆除以 2 直到剩 1 所需的次數，n = 3000 時約為 12。
- 外層迴圈枚舉第一個數 `nums[i]`，最多 n 次。
- 對每個 `i`，內層雙指針 `left`、`right` 從 `i` 右側的兩端往中間移動。每一步至少有一個指針往中間移一格（跳過重複值亦為移動指針），因此兩指針合計最多走 n 步即相遇。
- 外層 n 次 × 內層最多 n 步 = O(n²)。排序的 n log n 小於 n²，相加後由 n² 主導，總計為 **O(n²)**。
- 兩個剪枝在實際資料上通常能省下大量次數，但不改變最壞情況的結論。

暴力解：以三層迴圈嘗試所有三數組合，約 n³/6 次。n = 3000 時約 45 億次，此寫法約 450 萬次。

### 空間 O(1)（不計排序和輸出）

- 除排序與答案外，僅使用 `i`、`left`、`right`、`total` 幾個變數，數量固定，為 **O(1)**。
- 排序為語言內建函式，各語言實作所需的額外記憶體不同（例如 Python 的排序最多 O(n)，C++ 約 O(log n)），因此另行看待，不計入此結論。
- 答案 `answer` 為題目要求回傳的結果，任何寫法都必須存放，慣例上不計入額外空間。
