# 15. 三數之和

- 難度：中等
- 連結：https://leetcode.com/problems/3sum/

## 題目

給你一個整數陣列 `nums`，請找出所有三元組 `[nums[i], nums[j], nums[k]]`，其中 `i`、`j`、`k` 是三個互不相同的下標，而且三個數加起來等於 `0`。

回傳所有符合條件的三元組。答案裡不能有重複的三元組（由相同三個數值組成的算同一組，不管下標是否不同）。三元組之間的順序、以及每個三元組內數字的順序都不影響答案。

## 範例

**範例 1：**

```text
輸入：nums = [-1,0,1,2,-1,-4]
輸出：[[-1,-1,2],[-1,0,1]]
解釋：
下標 0、1、2 的數是 -1、0、1，總和為 0。
下標 1、2、4 的數是 0、1、-1，總和為 0。
下標 0、3、4 的數是 -1、2、-1，總和為 0。
前兩組其實都是 {-1,0,1}，只算一次，所以不重複的答案是 [-1,0,1] 和 [-1,-1,2]。
```

**範例 2：**

```text
輸入：nums = [0,1,1]
輸出：[]
解釋：只能選出 0、1、1 這一組，總和是 2，不是 0。
```

**範例 3：**

```text
輸入：nums = [0,0,0]
輸出：[[0,0,0]]
解釋：唯一能選的三個數都是 0，總和為 0。
```

## 提示

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`
