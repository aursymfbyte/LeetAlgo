# 643. 子陣列最大平均數 I

- 難度：簡單
- 連結：https://leetcode.com/problems/maximum-average-subarray-i/

## 題目

給你一個有 `n` 個元素的整數陣列 `nums`，以及一個整數 `k`。

在所有長度剛好為 `k` 的連續子陣列中，找出平均值最大的那一個，回傳這個最大平均值。答案與正確值的誤差小於 `10^-5` 就算正確。

## 範例

**範例 1：**

```text
輸入：nums = [1,12,-5,-6,50,3], k = 4
輸出：12.75000
解釋：長度 4 的子陣列中，[12,-5,-6,50] 的總和 51 最大，平均是 51 / 4 = 12.75。
```

**範例 2：**

```text
輸入：nums = [5], k = 1
輸出：5.00000
解釋：只有一個長度為 1 的子陣列 [5]，平均就是 5。
```

## 提示

- `n == nums.length`
- `1 <= k <= n <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
