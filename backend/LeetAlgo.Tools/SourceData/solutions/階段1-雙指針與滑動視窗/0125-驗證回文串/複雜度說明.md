### 時間 O(n)

n 為字串 `s` 的長度。

- `left` 從最左端、`right` 從最右端出發，初始相距 n − 1。
- 每輪迴圈僅執行固定步數：檢查一個字元是否為字母或數字，或將兩個字元轉為小寫後比較。之後至少有一個指針往中間移一格（或發現不同即結束）。
- 每輪兩指針距離至少減 1，最多執行 n − 1 次即相遇，為 **O(n)**。

### 空間 O(1)

- 額外使用的只有 `left`、`right` 兩個下標，數量固定，與 n 無關，為 **O(1)**。
- 直覺寫法：先挑出字母與數字並轉為小寫組成新字串，再與其反轉後的字串比較。此作法需多存一份最長 n 的新字串，空間為 O(n)。此寫法直接在原字串上逐一比對，因而省下這份空間。
