# 125. 驗證回文串

- 難度：簡單
- 連結：https://leetcode.com/problems/valid-palindrome/

## 題目

給你一個字串 `s`。先把其中所有大寫英文字母改成小寫，再把所有「不是字母也不是數字」的字元全部拿掉，如果剩下的字串從前面讀和從後面讀完全一樣，就稱 `s` 是回文。

字母和數字都算在保留範圍內。請判斷 `s` 是不是回文，是就回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：s = "A man, a plan, a canal: Panama"
輸出：true
解釋：去掉空白和標點、轉成小寫後得到 "amanaplanacanalpanama"，正讀反讀都一樣。
```

**範例 2：**

```text
輸入：s = "race a car"
輸出：false
解釋：處理後得到 "raceacar"，反過來是 "racaecar"，兩者不同。
```

**範例 3：**

```text
輸入：s = " "
輸出：true
解釋：唯一的空白被拿掉後變成空字串，空字串反過來還是空字串，所以算回文。
```

## 提示

- `1 <= s.length <= 2 * 10^5`
- `s` 只包含可列印的 ASCII 字元
