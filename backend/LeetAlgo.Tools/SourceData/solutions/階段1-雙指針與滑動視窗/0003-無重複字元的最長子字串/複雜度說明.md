### 時間 O(n)

n 為字串 `s` 的長度。

- 右端點 `right` 從頭走到尾，共 n 次。每次將一個字元加入計數，固定步數。
- 內層 `while` 將左端點 `left` 右移。注意：雖為兩層迴圈，但 `left` 只會右移、不會回頭，且不超過字串結尾，因此整個程式中 `left` 最多移動 n 次。
- 每個字元最多進入視窗一次、離開視窗一次，合計不超過 2n 步，常數倍不影響成長趨勢，為 **O(n)**。

暴力解：逐一檢查每個子字串是否有重複，至少 O(n²)。n = 10⁵ 時約 50 億次，此寫法約 20 萬次。

### 空間 O(字元集大小)

字元集大小為字串中可能出現的不同字元種類數。此題的字元為英文字母、數字、符號與空白，皆在 ASCII 的 128 種以內。

- 額外記憶體僅有計數表 `count`。
- C 與 C# 直接配置長度 128 的陣列；Python 與 C++ 使用雜湊表，只存放出現過的字元，最多不超過 128 種。
- 空間取決於字元集大小而非字串長度，記作 **O(字元集大小)**。因 128 為固定數字，亦可記為 O(1)。
