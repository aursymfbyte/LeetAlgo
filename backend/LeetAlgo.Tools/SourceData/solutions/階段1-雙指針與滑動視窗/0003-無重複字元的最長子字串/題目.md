# 3. 無重複字元的最長子字串

- 難度：中等
- 連結：https://leetcode.com/problems/longest-substring-without-repeating-characters/

## 題目

給你一個字串 `s`，請找出其中「沒有任何字元重複出現」的最長子字串，回傳它的長度。

子字串必須是原字串中連續的一段。

## 範例

**範例 1：**

```text
輸入：s = "abcabcbb"
輸出：3
解釋："abc" 沒有重複字元，長度 3；"bca"、"cab" 也是長度 3 的答案，找不到更長的。
```

**範例 2：**

```text
輸入：s = "bbbbb"
輸出：1
解釋：全部都是 b，任何長度 2 以上的子字串都會重複，最長只能是 "b"。
```

**範例 3：**

```text
輸入：s = "pwwkew"
輸出：3
解釋："wke" 是最長的無重複子字串，長度 3。
"pwke" 雖然沒有重複字元，但它不是連續的一段（是子序列），不算子字串。
```

## 提示

- `0 <= s.length <= 10^5`
- `s` 由英文字母、數字、符號和空白組成
