### 時間 O(n)

n 為陣列 `height` 的長度。

- `left` 從最左端、`right` 從最右端出發，初始相距 n − 1。
- 每輪迴圈僅執行固定步數：更新 `pre_max` 與 `suf_max`、計算一格的水量，接著 `left` 右移一格或 `right` 左移一格。
- 每輪兩指針距離恰好減 1，距離為 0 時結束，共執行 n − 1 次，為 **O(n)**。

暴力解：對每一格分別往左、往右尋找最高柱子，每格 O(n)，總計 O(n²)。

### 空間 O(1)

- 額外使用的只有 `left`、`right`、`pre_max`、`suf_max`、`answer` 幾個變數，數量固定，與 n 無關，為 **O(1)**。
- 前後綴分解寫法：另外配置兩個長度 n 的陣列，分別存放每一格左側與右側的最高值，空間為 O(n)。雙指針在走訪時同步維護這兩個最大值，因而省下這兩個陣列。
