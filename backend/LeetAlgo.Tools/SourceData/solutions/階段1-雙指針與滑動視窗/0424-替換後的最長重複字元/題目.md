# 424. 替換後的最長重複字元

- 難度：中等
- 連結：https://leetcode.com/problems/longest-repeating-character-replacement/

## 題目

給你一個只由大寫英文字母組成的字串 `s`，以及一個整數 `k`。

每次操作可以挑字串中任意一個字元，把它換成任意一個大寫英文字母，最多可以操作 `k` 次。

請回傳經過這些操作後，字串中「全部由同一個字母組成」的子字串最長可以有多長。

## 範例

**範例 1：**

```text
輸入：s = "ABAB", k = 2
輸出：4
解釋：把兩個 A 都換成 B（或把兩個 B 都換成 A），整個字串變成同一個字母，長度 4。
```

**範例 2：**

```text
輸入：s = "AABABBA", k = 1
輸出：4
解釋：把中間下標 3 的 A 換成 B，字串變成 "AABBBBA"，其中 "BBBB" 長度為 4。
也可能有其他換法得到同樣的長度。
```

## 提示

- `1 <= s.length <= 10^5`
- `s` 只包含大寫英文字母
- `0 <= k <= s.length`
