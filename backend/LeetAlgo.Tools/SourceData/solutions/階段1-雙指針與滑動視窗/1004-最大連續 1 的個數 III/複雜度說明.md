### 時間 O(n)

n 為陣列 `nums` 的長度。k 為最多可將幾個 0 翻成 1，只影響視窗條件，不影響步數。

- 右端點 `right` 從頭走到尾，共 n 次。每次遇到 0 即將 `zero_count` 加一，固定步數。
- 內層 `while` 將左端點 `left` 右移。注意：雖為兩層迴圈，但 `left` 只會右移、不會回頭，整個程式中最多移動 n 次。
- 每個數最多進入視窗一次、離開視窗一次，合計不超過 2n 步，常數倍不影響成長趨勢，為 **O(n)**。

暴力解：逐一嘗試每一組起點與終點，為 O(n²)。n = 10⁵ 時約 50 億次，此寫法約 20 萬次。

### 空間 O(1)

- 額外使用的只有 `zero_count`、`left`、`answer` 幾個變數，數量固定，與 n 無關，為 **O(1)**。
- 不需實際修改陣列中的 0，只需記錄視窗內 0 的個數。
