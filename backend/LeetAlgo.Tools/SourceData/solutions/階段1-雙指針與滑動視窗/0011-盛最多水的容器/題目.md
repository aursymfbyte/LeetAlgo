# 11. 盛最多水的容器

- 難度：中等
- 連結：https://leetcode.com/problems/container-with-most-water/

## 題目

給你一個長度為 `n` 的整數陣列 `height`。想像在 x 軸上豎立了 `n` 條垂直的線，第 `i` 條線的底端在 `(i, 0)`、頂端在 `(i, height[i])`。

從中挑兩條線，跟 x 軸一起圍成一個裝水的容器。容器的寬度是兩條線的下標差，能裝的水高只到兩條線中比較矮的那條（容器不能傾斜）。

請回傳容器最多能裝多少水，也就是 `寬度 × 較矮那條線的高度` 的最大值。

## 範例

**範例 1：**

```text
輸入：height = [1,8,6,2,5,4,8,3,7]
輸出：49
解釋：選下標 1（高 8）和下標 8（高 7）這兩條線，寬度是 8 - 1 = 7，
水高受限於較矮的 7，所以能裝 7 × 7 = 49，這是所有選法中最大的。
```

**範例 2：**

```text
輸入：height = [1,1]
輸出：1
解釋：只有兩條線，寬度 1、高度 1，面積為 1。
```

## 提示

- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`
