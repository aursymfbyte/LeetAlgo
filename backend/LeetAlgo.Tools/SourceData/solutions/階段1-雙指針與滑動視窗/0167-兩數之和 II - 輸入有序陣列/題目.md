# 167. 兩數之和 II - 輸入有序陣列

- 難度：中等
- 連結：https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/

## 題目

給你一個已經按照「非遞減」順序排好的整數陣列 `numbers`，注意它的下標從 **1** 開始算。

請從中找出兩個數，使它們相加剛好等於 `target`。假設這兩個數是 `numbers[index1]` 和 `numbers[index2]`，要滿足 `1 <= index1 < index2 <= numbers.length`，以長度為 2 的陣列 `[index1, index2]` 回傳。

測資保證剛好只有一組解，而且同一個元素不能使用兩次。你的做法只能使用常數的額外空間。

## 範例

**範例 1：**

```text
輸入：numbers = [2,7,11,15], target = 9
輸出：[1,2]
解釋：第 1 個數 2 加第 2 個數 7 等於 9，所以回傳 [1,2]。
```

**範例 2：**

```text
輸入：numbers = [2,3,4], target = 6
輸出：[1,3]
解釋：第 1 個數 2 加第 3 個數 4 等於 6，所以回傳 [1,3]。
```

**範例 3：**

```text
輸入：numbers = [-1,0], target = -1
輸出：[1,2]
解釋：-1 加 0 等於 -1，兩個數分別在第 1 和第 2 個位置。
```

## 提示

- `2 <= numbers.length <= 3 * 10^4`
- `-1000 <= numbers[i] <= 1000`
- `numbers` 以非遞減順序排列
- `-1000 <= target <= 1000`
- 測資保證恰好只有一組解
