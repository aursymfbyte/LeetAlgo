# 76. 最小覆蓋子字串

- 難度：困難
- 連結：https://leetcode.com/problems/minimum-window-substring/

## 題目

給你兩個字串 `s`（長度 `m`）和 `t`（長度 `n`）。

請在 `s` 中找出最短的一段連續子字串，使 `t` 裡的每個字元都包含在這段子字串中，而且重複的字元也要算足數量（例如 `t` 有兩個 `a`，子字串裡就至少要有兩個 `a`）。回傳這段最短的子字串；如果找不到，回傳空字串 `""`。

測資保證符合條件的最短子字串只有一個。

## 範例

**範例 1：**

```text
輸入：s = "ADOBECODEBANC", t = "ABC"
輸出："BANC"
解釋："BANC" 同時含有 A、B、C，而且是所有符合條件的子字串中最短的。
```

**範例 2：**

```text
輸入：s = "a", t = "a"
輸出："a"
解釋：整個 s 就是答案。
```

**範例 3：**

```text
輸入：s = "a", t = "aa"
輸出：""
解釋：t 需要兩個 a，但 s 整段也只有一個 a，不可能湊齊，所以回傳空字串。
```

## 提示

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 10^5`
- `s` 和 `t` 由大寫和小寫英文字母組成

## 進階

你能設計出時間複雜度為 O(m + n) 的演算法嗎？
