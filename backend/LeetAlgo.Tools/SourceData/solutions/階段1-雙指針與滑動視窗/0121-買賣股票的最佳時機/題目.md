# 121. 買賣股票的最佳時機

- 難度：簡單
- 連結：https://leetcode.com/problems/best-time-to-buy-and-sell-stock/

## 題目

給你一個陣列 `prices`，`prices[i]` 是某支股票第 `i` 天的價格。

你只能做一次交易：挑某一天買進一股，再挑之後的另一天把它賣掉（必須先買後賣）。請回傳這次交易最多能賺多少錢；如果怎麼買賣都賺不到錢，就回傳 `0`。

## 範例

**範例 1：**

```text
輸入：prices = [7,1,5,3,6,4]
輸出：5
解釋：第 2 天以價格 1 買進，第 5 天以價格 6 賣出，賺 6 - 1 = 5。
雖然第 1 天價格 7 比較高，但它在第 2 天之前，不能先賣再買。
```

**範例 2：**

```text
輸入：prices = [7,6,4,3,1]
輸出：0
解釋：價格一路下跌，任何買賣都會虧錢，所以不交易，利潤為 0。
```

## 提示

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`
