# 567. 字串的排列

- 難度：中等
- 連結：https://leetcode.com/problems/permutation-in-string/

## 題目

給你兩個字串 `s1` 和 `s2`。請判斷 `s2` 裡面是否有一段連續的子字串，剛好是 `s1` 把字母重新排列後得到的結果（也就是字母種類和每種字母的個數都跟 `s1` 一樣）。

有的話回傳 `true`，沒有就回傳 `false`。

## 範例

**範例 1：**

```text
輸入：s1 = "ab", s2 = "eidbaooo"
輸出：true
解釋：s2 中間有一段 "ba"，它是 "ab" 的一種排列。
```

**範例 2：**

```text
輸入：s1 = "ab", s2 = "eidboaoo"
輸出：false
解釋：s2 裡的 b 和 a 中間隔著 o，找不到一段長度 2、剛好由一個 a 和一個 b 組成的子字串。
```

## 提示

- `1 <= s1.length, s2.length <= 10^4`
- `s1` 和 `s2` 只包含小寫英文字母
