# 713. 乘積小於 K 的子陣列

- 難度：中等
- 連結：https://leetcode.com/problems/subarray-product-less-than-k/

## 題目

給你一個整數陣列 `nums` 和一個整數 `k`。

請計算有多少個連續子陣列，其中所有元素相乘的結果「嚴格小於」`k`，回傳這個數量。

## 範例

**範例 1：**

```text
輸入：nums = [10,5,2,6], k = 100
輸出：8
解釋：乘積小於 100 的子陣列共有 8 個：
[10]、[5]、[2]、[6]、[10,5]、[5,2]、[2,6]、[5,2,6]。
[10,5,2] 的乘積剛好是 100，不是嚴格小於 100，所以不算。
```

**範例 2：**

```text
輸入：nums = [1,2,3], k = 0
輸出：0
解釋：元素都是正整數，乘積不可能小於 0，所以一個都沒有。
```

## 提示

- `1 <= nums.length <= 3 * 10^4`
- `1 <= nums[i] <= 1000`
- `0 <= k <= 10^6`
