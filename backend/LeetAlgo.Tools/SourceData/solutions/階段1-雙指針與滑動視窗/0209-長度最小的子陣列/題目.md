# 209. 長度最小的子陣列

- 難度：中等
- 連結：https://leetcode.com/problems/minimum-size-subarray-sum/

## 題目

給你一個由正整數組成的陣列 `nums`，以及一個正整數 `target`。

請找出總和大於或等於 `target` 的連續子陣列中，長度最短的那一個，回傳它的長度。如果沒有任何子陣列的總和能達到 `target`，回傳 `0`。

## 範例

**範例 1：**

```text
輸入：target = 7, nums = [2,3,1,2,4,3]
輸出：2
解釋：子陣列 [4,3] 的總和是 7，長度 2，沒有更短的子陣列能達到 7。
```

**範例 2：**

```text
輸入：target = 4, nums = [1,4,4]
輸出：1
解釋：單獨一個 4 就達到 target，長度為 1。
```

**範例 3：**

```text
輸入：target = 11, nums = [1,1,1,1,1,1,1,1]
輸出：0
解釋：整個陣列加起來只有 8，達不到 11，所以回傳 0。
```

## 提示

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

## 進階

如果你已經寫出 O(n) 的做法，可以再試試寫一個 O(n log n) 的做法。
