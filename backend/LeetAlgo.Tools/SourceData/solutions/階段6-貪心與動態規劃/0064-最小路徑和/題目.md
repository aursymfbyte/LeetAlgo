# 64. 最小路徑和

- 難度：中等
- 連結：https://leetcode.com/problems/minimum-path-sum/

## 題目

給你一個 `m x n` 的網格 `grid`，每一格都是非負整數。請從左上角走到右下角，找出一條路徑使得路徑上經過的所有數字總和最小，並回傳這個最小總和。

每一步只能往右或往下移動一格。

## 範例

**範例 1：**

```text
輸入：grid = [[1,3,1],[1,5,1],[4,2,1]]
輸出：7
解釋：網格如下：
      1 3 1
      1 5 1
      4 2 1
      沿著 1 → 3 → 1 → 1 → 1（先往右兩格，再往下兩格）走，總和 7 是最小的。
```

**範例 2：**

```text
輸入：grid = [[1,2,3],[4,5,6]]
輸出：12
解釋：沿著 1 → 2 → 3 → 6 走，總和為 12。
```

## 提示

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`
