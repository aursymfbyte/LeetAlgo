# 337. 打家劫舍 III

- 難度：中等
- 連結：https://leetcode.com/problems/house-robber-iii/

## 題目

小偷又找到一個新地區，這裡的所有房子剛好連成一棵二元樹：唯一的入口是根節點 `root`，除了根之外，每間房子都有且只有一間父房子。每個節點的 `val` 是那間房子裡的錢。

如果同一晚有兩間「直接相連」的房子（也就是父子節點）都被偷，就會自動報警。

給你這棵樹的根節點 `root`，在不觸發警報的前提下，回傳小偷最多能偷到多少錢。

輸入用層序表示樹，`null` 代表該位置沒有節點。

## 範例

**範例 1：**

```text
輸入：root = [3,2,3,null,3,null,1]
輸出：7
解釋：樹的形狀如下：
          3
         / \
        2   3
         \   \
          3   1
      偷根節點 3、左下的 3 和右下的 1，三者互不相連，總共 3 + 3 + 1 = 7。
```

**範例 2：**

```text
輸入：root = [3,4,5,1,3,null,1]
輸出：9
解釋：樹的形狀如下：
            3
           / \
          4   5
         / \   \
        1   3   1
      偷第二層的 4 和 5，總共 4 + 5 = 9。
```

## 提示

- 樹中節點數量在 `[1, 10^4]` 範圍內
- `0 <= Node.val <= 10^4`
