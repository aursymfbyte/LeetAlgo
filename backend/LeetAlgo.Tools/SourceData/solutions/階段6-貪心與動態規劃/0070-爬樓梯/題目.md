# 70. 爬樓梯

- 難度：簡單
- 連結：https://leetcode.com/problems/climbing-stairs/

## 題目

有一座共 `n` 階的樓梯，你從地面（第 0 階）出發，要走到最上面的第 `n` 階。

每一次移動可以往上走 1 階或 2 階。請計算總共有多少種不同的走法可以剛好到達頂端，並回傳這個數量。

## 範例

**範例 1：**

```text
輸入：n = 2
輸出：2
解釋：可以一次走 1 階走兩次（1 + 1），或直接一次走 2 階，共 2 種。
```

**範例 2：**

```text
輸入：n = 3
輸出：3
解釋：三種走法分別是 1 + 1 + 1、1 + 2、2 + 1。
```

## 提示

- `1 <= n <= 45`
