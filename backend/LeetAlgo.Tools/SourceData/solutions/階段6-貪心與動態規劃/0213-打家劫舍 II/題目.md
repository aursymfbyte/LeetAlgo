# 213. 打家劫舍 II

- 難度：中等
- 連結：https://leetcode.com/problems/house-robber-ii/

## 題目

這次的房子不是排成一直線，而是圍成一個圓圈，因此第一間房子和最後一間房子也算相鄰。整數陣列 `nums` 中的 `nums[i]` 代表第 `i` 間房子裡藏的錢。

同樣地，只要同一晚有兩間相鄰的房子被闖入就會報警。在不觸發警報的前提下，請回傳今晚最多能偷到多少錢。

## 範例

**範例 1：**

```text
輸入：nums = [2,3,2]
輸出：3
解釋：第 1 間和第 3 間在圓圈上相鄰，不能同時偷，所以最好的做法是只偷中間那間 3 元。
```

**範例 2：**

```text
輸入：nums = [1,2,3,1]
輸出：4
解釋：偷第 1 間（1 元）和第 3 間（3 元），總共 4。
```

**範例 3：**

```text
輸入：nums = [1,2,3]
輸出：3
```

## 提示

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`
