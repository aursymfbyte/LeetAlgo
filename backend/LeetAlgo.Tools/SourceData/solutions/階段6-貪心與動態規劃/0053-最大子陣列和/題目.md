# 53. 最大子陣列和

- 難度：中等
- 連結：https://leetcode.com/problems/maximum-subarray/

## 題目

給你一個整數陣列 `nums`，請在所有「連續且至少包含一個元素」的子陣列中，找出元素總和最大的那一個，並回傳這個最大總和。

## 範例

**範例 1：**

```text
輸入：nums = [-2,1,-3,4,-1,2,1,-5,4]
輸出：6
解釋：取中間的 [4,-1,2,1]，總和 6 是所有連續子陣列裡最大的。
```

**範例 2：**

```text
輸入：nums = [1]
輸出：1
解釋：只有一個元素，子陣列只能是 [1]。
```

**範例 3：**

```text
輸入：nums = [5,4,-1,7,8]
輸出：23
解釋：整個陣列加起來是 23，雖然中間有 -1，但拿掉它會把陣列切斷，反而變小。
```

## 提示

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 進階

如果你已經寫出 O(n) 的解法，可以再試試用分治法來解，那個做法比較精妙。
