# 55. 跳躍遊戲

- 難度：中等
- 連結：https://leetcode.com/problems/jump-game/

## 題目

給你一個整數陣列 `nums`，你一開始站在第一個位置（下標 `0`）。`nums[i]` 表示站在下標 `i` 時，往前跳最多可以跳幾格（可以跳比較少格，也可以不跳）。

請判斷能不能抵達最後一個位置，可以就回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：nums = [2,3,1,1,4]
輸出：true
解釋：先從下標 0 跳 1 格到下標 1，再從那裡跳 3 格，就到了最後一個位置。
```

**範例 2：**

```text
輸入：nums = [3,2,1,0,4]
輸出：false
解釋：不管前面怎麼跳，最遠都只會停在下標 3；而下標 3 的值是 0，一步都跳不出去，所以到不了最後一格。
```

## 提示

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^5`
