# 56. 合併區間

- 難度：中等
- 連結：https://leetcode.com/problems/merge-intervals/

## 題目

給你一個區間陣列 `intervals`，其中 `intervals[i] = [start_i, end_i]`。請把所有彼此重疊的區間合併起來，回傳合併後的區間陣列：這些區間兩兩不重疊，而且剛好涵蓋輸入中所有區間涵蓋的範圍。

兩個區間只要有共同的點就算重疊，端點剛好相接（例如 `[1,4]` 和 `[4,5]`）也算。

## 範例

**範例 1：**

```text
輸入：intervals = [[1,3],[2,6],[8,10],[15,18]]
輸出：[[1,6],[8,10],[15,18]]
解釋：[1,3] 和 [2,6] 有重疊，合併成 [1,6]；其他區間跟誰都不重疊，原樣保留。
```

**範例 2：**

```text
輸入：intervals = [[1,4],[4,5]]
輸出：[[1,5]]
解釋：兩個區間在 4 這個點相接，也算重疊，合併成 [1,5]。
```

**範例 3：**

```text
輸入：intervals = [[4,7],[1,4]]
輸出：[[1,7]]
解釋：輸入不一定照順序排好；[1,4] 和 [4,7] 在 4 相接，合併成 [1,7]。
```

## 提示

- `1 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= start_i <= end_i <= 10^4`
