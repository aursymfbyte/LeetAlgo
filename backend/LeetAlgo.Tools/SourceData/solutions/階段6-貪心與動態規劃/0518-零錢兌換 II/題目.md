# 518. 零錢兌換 II

- 難度：中等
- 連結：https://leetcode.com/problems/coin-change-ii/

## 題目

給你一個整數 `amount` 代表要湊出的總金額，以及一個整數陣列 `coins`，代表幾種不同面額的硬幣。每一種面額的硬幣數量都是無限的。

請回傳有多少種「組合」可以剛好湊出 `amount`。組合只看每種硬幣各用了幾枚，不看拿取順序（例如 `2 + 1` 和 `1 + 2` 算同一種）。如果湊不出來，回傳 `0`。

測資保證答案可以放進 32 位元有號整數。

## 範例

**範例 1：**

```text
輸入：amount = 5, coins = [1,2,5]
輸出：4
解釋：湊出 5 的組合有四種：
      5 = 5
      5 = 2 + 2 + 1
      5 = 2 + 1 + 1 + 1
      5 = 1 + 1 + 1 + 1 + 1
```

**範例 2：**

```text
輸入：amount = 3, coins = [2]
輸出：0
解釋：只用面額 2 的硬幣湊不出 3。
```

**範例 3：**

```text
輸入：amount = 10, coins = [10]
輸出：1
```

## 提示

- `1 <= coins.length <= 300`
- `1 <= coins[i] <= 5000`
- `coins` 中的值互不相同
- `0 <= amount <= 5000`
