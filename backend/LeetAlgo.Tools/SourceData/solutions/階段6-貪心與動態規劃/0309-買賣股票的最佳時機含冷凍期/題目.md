# 309. 買賣股票的最佳時機含冷凍期

- 難度：中等
- 連結：https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/

## 題目

給你一個陣列 `prices`，`prices[i]` 是某支股票第 `i` 天的價格。

你可以進行任意多次交易（每次交易是買進一股再賣出），但要遵守下面的規則：

- 賣出股票的隔天不能買進，也就是賣出後要「冷凍」一天。
- 手上最多只能持有一股，必須先賣掉手上的股票才能再買。

請回傳你能獲得的最大利潤。

## 範例

**範例 1：**

```text
輸入：prices = [1,2,3,0,2]
輸出：3
解釋：依序做「買進、賣出、冷凍、買進、賣出」：
      第 1 天以 1 買進、第 2 天以 2 賣出（賺 1），第 3 天冷凍，
      第 4 天以 0 買進、第 5 天以 2 賣出（賺 2），總共 3。
```

**範例 2：**

```text
輸入：prices = [1]
輸出：0
解釋：只有一天，無法完成任何交易。
```

## 提示

- `1 <= prices.length <= 5000`
- `0 <= prices[i] <= 1000`
