# 714. 買賣股票的最佳時機含手續費

- 難度：中等
- 連結：https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/

## 題目

給你一個陣列 `prices`，`prices[i]` 是某支股票第 `i` 天的價格，另外給你一個整數 `fee` 代表每筆交易的手續費。

你可以進行任意多次交易，但每完成一筆交易（買進一股再賣出）都要付一次手續費 `fee`，買和賣合起來只收一次。手上最多只能持有一股，必須先賣掉才能再買。

請回傳你能獲得的最大利潤。

## 範例

**範例 1：**

```text
輸入：prices = [1,3,2,8,4,9], fee = 2
輸出：8
解釋：以 1 買進、以 8 賣出，扣手續費後賺 (8 - 1) - 2 = 5；
      再以 4 買進、以 9 賣出，扣手續費後賺 (9 - 4) - 2 = 3；
      總共 5 + 3 = 8。
```

**範例 2：**

```text
輸入：prices = [1,3,7,5,10,3], fee = 3
輸出：6
```

## 提示

- `1 <= prices.length <= 5 * 10^4`
- `1 <= prices[i] < 5 * 10^4`
- `0 <= fee < 5 * 10^4`
