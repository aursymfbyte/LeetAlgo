# 45. 跳躍遊戲 II

- 難度：中等
- 連結：https://leetcode.com/problems/jump-game-ii/

## 題目

給你一個長度為 `n`、下標從 `0` 開始的整數陣列 `nums`，你一開始站在下標 `0`。`nums[i]` 表示站在下標 `i` 時，往前最多能跳幾格：也就是可以跳到任何下標 `i + j`，其中 `0 <= j <= nums[i]` 且 `i + j < n`。

請回傳抵達下標 `n - 1` 最少需要跳幾次。測資保證一定能抵達下標 `n - 1`。

## 範例

**範例 1：**

```text
輸入：nums = [2,3,1,1,4]
輸出：2
解釋：從下標 0 跳 1 格到下標 1，再從下標 1 跳 3 格到最後一格，總共跳 2 次。
```

**範例 2：**

```text
輸入：nums = [2,3,0,1,4]
輸出：2
解釋：一樣是先跳到下標 1，再直接跳到最後一格。
```

## 提示

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- 保證可以抵達 `nums[n - 1]`。
