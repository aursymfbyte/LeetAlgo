# 300. 最長遞增子序列

- 難度：中等
- 連結：https://leetcode.com/problems/longest-increasing-subsequence/

## 題目

給你一個整數陣列 `nums`，請回傳其中最長「嚴格遞增」子序列的長度。

子序列是從陣列中刪掉一些元素（也可以不刪）後，剩下元素保持原本順序所組成的序列；嚴格遞增代表後一個元素一定要比前一個大，不能相等。

## 範例

**範例 1：**

```text
輸入：nums = [10,9,2,5,3,7,101,18]
輸出：4
解釋：例如 [2,3,7,101] 就是一個長度 4 的嚴格遞增子序列，沒有更長的了。
```

**範例 2：**

```text
輸入：nums = [0,1,0,3,2,3]
輸出：4
解釋：例如 [0,1,2,3]。
```

**範例 3：**

```text
輸入：nums = [7,7,7,7,7,7,7]
輸出：1
解釋：所有元素都一樣，任兩個都不構成嚴格遞增，只能取單一元素。
```

## 提示

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

## 進階

你能想出時間複雜度 `O(n log(n))` 的演算法嗎？
