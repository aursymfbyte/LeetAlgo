# 763. 劃分字母區間

- 難度：中等
- 連結：https://leetcode.com/problems/partition-labels/

## 題目

給你一個字串 `s`，請把它切成盡可能多段，條件是：每一個字母都只能出現在其中一段裡。例如 `"ababcc"` 可以切成 `["abab", "cc"]`；但 `["aba", "bcc"]`（`b` 跨了兩段）或 `["ab", "ab", "cc"]`（`a`、`b` 都跨了兩段）都不合法。

切完之後，把各段依序接起來必須還原成原本的 `s`（也就是只能切開，不能重排）。

請依序回傳每一段的長度。

## 範例

**範例 1：**

```text
輸入：s = "ababcbacadefegdehijhklij"
輸出：[9,7,8]
解釋：切成 "ababcbaca"、"defegde"、"hijhklij" 三段，每個字母都只落在其中一段。
像 "ababcbacadefegde"、"hijhklij" 這樣也合法，但只有兩段，不是最多的切法。
```

**範例 2：**

```text
輸入：s = "eccbbbbdec"
輸出：[10]
解釋：第一個字元 e 和倒數第二個字元 e 把前 9 個字元綁在同一段，最後的 c 又和前面的 c 綁住，所以整串只能當一段。
```

## 提示

- `1 <= s.length <= 500`
- `s` 只包含小寫英文字母。
