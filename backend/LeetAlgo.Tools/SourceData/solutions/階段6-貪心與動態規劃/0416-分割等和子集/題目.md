# 416. 分割等和子集

- 難度：中等
- 連結：https://leetcode.com/problems/partition-equal-subset-sum/

## 題目

給你一個只包含正整數的陣列 `nums`。請判斷能不能把陣列中的所有元素分成兩組（每個元素恰好屬於其中一組），使兩組元素的總和相等。可以的話回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：nums = [1,5,11,5]
輸出：true
解釋：分成 [1, 5, 5] 和 [11]，兩組的和都是 11。
```

**範例 2：**

```text
輸入：nums = [1,2,3,5]
輸出：false
解釋：總和是 11，是奇數，不可能平分成兩組相等的和。
```

## 提示

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`
