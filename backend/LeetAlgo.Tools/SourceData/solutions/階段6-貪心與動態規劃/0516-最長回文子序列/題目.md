# 516. 最長回文子序列

- 難度：中等
- 連結：https://leetcode.com/problems/longest-palindromic-subsequence/

## 題目

給你一個字串 `s`，請找出 `s` 中最長回文子序列，並回傳它的長度。

子序列是從原字串中刪掉一些字元（也可以不刪），剩下字元保持原本順序組成的序列；它不需要是連續的一段。回文是指正著讀和倒著讀一樣。

## 範例

**範例 1：**

```text
輸入：s = "bbbab"
輸出：4
解釋：取出四個 'b' 組成 "bbbb"，就是一個長度 4 的回文子序列。
```

**範例 2：**

```text
輸入：s = "cbbd"
輸出：2
解釋：例如 "bb"。
```

## 提示

- `1 <= s.length <= 1000`
- `s` 只包含英文小寫字母
