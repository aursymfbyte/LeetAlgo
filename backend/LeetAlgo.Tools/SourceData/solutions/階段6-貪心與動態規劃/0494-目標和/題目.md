# 494. 目標和

- 難度：中等
- 連結：https://leetcode.com/problems/target-sum/

## 題目

給你一個整數陣列 `nums` 和一個整數 `target`。

你要在 `nums` 的每個數字前面各放一個符號，`'+'` 或 `'-'`，再把它們依序串起來組成一個運算式。例如 `nums = [2, 1]` 時，可以在 2 前面放 `'+'`、1 前面放 `'-'`，得到運算式 `"+2-1"`。

請回傳有多少種不同的符號放法，使得運算式計算出來的結果剛好等於 `target`。

## 範例

**範例 1：**

```text
輸入：nums = [1,1,1,1,1], target = 3
輸出：5
解釋：五個 1 裡要剛好有一個放負號，負號可以放在任何一個位置，共 5 種：
      -1 + 1 + 1 + 1 + 1 = 3
      +1 - 1 + 1 + 1 + 1 = 3
      +1 + 1 - 1 + 1 + 1 = 3
      +1 + 1 + 1 - 1 + 1 = 3
      +1 + 1 + 1 + 1 - 1 = 3
```

**範例 2：**

```text
輸入：nums = [1], target = 1
輸出：1
```

## 提示

- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 1000`
- `0 <= sum(nums[i]) <= 1000`
- `-1000 <= target <= 1000`
