# 1143. 最長公共子序列

- 難度：中等
- 連結：https://leetcode.com/problems/longest-common-subsequence/

## 題目

給你兩個字串 `text1` 和 `text2`，請回傳它們最長公共子序列的長度；如果沒有任何公共子序列，回傳 `0`。

子序列是指從原字串中刪掉一些字元（也可以一個都不刪），剩下的字元保持原本的先後順序所組成的新字串。例如 `"ace"` 是 `"abcde"` 的子序列。

公共子序列則是同時是兩個字串子序列的字串。

## 範例

**範例 1：**

```text
輸入：text1 = "abcde", text2 = "ace"
輸出：3
解釋：最長公共子序列是 "ace"，長度 3。
```

**範例 2：**

```text
輸入：text1 = "abc", text2 = "abc"
輸出：3
解釋：兩個字串完全相同，最長公共子序列就是 "abc" 本身。
```

**範例 3：**

```text
輸入：text1 = "abc", text2 = "def"
輸出：0
解釋：兩個字串沒有任何共同字元，所以沒有公共子序列。
```

## 提示

- `1 <= text1.length, text2.length <= 1000`
- `text1` 和 `text2` 只包含英文小寫字母
