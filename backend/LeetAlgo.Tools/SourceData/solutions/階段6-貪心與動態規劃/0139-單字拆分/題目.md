# 139. 單字拆分

- 難度：中等
- 連結：https://leetcode.com/problems/word-break/

## 題目

給你一個字串 `s` 和一個字串陣列 `wordDict`（字典）。請判斷能不能把 `s` 切成一段一段，讓每一段都是字典裡的某個單字（切完後用空白隔開，就是由一個或多個字典單字組成的句子）。可以的話回傳 `true`，否則回傳 `false`。

字典裡的同一個單字可以在切分中重複使用任意多次。

## 範例

**範例 1：**

```text
輸入：s = "leetcode", wordDict = ["leet","code"]
輸出：true
解釋："leetcode" 可以切成 "leet" 和 "code" 兩段。
```

**範例 2：**

```text
輸入：s = "applepenapple", wordDict = ["apple","pen"]
輸出：true
解釋：可以切成 "apple"、"pen"、"apple"，其中 "apple" 用了兩次，這是允許的。
```

**範例 3：**

```text
輸入：s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
輸出：false
解釋：不論怎麼切，最後總會剩下無法對應到字典單字的片段。
```

## 提示

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 只包含英文小寫字母
- `wordDict` 中的字串互不相同
