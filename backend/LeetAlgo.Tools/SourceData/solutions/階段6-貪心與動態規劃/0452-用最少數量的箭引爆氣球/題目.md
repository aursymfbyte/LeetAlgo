# 452. 用最少數量的箭引爆氣球

- 難度：中等
- 連結：https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/

## 題目

牆上（可以想成 XY 平面）貼著一些球形氣球。每個氣球用 `points[i] = [x_start, x_end]` 表示，代表它在水平方向上從 `x_start` 延伸到 `x_end`；氣球確切的 y 座標不重要。

你可以從 x 軸上任意位置垂直往上射箭。射在位置 `x` 的箭會一路往上飛，穿過所有滿足 `x_start <= x <= x_end` 的氣球並把它們射爆（剛好碰到端點也算）。箭的數量沒有上限。

請回傳射爆所有氣球最少需要幾支箭。

## 範例

**範例 1：**

```text
輸入：points = [[10,16],[2,8],[1,6],[7,12]]
輸出：2
解釋：一支箭射在 x = 6，可以同時射爆 [2,8] 和 [1,6]；
另一支箭射在 x = 11，可以同時射爆 [10,16] 和 [7,12]。
```

**範例 2：**

```text
輸入：points = [[1,2],[3,4],[5,6],[7,8]]
輸出：4
解釋：四個氣球兩兩沒有交集，每個氣球都需要自己的一支箭。
```

**範例 3：**

```text
輸入：points = [[1,2],[2,3],[3,4],[4,5]]
輸出：2
解釋：射在 x = 2 可以射爆 [1,2] 和 [2,3]；射在 x = 4 可以射爆 [3,4] 和 [4,5]。
```

## 提示

- `1 <= points.length <= 10^5`
- `points[i].length == 2`
- `-2^31 <= x_start < x_end <= 2^31 - 1`
