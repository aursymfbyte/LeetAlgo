# 746. 使用最小花費爬樓梯

- 難度：簡單
- 連結：https://leetcode.com/problems/min-cost-climbing-stairs/

## 題目

給你一個整數陣列 `cost`，`cost[i]` 是踩在第 `i` 階時要付的費用。付完這一階的費用後，你可以往上走 1 階或 2 階。

一開始你可以自由選擇從第 0 階或第 1 階出發（出發的那一階一樣要付費才能往上走）。樓梯頂端是最後一階再往上一格的位置（也就是下標 `cost.length`）。

請回傳到達頂端所需的最小總花費。

## 範例

**範例 1：**

```text
輸入：cost = [10,15,20]
輸出：15
解釋：從第 1 階出發，付 15 後直接往上走 2 階就到頂端，總花費 15。
```

**範例 2：**

```text
輸入：cost = [1,100,1,1,1,100,1,1,100,1]
輸出：6
解釋：從第 0 階出發，依序踩第 0、2、4、6、7、9 階，每階都只付 1，
      避開所有費用 100 的階，最後從第 9 階走 1 階到頂端，總花費 6。
```

## 提示

- `2 <= cost.length <= 1000`
- `0 <= cost[i] <= 999`
