# 435. 無重疊區間

- 難度：中等
- 連結：https://leetcode.com/problems/non-overlapping-intervals/

## 題目

給你一個區間陣列 `intervals`，其中 `intervals[i] = [start_i, end_i]`。請回傳最少要移除幾個區間，才能讓剩下的區間兩兩互不重疊。

注意：只在一個端點相接的區間不算重疊，例如 `[1,2]` 和 `[2,3]` 是不重疊的。

## 範例

**範例 1：**

```text
輸入：intervals = [[1,2],[2,3],[3,4],[1,3]]
輸出：1
解釋：拿掉 [1,3] 之後，[1,2]、[2,3]、[3,4] 彼此都只在端點相接，不重疊。
```

**範例 2：**

```text
輸入：intervals = [[1,2],[1,2],[1,2]]
輸出：2
解釋：三個完全一樣的區間只能留一個，要拿掉兩個。
```

**範例 3：**

```text
輸入：intervals = [[1,2],[2,3]]
輸出：0
解釋：兩個區間本來就不重疊，不用拿掉任何區間。
```

## 提示

- `1 <= intervals.length <= 10^5`
- `intervals[i].length == 2`
- `-5 * 10^4 <= start_i < end_i <= 5 * 10^4`
