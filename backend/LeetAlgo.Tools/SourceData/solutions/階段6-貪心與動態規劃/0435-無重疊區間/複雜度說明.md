### 時間 O(n log n)

n 為區間的個數。

- 第一步按右端點排序。一般排序演算法約需 n × log₂n 次比較，記作 O(n log n)。log₂n 為 n 連續除以 2 直到變成 1 所需的次數，例如 n = 10⁵ 時 log₂n 約為 17，排序約需 170 萬次比較。
- 第二步由頭到尾走訪排好的區間，共 n − 1 次。每次只比較左端點與 `last_end`，必要時更新計數與 `last_end`，皆為固定運算，記作 O(1)，合計 O(n)。
- 兩步合計 O(n log n) + O(n)。n 很大時 n log n 遠大於 n，只保留較大的項，為 **O(n log n)**。

### 空間：Python O(n)，C、C++、C# O(log n)（排序用）

各語言的檔頭寫法不同，差別在排序本身所需的額外空間：

- Python：**O(n)**。Python 內建的 `sort` 採用 Timsort，合併兩段已排序資料時需要暫存空間，最多約 n/2 個元素；另外 `intervals[1:]` 也會複製一份長度 n − 1 的串列。兩者皆與 n 成正比，為 O(n)。
- C、C++、C#：**O(log n)**。`qsort`、`std::sort`、`Array.Sort` 是以快速排序為基礎的原地排序，不需複製整個陣列，但以遞迴切半處理，會使用呼叫堆疊。呼叫堆疊為系統保存尚未完成之函式的返回位置與區域變數的空間；排序每往下切一層即多一層，約切 log n 層，因此為 O(log n)。之後的走訪直接使用下標，只需固定數量的變數。
