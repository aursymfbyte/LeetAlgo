# 5. 最長回文子字串

- 難度：中等
- 連結：https://leetcode.com/problems/longest-palindromic-substring/

## 題目

給你一個字串 `s`，請找出 `s` 裡面最長的回文子字串並回傳它。

回文指的是正著讀和倒著讀完全一樣的字串；子字串必須是 `s` 中連續的一段。如果有好幾個一樣長的最長回文子字串，回傳其中任何一個都可以。

## 範例

**範例 1：**

```text
輸入：s = "babad"
輸出："bab"
解釋："aba" 也一樣長，回傳它也算正確。
```

**範例 2：**

```text
輸入：s = "cbbd"
輸出："bb"
```

## 提示

- `1 <= s.length <= 1000`
- `s` 只包含數字和英文字母
