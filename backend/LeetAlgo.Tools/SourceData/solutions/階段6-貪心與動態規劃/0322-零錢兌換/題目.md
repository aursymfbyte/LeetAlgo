# 322. 零錢兌換

- 難度：中等
- 連結：https://leetcode.com/problems/coin-change/

## 題目

給你一個整數陣列 `coins`，代表幾種不同面額的硬幣，以及一個整數 `amount`，代表要湊出的總金額。每一種面額的硬幣數量都是無限的。

請回傳湊出 `amount` 最少需要幾枚硬幣。如果不管怎麼組合都湊不出 `amount`，回傳 `-1`。

## 範例

**範例 1：**

```text
輸入：coins = [1,2,5], amount = 11
輸出：3
解釋：5 + 5 + 1 = 11，用 3 枚硬幣最少。
```

**範例 2：**

```text
輸入：coins = [2], amount = 3
輸出：-1
解釋：只有面額 2 的硬幣，永遠湊不出奇數金額 3。
```

**範例 3：**

```text
輸入：coins = [1], amount = 0
輸出：0
解釋：金額 0 不需要任何硬幣。
```

## 提示

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`
