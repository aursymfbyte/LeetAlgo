# 72. 編輯距離

- 難度：中等
- 連結：https://leetcode.com/problems/edit-distance/

## 題目

給你兩個字串 `word1` 和 `word2`，請計算把 `word1` 變成 `word2` 最少需要幾次操作，並回傳這個次數。

每一次操作只能是下面三種之一：

- 插入一個字元
- 刪除一個字元
- 把一個字元替換成另一個字元

## 範例

**範例 1：**

```text
輸入：word1 = "horse", word2 = "ros"
輸出：3
解釋：一種三步的做法：
      horse -> rorse（把 'h' 換成 'r'）
      rorse -> rose（刪掉一個 'r'）
      rose -> ros（刪掉 'e'）
```

**範例 2：**

```text
輸入：word1 = "intention", word2 = "execution"
輸出：5
解釋：一種五步的做法：
      intention -> inention（刪掉 't'）
      inention -> enention（把 'i' 換成 'e'）
      enention -> exention（把 'n' 換成 'x'）
      exention -> exection（把 'n' 換成 'c'）
      exection -> execution（插入 'u'）
```

## 提示

- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 只包含英文小寫字母
