# 134. 加油站

- 難度：中等
- 連結：https://leetcode.com/problems/gas-station/

## 題目

一條環狀的路線上有 `n` 個加油站，第 `i` 站可以加 `gas[i]` 單位的油。你有一台油箱容量無限大的車，從第 `i` 站開到下一站（第 `i + 1` 站，最後一站的下一站是第 `0` 站）要花 `cost[i]` 單位的油。出發時油箱是空的，你可以選任何一站當起點。

給你兩個整數陣列 `gas` 和 `cost`，如果能從某一站出發、順時針繞一整圈回到起點，就回傳那個起點的下標；不管從哪裡出發都做不到，就回傳 `-1`。測資保證如果有解，解是唯一的。

## 範例

**範例 1：**

```text
輸入：gas = [1,2,3,4,5], cost = [3,4,5,1,2]
輸出：3
解釋：從第 3 站出發，加 4 單位油，油箱有 4。
開到第 4 站：4 - 1 + 5 = 8。
開到第 0 站：8 - 2 + 1 = 7。
開到第 1 站：7 - 3 + 2 = 6。
開到第 2 站：6 - 4 + 3 = 5。
開回第 3 站要花 5，油剛好夠，所以答案是 3。
```

**範例 2：**

```text
輸入：gas = [2,3,4], cost = [3,4,3]
輸出：-1
解釋：從第 0 站或第 1 站出發，第一段路就沒油了。
從第 2 站出發：加 4 單位油，開到第 0 站剩 4 - 3 + 2 = 3，開到第 1 站剩 3 - 3 + 3 = 3，
但開回第 2 站需要 4，油不夠。所以從哪裡出發都繞不完一圈。
```

## 提示

- `n == gas.length == cost.length`
- `1 <= n <= 10^5`
- `0 <= gas[i], cost[i] <= 10^4`
- 測資保證答案唯一。
