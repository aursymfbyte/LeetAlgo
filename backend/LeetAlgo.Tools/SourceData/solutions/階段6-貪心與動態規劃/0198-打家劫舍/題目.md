# 198. 打家劫舍

- 難度：中等
- 連結：https://leetcode.com/problems/house-robber/

## 題目

一條街上有一排房子，整數陣列 `nums` 中的 `nums[i]` 代表第 `i` 間房子裡藏的錢。

你打算在今晚偷這些房子，但相鄰的兩間房子裝有連動的警報系統：只要同一晚有兩間相鄰的房子都被闖入，就會自動報警。

在不觸發警報（也就是不能偷任何兩間相鄰房子）的前提下，請回傳今晚最多能偷到多少錢。

## 範例

**範例 1：**

```text
輸入：nums = [1,2,3,1]
輸出：4
解釋：偷第 1 間（1 元）和第 3 間（3 元），兩間不相鄰，總共 1 + 3 = 4。
```

**範例 2：**

```text
輸入：nums = [2,7,9,3,1]
輸出：12
解釋：偷第 1、3、5 間，分別是 2、9、1 元，總共 2 + 9 + 1 = 12。
```

## 提示

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`
