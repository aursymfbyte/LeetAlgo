# 146. LRU 快取

- 難度：中等
- 連結：https://leetcode.com/problems/lru-cache/

## 題目

設計一個符合 LRU（Least Recently Used，最近最少使用）規則的快取。快取容量有限，滿了之後要淘汰「最久沒有被用到」的那筆資料。

實作 `LRUCache` 類別：

- `LRUCache(int capacity)`：建立容量為 `capacity`（正整數）的快取。
- `int get(int key)`：如果 `key` 在快取中，回傳它的值，否則回傳 `-1`。
- `void put(int key, int value)`：如果 `key` 已經存在，就把它的值更新成 `value`；否則把這組鍵值加進快取。如果這次加入讓 key 的數量超過容量，就淘汰最久沒被使用的 key。

`get` 和 `put` 都算是「使用」了該 key。兩個函式的平均時間複雜度都必須是 O(1)。

## 範例

**範例 1：**

```text
輸入：
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]
輸出：
[null, null, null, 1, null, -1, null, -1, 3, 4]
解釋：
建立容量 2 的快取，放入 1=1、2=2。
get(1) 得到 1，這時 1 變成最近用過的，2 是最久沒用的。
放入 3=3 超過容量，淘汰 2，快取剩 {1=1, 3=3}，所以 get(2) 是 -1。
放入 4=4 又超過容量，這時最久沒用的是 1，淘汰 1，快取剩 {3=3, 4=4}。
之後 get(1) 是 -1，get(3) 是 3，get(4) 是 4。
```

## 提示

- `1 <= capacity <= 3000`
- `0 <= key <= 10^4`
- `0 <= value <= 10^5`
- `get` 和 `put` 合計最多呼叫 `2 * 10^5` 次。
