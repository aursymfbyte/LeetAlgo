# 2336. 無限集中的最小數字

- 難度：中等
- 連結：https://leetcode.com/problems/smallest-number-in-infinite-set/

## 題目

有一個集合，一開始包含所有正整數 `1, 2, 3, 4, 5, ...`。請實作 `SmallestInfiniteSet` 類別：

- `SmallestInfiniteSet()`：建立物件，此時集合裡有全部的正整數。
- `int popSmallest()`：把集合中最小的整數拿出來（從集合移除），並回傳它。
- `void addBack(int num)`：如果正整數 `num` 目前不在集合裡，就把它放回集合；已經在集合裡就什麼都不做。

## 範例

**範例 1：**

```text
輸入：
["SmallestInfiniteSet", "addBack", "popSmallest", "popSmallest", "popSmallest", "addBack", "popSmallest", "popSmallest", "popSmallest"]
[[], [2], [], [], [], [1], [], [], []]
輸出：
[null, null, 1, 2, 3, null, 1, 4, 5]
解釋：
addBack(2)：2 本來就在集合裡，不變。
popSmallest()：拿走 1，回傳 1。
popSmallest()：拿走 2，回傳 2。
popSmallest()：拿走 3，回傳 3。
addBack(1)：1 已經被拿走過，現在放回集合。
popSmallest()：最小的是剛放回來的 1，回傳 1。
popSmallest()：接著是 4，回傳 4。
popSmallest()：接著是 5，回傳 5。
```

## 提示

- `1 <= num <= 1000`
- `popSmallest` 和 `addBack` 合計最多被呼叫 `1000` 次
