# 933. 最近的請求次數

- 難度：簡單
- 連結：https://leetcode.com/problems/number-of-recent-calls/

## 題目

實作一個 `RecentCounter` 類別，統計「最近一段時間內」收到了多少次請求：

- `RecentCounter()`：建立計數器，一開始沒有任何請求。
- `int ping(int t)`：在時間 `t`（單位毫秒）收到一次新請求。回傳落在閉區間 `[t - 3000, t]` 內的請求總數，也就是這次新請求，加上所有比它早、但時間差不超過 3000 毫秒的請求。

保證每次呼叫 `ping` 的 `t` 都嚴格大於上一次。

## 範例

**範例 1：**

```text
輸入：
["RecentCounter", "ping", "ping", "ping", "ping"]
[[], [1], [100], [3001], [3002]]
輸出：
[null, 1, 2, 3, 3]
解釋：
ping(1)：請求有 [1]，區間是 [-2999, 1]，只有 1 次，回傳 1。
ping(100)：請求有 [1, 100]，區間是 [-2900, 100]，兩次都算，回傳 2。
ping(3001)：請求有 [1, 100, 3001]，區間是 [1, 3001]，三次都算，回傳 3。
ping(3002)：請求有 [1, 100, 3001, 3002]，區間是 [2, 3002]，時間 1 的那次已經太舊，回傳 3。
```

## 提示

- `1 <= t <= 10^9`
- 每組測資呼叫 `ping` 時的 `t` 都嚴格遞增
- `ping` 最多被呼叫 `10^4` 次
