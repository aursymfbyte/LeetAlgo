設計題，只有一個方法 `ping`。q 為 `ping` 的呼叫次數。C 版的空間寫法不同，於最後另行說明。

### ping：均攤 O(1)

- 每次 `ping` 先將 t 放入佇列尾端，為 O(1)。
- 接著以 while 迴圈從佇列前端移除過舊的請求。單看某一次，可能一次移除許多個，耗時較長。
- 每個請求只會被放入佇列一次、最多被移除一次。呼叫 q 次 `ping`，放入與移除的總次數最多 2q，平均每次 `ping` 約為固定的 2 次。
- 偶爾有一次成本較高、平均每次仍為固定時間的情形，稱為**均攤 O(1)**。

### 空間 O(3000)

- 移除過舊的請求後，佇列中只剩時間落在 [t − 3000, t] 的請求。
- 題目保證 t 為嚴格遞增的整數，因此此範圍內最多只有 3001 個不同的時間，佇列最多 3001 個元素。
- 無論呼叫多少次 `ping`，佇列都不會超過此大小，因此寫成 **O(3000)**，即固定大小。

### C 版

- C 版檔頭標示：均攤每次 O(1)；空間 O(q)，q 為 ping 的呼叫次數。時間的計算與上方相同。
- C 版使用一般陣列 `requests`，移除舊請求時僅將 `head` 往後移，不回收前方位置重複使用。因此每次 `ping` 皆佔用新的一格，呼叫 q 次即佔 q 格。
- 陣列一開始即依題目上限（最多 10⁴ 次呼叫）配置，空間為 **O(q)**。
