# 355. 設計推特

- 難度：中等
- 連結：https://leetcode.com/problems/design-twitter/

## 題目

設計一個簡化版的推特：使用者可以發推文、追蹤或取消追蹤其他使用者，並能看到自己動態消息中最新的 10 則推文。

實作 `Twitter` 類別：

- `Twitter()`：建立推特物件。
- `void postTweet(int userId, int tweetId)`：使用者 `userId` 發一則編號為 `tweetId` 的新推文。每次呼叫的 `tweetId` 都不會重複。
- `List<Integer> getNewsFeed(int userId)`：回傳使用者 `userId` 動態消息中最新的 10 則推文編號（不足 10 則就全部回傳）。動態消息只包含這位使用者自己，以及他目前追蹤的人所發的推文，必須依照發文時間由新到舊排列。
- `void follow(int followerId, int followeeId)`：使用者 `followerId` 開始追蹤使用者 `followeeId`。
- `void unfollow(int followerId, int followeeId)`：使用者 `followerId` 取消追蹤使用者 `followeeId`。

## 範例

**範例 1：**

```text
輸入：
["Twitter", "postTweet", "getNewsFeed", "follow", "postTweet", "getNewsFeed", "unfollow", "getNewsFeed"]
[[], [1, 5], [1], [1, 2], [2, 6], [1], [1, 2], [1]]
輸出：
[null, null, [5], null, null, [6, 5], null, [5]]
解釋：
使用者 1 發了推文 5，他的動態消息是 [5]。
使用者 1 追蹤使用者 2，接著使用者 2 發了推文 6。
這時使用者 1 的動態消息有兩則，6 比 5 晚發，所以排在前面：[6, 5]。
使用者 1 取消追蹤使用者 2 之後，動態消息只剩自己的推文 [5]。
```

## 提示

- `1 <= userId, followerId, followeeId <= 500`
- `0 <= tweetId <= 10^4`
- 所有推文的編號都不相同。
- `postTweet`、`getNewsFeed`、`follow`、`unfollow` 合計最多呼叫 `3 * 10^4` 次。
- 使用者不會追蹤自己。
