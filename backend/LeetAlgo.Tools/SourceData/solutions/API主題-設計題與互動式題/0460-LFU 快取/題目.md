# 460. LFU 快取

- 難度：困難
- 連結：https://leetcode.com/problems/lfu-cache/

## 題目

設計一個 LFU（Least Frequently Used，最不常使用）快取，實作 `LFUCache` 類別：

- `LFUCache(int capacity)`：用容量 `capacity` 建立快取。
- `int get(int key)`：如果 `key` 在快取裡，回傳它的值；否則回傳 `-1`。
- `void put(int key, int value)`：如果 `key` 已經在快取裡，就把它的值改成 `value`；否則插入這組 `(key, value)`。如果插入新 key 時快取已經滿了，要先移除一個「最不常使用」的 key，再插入新的。

每個 key 都有一個使用次數：

- 新 key 第一次被 `put` 進來時，使用次數是 1。
- 之後每次對它呼叫 `get` 或 `put`，使用次數都加 1。
- 要淘汰時，移除使用次數最小的 key；如果有好幾個 key 使用次數一樣小，就移除其中「最久沒被用過」的那一個。

`get` 和 `put` 的平均時間複雜度都必須是 `O(1)`。

## 範例

**範例 1：**

```text
輸入：
["LFUCache", "put", "put", "get", "put", "get", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [3], [4, 4], [1], [3], [4]]
輸出：
[null, null, null, 1, null, -1, 3, null, -1, 3, 4]
解釋：
以下 cnt(x) 表示 key x 的使用次數。
LFUCache(2)：容量為 2。
put(1, 1)：cnt(1) = 1。
put(2, 2)：cnt(2) = 1。
get(1)：回傳 1，cnt(1) 變成 2。
put(3, 3)：快取已滿，cnt(2) = 1 最小，淘汰 key 2；放入 3，cnt(3) = 1。
get(2)：key 2 已被淘汰，回傳 -1。
get(3)：回傳 3，cnt(3) 變成 2。
put(4, 4)：快取已滿，key 1 和 key 3 的使用次數都是 2，其中 key 1 比較久沒被用到，淘汰 key 1；放入 4，cnt(4) = 1。
get(1)：key 1 已被淘汰，回傳 -1。
get(3)：回傳 3，cnt(3) 變成 3。
get(4)：回傳 4，cnt(4) 變成 2。
```

## 提示

- `1 <= capacity <= 10^4`
- `0 <= key <= 10^5`
- `0 <= value <= 10^9`
- `get` 和 `put` 合計最多被呼叫 `2 * 10^5` 次
