設計題，只有建構與 `addCar` 兩個方法。

### 每次操作：O(1)

- 建構時將三種車位的數量存入長度 4 的陣列 `remaining`，固定 4 格，為 O(1)。
- `addCar` 以 `carType` 為下標直接讀取陣列該格：為 0 則回傳 false，否則減一並回傳 true。
- 沒有任何迴圈，也不逐格尋找空車位，只記錄剩餘數量，為 **O(1)**。

直覺寫法：為每個車位各配置一個位置，再從頭尋找空位，最壞需走訪所有車位。題目只詢問能否停車，因此只記錄數量即可。

### 空間 O(1)

- 僅使用一個固定長度 4 的陣列，與車位數量無關。
- 即使大車位有 1000 格，記錄的也只是「1000」這一個數字，而非 1000 個位置。空間為 **O(1)**。
