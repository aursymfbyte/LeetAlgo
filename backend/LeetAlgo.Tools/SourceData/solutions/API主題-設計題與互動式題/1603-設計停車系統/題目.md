# 1603. 設計停車系統

- 難度：簡單
- 連結：https://leetcode.com/problems/design-parking-system/

## 題目

一座停車場有大、中、小三種車位，每種車位的數量在一開始就固定好。請實作 `ParkingSystem` 類別：

- `ParkingSystem(int big, int medium, int small)`：建立停車系統，三個參數分別是大、中、小車位的數量。
- `bool addCar(int carType)`：有一輛車要進場，`carType` 是 1、2、3，分別代表大車、中車、小車。車子只能停進和自己同尺寸的車位。如果該尺寸還有空位，就讓車子停進去並回傳 `true`；沒有空位就回傳 `false`。

## 範例

**範例 1：**

```text
輸入：
["ParkingSystem", "addCar", "addCar", "addCar", "addCar"]
[[1, 1, 0], [1], [2], [3], [1]]
輸出：
[null, true, true, false, false]
解釋：
停車場有 1 個大車位、1 個中車位、0 個小車位。
addCar(1)：大車位還有 1 格，停進去，回傳 true。
addCar(2)：中車位還有 1 格，停進去，回傳 true。
addCar(3)：根本沒有小車位，回傳 false。
addCar(1)：唯一的大車位已經被佔走，回傳 false。
```

## 提示

- `0 <= big, medium, small <= 1000`
- `carType` 只會是 `1`、`2` 或 `3`
- `addCar` 最多被呼叫 `1000` 次
