# 211. 新增與搜尋單字

- 難度：中等
- 連結：https://leetcode.com/problems/design-add-and-search-words-data-structure/

## 題目

設計一個資料結構，可以加入新單字，也可以查詢某個字串是否能和之前加入過的任何一個單字配對。查詢的字串裡可能有萬用字元 `'.'`，一個 `'.'` 可以代表任意一個字母。

實作 `WordDictionary` 類別：

- `WordDictionary()`：建立一個空的資料結構。
- `void addWord(word)`：加入單字 `word`，之後的查詢可以配對到它。
- `bool search(word)`：如果資料結構中有任何單字能和 `word` 配對，回傳 `true`，否則回傳 `false`。配對時 `word` 的每個字元要和單字同位置的字母相同，`'.'` 則可以對上任何字母，而且長度必須一樣。

## 範例

**範例 1：**

```text
輸入：
["WordDictionary","addWord","addWord","addWord","search","search","search","search"]
[[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]
輸出：
[null,null,null,null,false,true,true,true]
解釋：
加入 "bad"、"dad"、"mad" 三個單字。
"pad" 沒有加入過，回傳 false；"bad" 有加入過，回傳 true。
".ad" 的第一個字元可以是任何字母，"bad"、"dad"、"mad" 都對得上，回傳 true。
"b.." 是 b 開頭的三個字母單字，"bad" 對得上，回傳 true。
```

## 提示

- `1 <= word.length <= 25`
- `addWord` 的 `word` 只包含小寫英文字母。
- `search` 的 `word` 只包含 `'.'` 或小寫英文字母。
- 每次 `search` 的 `word` 最多有 `2` 個 `'.'`。
- `addWord` 和 `search` 合計最多呼叫 `10^4` 次。
