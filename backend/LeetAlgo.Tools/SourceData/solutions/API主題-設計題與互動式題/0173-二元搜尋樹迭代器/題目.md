# 173. 二元搜尋樹迭代器

- 難度：中等
- 連結：https://leetcode.com/problems/binary-search-tree-iterator/

## 題目

給你一棵二元搜尋樹（BST）的根節點，請實作一個迭代器，能照中序遍歷的順序（也就是由小到大）逐一取出節點的值。

實作 `BSTIterator` 類別：

- `BSTIterator(TreeNode root)`：用 BST 的根節點建立迭代器。可以想像有一個指標，一開始指在「比樹中所有值都還小、實際上不存在的位置」。
- `boolean hasNext()`：如果指標右邊（中序順序的下一個）還有數字，回傳 `true`，否則回傳 `false`。
- `int next()`：把指標往右移一格，並回傳那個位置的數字。

因為指標一開始在最小值的左邊，所以第一次呼叫 `next()` 會拿到樹中最小的值。題目保證每次呼叫 `next()` 時一定還有下一個數字。

## 範例

**範例 1：**

```text
樹的結構（層序 [7,3,15,null,null,9,20]）：
      7
     / \
    3   15
       /  \
      9    20

輸入：
["BSTIterator", "next", "next", "hasNext", "next", "hasNext", "next", "hasNext", "next", "hasNext"]
[[[7, 3, 15, null, null, 9, 20]], [], [], [], [], [], [], [], [], []]
輸出：
[null, 3, 7, true, 9, true, 15, true, 20, false]
解釋：
中序順序是 3、7、9、15、20。
依序呼叫 next() 會拿到 3、7、9、15、20；拿完 20 之後 hasNext() 才變成 false，在那之前都是 true。
```

## 提示

- 樹的節點數目在範圍 `[1, 10^5]` 內。
- `0 <= Node.val <= 10^6`
- `hasNext` 和 `next` 合計最多呼叫 `10^5` 次。

## 進階

你能不能讓 `next()` 和 `hasNext()` 的平均時間複雜度是 O(1)，並且只使用 O(h) 的記憶體？其中 h 是樹的高度。
