設計題依方法分別計算單次呼叫的成本。n 為樹的節點數，h 為樹高（從根到最深葉節點經過的層數）。

### next：均攤 O(1)

- `next` 彈出堆疊頂端，再呼叫 `push_left` 將右子樹沿左側路徑的節點全部推入堆疊。
- 單看某一次，`push_left` 可能推入多個節點，最多 h 個，因此個別的 `next` 可能較慢。
- 從整趟走訪來看：每個節點只會被推入一次、彈出一次。n 次 `next` 的推入與彈出總次數為 2n，平均每次 `next` 約為固定的 2 次。
- 偶爾有一次成本較高、平均每次仍為固定時間的情形，稱為**均攤 O(1)**。

### hasNext：O(1)

- 僅檢查堆疊是否為空，一步完成，為 **O(1)**。

### 空間 O(h)

- 額外記憶體僅有堆疊 `stack`。
- 堆疊中存放的始終是「某條往左延伸的路徑」上尚未處理的節點，這些節點位於同一條由上往下的路徑，最多 h 個，空間為 **O(h)**。
- h 取決於樹的形狀：較平衡的樹 h 約為 log₂n（log₂n 為 n 連續除以 2 直到變成 1 所需的次數）；樹退化成一條鏈時 h 等於 n。

直覺寫法：一開始就將整棵樹中序走訪並存入陣列，`next` 同樣為 O(1)，但需 O(n) 空間。以堆疊僅保存一條路徑，空間由 O(n) 降為 O(h)。
