# 622. 設計循環佇列

- 難度：中等
- 連結：https://leetcode.com/problems/design-circular-queue/

## 題目

請自己實作一個「循環佇列」（環狀緩衝區）。它和一般佇列一樣是先進先出，但儲存空間的最後一格會接回第一格，形成一個環，所以前面已經被取走的空位可以重新拿來放新元素。不能使用程式語言內建的佇列結構。

實作 `MyCircularQueue` 類別：

- `MyCircularQueue(k)`：建立一個最多能放 `k` 個元素的循環佇列。
- `boolean enQueue(int value)`：把 `value` 放到佇列尾端。成功放入回傳 `true`；佇列已滿則回傳 `false`。
- `boolean deQueue()`：移除佇列最前面的元素。成功移除回傳 `true`；佇列是空的則回傳 `false`。
- `int Front()`：回傳最前面的元素；佇列是空的就回傳 `-1`。
- `int Rear()`：回傳最後面的元素；佇列是空的就回傳 `-1`。
- `boolean isEmpty()`：佇列是否為空。
- `boolean isFull()`：佇列是否已滿。

## 範例

**範例 1：**

```text
輸入：
["MyCircularQueue", "enQueue", "enQueue", "enQueue", "enQueue", "Rear", "isFull", "deQueue", "enQueue", "Rear"]
[[3], [1], [2], [3], [4], [], [], [], [4], []]
輸出：
[null, true, true, true, false, 3, true, true, true, 4]
解釋：
建立容量為 3 的佇列。
依序放入 1、2、3 都成功；再放 4 時已經滿了，回傳 false。
此時尾端是 3，佇列是滿的。
取走最前面的 1 之後空出一格，再放入 4 就成功了，尾端變成 4。
```

## 提示

- `1 <= k <= 1000`
- `0 <= value <= 1000`
- `enQueue`、`deQueue`、`Front`、`Rear`、`isEmpty`、`isFull` 合計最多呼叫 `3000` 次。
