設計題依方法分別計算單次呼叫的成本。n 為目前已加入的數字個數。

### addNum：O(log n)

- 堆積（heap）為排成完全二元樹的結構，最大堆的頂端恆為最大值，最小堆的頂端恆為最小值。
- 放入一個數或彈出頂端時，只需沿樹上一條由上到下（或由下到上）的路徑調整位置。n 個元素的完全二元樹高度約為 log₂n 層（log₂n 為 n 連續除以 2 直到變成 1 所需的次數），因此每次放入或彈出為 O(log n)。
- `addNum` 最多做 5 次堆積操作：放入 `lower`、從 `lower` 彈出、放入 `upper`，必要時再從 `upper` 彈出、放回 `lower`。兩個堆各自最多約 n/2 個元素。
- 固定次數 × O(log n)，為 **O(log n)**。

### findMedian：O(1)

- 中位數只需讀取兩個堆的頂端（`lower[0]` 與 `upper[0]`），即陣列第一格，不必調整堆積。
- 為 **O(1)**。

直覺寫法：將所有數存在陣列中，每次求中位數時先排序，需 O(n log n)。改用兩個堆，將整理順序的工作分攤到每次加入時，每次僅需 O(log n)。

### 空間 O(n)

- 每個加入的數都留在 `lower` 或 `upper` 其中一個堆中，不會被移除。
- 兩個堆合計恰好存放 n 個數，空間為 **O(n)**。
