# 295. 資料流的中位數

- 難度：困難
- 連結：https://leetcode.com/problems/find-median-from-data-stream/

## 題目

中位數是一串排好序的整數中，位在正中間的那個值。如果個數是偶數，沒有單一的正中間值，中位數就取中間兩個數的平均。例如 `[2,3,4]` 的中位數是 `3`；`[2,3]` 的中位數是 `(2 + 3) / 2 = 2.5`。

整數會一個一個送進來，請實作 `MedianFinder` 類別，隨時都能回答目前的中位數：

- `MedianFinder()`：建立物件。
- `void addNum(int num)`：把資料流中的整數 `num` 加進資料結構。
- `double findMedian()`：回傳目前所有已加入元素的中位數。和正確答案相差在 `10^-5` 以內都算對。

## 範例

**範例 1：**

```text
輸入：
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
輸出：
[null, null, null, 1.5, null, 2.0]
解釋：
addNum(1)、addNum(2) 之後資料是 [1, 2]。
findMedian()：偶數個，取 (1 + 2) / 2 = 1.5。
addNum(3) 之後資料是 [1, 2, 3]。
findMedian()：奇數個，正中間是 2，回傳 2.0。
```

## 提示

- `-10^5 <= num <= 10^5`
- 呼叫 `findMedian` 之前，資料結構裡至少會有一個元素
- `addNum` 和 `findMedian` 合計最多被呼叫 `5 * 10^4` 次

## 進階

- 如果資料流中的所有整數都落在 `[0, 100]`，可以怎麼最佳化？
- 如果資料流中有 99% 的整數落在 `[0, 100]`，又可以怎麼最佳化？
