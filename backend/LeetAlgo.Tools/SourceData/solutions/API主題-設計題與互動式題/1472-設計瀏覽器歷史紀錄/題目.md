# 1472. 設計瀏覽器歷史紀錄

- 難度：中等
- 連結：https://leetcode.com/problems/design-browser-history/

## 題目

模擬一個只有單一分頁的瀏覽器：一開始停在首頁，之後可以前往新網址，也可以在瀏覽紀錄裡往回或往前跳若干步。

實作 `BrowserHistory` 類別：

- `BrowserHistory(string homepage)`：以 `homepage` 作為首頁建立瀏覽器，目前就在首頁。
- `void visit(string url)`：從目前頁面前往 `url`。這會清掉目前頁面之後所有「往前」的紀錄。
- `string back(int steps)`：往回走 `steps` 步。如果實際上最多只能往回走 `x` 步而 `steps > x`，就只走 `x` 步。回傳移動後所在的網址。
- `string forward(int steps)`：往前走 `steps` 步。如果最多只能往前走 `x` 步而 `steps > x`，就只走 `x` 步。回傳移動後所在的網址。

## 範例

**範例 1：**

```text
輸入：
["BrowserHistory","visit","visit","visit","back","back","forward","visit","forward","back","back"]
[["leetcode.com"],["google.com"],["facebook.com"],["youtube.com"],[1],[1],[1],["linkedin.com"],[2],[2],[7]]
輸出：
[null,null,null,null,"facebook.com","google.com","facebook.com",null,"linkedin.com","google.com","leetcode.com"]
解釋：
首頁是 leetcode.com，接著依序造訪 google.com、facebook.com、youtube.com。
往回 1 步到 facebook.com，再往回 1 步到 google.com，往前 1 步回到 facebook.com。
在 facebook.com 造訪 linkedin.com，原本後面的 youtube.com 紀錄被清掉。
此時往前 2 步，但已經沒有往前的紀錄，所以停在 linkedin.com。
往回 2 步經過 facebook.com 到 google.com。
再往回 7 步，但最多只能退 1 步，停在 leetcode.com。
```

## 提示

- `1 <= homepage.length <= 20`
- `1 <= url.length <= 20`
- `1 <= steps <= 100`
- `homepage` 和 `url` 只包含 `'.'` 和小寫英文字母。
- `visit`、`back`、`forward` 合計最多呼叫 `5000` 次。
