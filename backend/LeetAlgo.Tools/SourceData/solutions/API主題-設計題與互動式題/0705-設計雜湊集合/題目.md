# 705. 設計雜湊集合

- 難度：簡單
- 連結：https://leetcode.com/problems/design-hashset/

## 題目

不使用任何語言內建的雜湊表函式庫，自己做出一個雜湊集合 `MyHashSet`：

- `void add(key)`：把 `key` 放進集合。已經在集合裡就不用重複放。
- `bool contains(key)`：回傳 `key` 目前是否在集合裡。
- `void remove(key)`：把 `key` 從集合移除；如果 `key` 本來就不在集合裡，什麼都不做。

## 範例

**範例 1：**

```text
輸入：
["MyHashSet", "add", "add", "contains", "contains", "add", "contains", "remove", "contains"]
[[], [1], [2], [1], [3], [2], [2], [2], [2]]
輸出：
[null, null, null, true, false, null, true, null, false]
解釋：
add(1)、add(2) 之後集合是 {1, 2}。
contains(1)：1 在集合裡，回傳 true。
contains(3)：3 不在集合裡，回傳 false。
add(2)：2 已經存在，集合不變，仍是 {1, 2}。
contains(2)：回傳 true。
remove(2)：集合變成 {1}。
contains(2)：2 已被移除，回傳 false。
```

## 提示

- `0 <= key <= 10^6`
- `add`、`remove`、`contains` 合計最多被呼叫 `10^4` 次
