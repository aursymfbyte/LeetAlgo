# 470. 用 Rand7() 實作 Rand10()

- 難度：中等
- 連結：https://leetcode.com/problems/implement-rand10-using-rand7/

## 題目

題目已經提供一個 API `rand7()`，每次呼叫會均勻隨機回傳 `1` 到 `7` 之間的一個整數。請只靠 `rand7()`，寫出函式 `rand10()`，讓它均勻隨機回傳 `1` 到 `10` 之間的一個整數。

不可以呼叫 `rand7()` 以外的任何 API，也不能使用程式語言內建的亂數函式。

各語言呼叫 `rand7()` 的方式：

- Python、C、C++：直接呼叫全域函式 `rand7()`。
- C#：`Solution` 繼承自 `SolBase`，呼叫父類別的 `Rand7()`。

每組測資有一個內部參數 `n`，代表評測時會呼叫你的 `rand10()` 幾次；`n` 不會當作參數傳給 `rand10()`。評測系統會檢查回傳值的分布是否均勻。

## 範例

**範例 1：**

```text
輸入：n = 1
輸出：[2]
解釋：呼叫 rand10() 一次，這次剛好得到 2（結果是隨機的，任何 1 到 10 的值都有可能）。
```

**範例 2：**

```text
輸入：n = 2
輸出：[2,8]
解釋：呼叫兩次，得到 2 和 8。
```

**範例 3：**

```text
輸入：n = 3
輸出：[3,8,10]
解釋：呼叫三次，得到 3、8、10。
```

## 提示

- `1 <= n <= 10^5`

## 進階
