# 208. 實作 Trie（前綴樹）

- 難度：中等
- 連結：https://leetcode.com/problems/implement-trie-prefix-tree/

## 題目

Trie（讀音同 "try"），又叫前綴樹或字典樹，是一種樹狀資料結構，專門用來快速存放和查詢一堆字串，常見用途有自動完成、拼字檢查等。

實作 `Trie` 類別：

- `Trie()`：建立一棵空的前綴樹。
- `void insert(String word)`：把字串 `word` 加進前綴樹。
- `boolean search(String word)`：如果 `word` 曾經被完整地插入過，回傳 `true`，否則回傳 `false`。
- `boolean startsWith(String prefix)`：如果已插入的字串中，有任何一個是以 `prefix` 開頭，回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
輸出：
[null, null, true, false, true, null, true]
解釋：
插入 "apple" 之後，搜尋 "apple" 找得到；搜尋 "app" 找不到，因為 "app" 本身沒有被插入過，
但 "apple" 是以 "app" 開頭，所以 startsWith("app") 是 true。
接著插入 "app"，再搜尋 "app" 就找得到了。
```

## 提示

- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 只包含小寫英文字母。
- `insert`、`search`、`startsWith` 合計最多呼叫 `3 * 10^4` 次。
