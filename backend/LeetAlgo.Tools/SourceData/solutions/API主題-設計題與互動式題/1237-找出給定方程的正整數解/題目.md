# 1237. 找出給定方程的正整數解

- 難度：中等
- 連結：https://leetcode.com/problems/find-positive-integer-solution-for-a-given-equation/

## 題目

給你一個公式未知的函式 `f(x, y)` 和一個目標值 `z`，請找出所有滿足 `f(x, y) == z` 的正整數對 `[x, y]`，回傳順序不限。

雖然看不到公式，但保證這個函式對兩個參數都是嚴格遞增的：

- `f(x, y) < f(x + 1, y)`
- `f(x, y) < f(x, y + 1)`

你只能透過題目給的介面呼叫函式（各語言的寫法）：

- Python：`customfunction.f(x, y)`
- C#：`customfunction.f(x, y)`
- C++：`customfunction.f(x, y)`
- C：函式指標 `customFunction(x, y)`

評測方式：評測系統內部有 9 種不同公式的 `CustomFunction`，輸入是 `function_id`（決定用哪一種公式）和目標值 `z`。它會呼叫你的 `findSolution`，再把你的結果和標準答案中所有合法的數對比對，完全相符才算通過。

## 範例

**範例 1：**

```text
輸入：function_id = 1, z = 5
輸出：[[1,4],[2,3],[3,2],[4,1]]
解釋：function_id = 1 的公式是 f(x, y) = x + y。
加起來等於 5 的正整數對有 (1, 4)、(2, 3)、(3, 2)、(4, 1) 四組。
```

**範例 2：**

```text
輸入：function_id = 2, z = 5
輸出：[[1,5],[5,1]]
解釋：function_id = 2 的公式是 f(x, y) = x * y。
乘積等於 5 的正整數對只有 (1, 5) 和 (5, 1)。
```

## 提示

- `1 <= function_id <= 9`
- `1 <= z <= 100`
- 保證所有 `f(x, y) == z` 的解都落在 `1 <= x, y <= 1000` 範圍內
- 保證當 `1 <= x, y <= 1000` 時，`f(x, y)` 的值不會超出 32 位元有號整數範圍
