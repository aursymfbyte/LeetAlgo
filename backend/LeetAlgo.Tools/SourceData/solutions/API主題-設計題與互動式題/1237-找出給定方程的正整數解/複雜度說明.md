互動式題目，函式 f 的內容不可見，只能透過 `customfunction.f(x, y)` 呼叫，因此時間主要取決於呼叫 f 的次數。題目規定 x 與 y 皆介於 1 到 1000。

### 時間 O(2000)

- while 迴圈每一輪呼叫一次 `f`，並至少做一件事：x 加一，或 y 減一（相等時兩者皆做）。
- x 從 1 開始，最多加到 1000；y 從 1000 開始，最多減到 1。因此 x 最多變動 1000 次，y 最多變動 1000 次。
- 每一輪至少變動一次，迴圈最多 1000 + 1000 = 2000 輪，即最多呼叫 2000 次 `f`。每輪除呼叫 f 外只做固定步數。
- 時間為 **O(2000)**，為與輸入無關的固定上限。

暴力解：嘗試所有 (x, y) 組合，需 1000 × 1000 = 100 萬次呼叫 f。雙指針利用「f 對 x、y 皆遞增」的性質，每一步排除一整列或一整行，最多僅需 2000 次。

### 空間 O(1)（不計答案）

- 程式本身僅使用 `x`、`y`、`value` 幾個變數，大小固定。
- 答案清單 `answer` 為題目要求的回傳結果，任何方法都必須產生，不計入額外空間。
- 額外空間為 **O(1)**。
