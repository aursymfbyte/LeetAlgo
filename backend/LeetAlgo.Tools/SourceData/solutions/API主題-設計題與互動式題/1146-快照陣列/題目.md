# 1146. 快照陣列

- 難度：中等
- 連結：https://leetcode.com/problems/snapshot-array/

## 題目

實作一個支援「拍快照」的陣列 `SnapshotArray`，可以在任意時刻記下整個陣列的狀態，之後再查詢某次快照當下某個位置的值。

- `SnapshotArray(int length)`：建立一個長度為 `length` 的陣列，一開始每個元素都是 `0`。
- `void set(index, val)`：把下標 `index` 的元素設成 `val`。
- `int snap()`：拍一次快照，回傳這次快照的編號 `snap_id`，也就是到目前為止呼叫 `snap()` 的總次數減 1（第一次是 0）。
- `int get(index, snap_id)`：回傳編號 `snap_id` 的那次快照拍下時，下標 `index` 的值。

## 範例

**範例 1：**

```text
輸入：["SnapshotArray","set","snap","set","get"]
[[3],[0,5],[],[0,6],[0,0]]
輸出：[null,null,0,null,5]
解釋：
建立長度 3 的陣列，內容是 [0,0,0]。
把下標 0 設成 5，接著拍快照，得到編號 0。
之後再把下標 0 改成 6，但這是快照之後的修改。
查詢編號 0 的快照中下標 0 的值，是拍照當時的 5。
```

## 提示

- `1 <= length <= 5 * 10^4`
- `0 <= index < length`
- `0 <= val <= 10^9`
- `0 <= snap_id <` 呼叫 `snap()` 的總次數
- `set`、`snap`、`get` 合計最多呼叫 `5 * 10^4` 次。
