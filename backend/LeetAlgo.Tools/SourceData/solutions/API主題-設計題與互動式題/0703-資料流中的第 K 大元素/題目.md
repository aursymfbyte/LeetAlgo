# 703. 資料流中的第 K 大元素

- 難度：簡單
- 連結：https://leetcode.com/problems/kth-largest-element-in-a-stream/

## 題目

分數會一筆一筆不斷送進來，你要隨時回報「目前所有分數中第 `k` 大的是多少」。這裡的第 `k` 大是指把所有分數由大到小排好後的第 `k` 個（重複的數字分開算）。

請實作 `KthLargest` 類別：

- `KthLargest(int k, int[] nums)`：用整數 `k` 和一開始已有的分數 `nums` 建立物件。
- `int add(int val)`：新增一筆分數 `val`，然後回傳目前所有分數中的第 `k` 大。

## 範例

**範例 1：**

```text
輸入：
["KthLargest", "add", "add", "add", "add", "add"]
[[3, [4, 5, 8, 2]], [3], [5], [10], [9], [4]]
輸出：
[null, 4, 5, 5, 8, 8]
解釋：
k = 3，一開始分數是 [4, 5, 8, 2]。
add(3)：分數由大到小是 8, 5, 4, 3, 2，第 3 大是 4。
add(5)：8, 5, 5, 4, 3, 2，第 3 大是 5。
add(10)：10, 8, 5, 5, ...，第 3 大是 5。
add(9)：10, 9, 8, 5, ...，第 3 大是 8。
add(4)：最大的三個仍是 10, 9, 8，第 3 大是 8。
```

**範例 2：**

```text
輸入：
["KthLargest", "add", "add", "add", "add"]
[[4, [7, 7, 7, 7, 8, 3]], [2], [10], [9], [9]]
輸出：
[null, 7, 7, 7, 8]
解釋：
k = 4，一開始分數是 [7, 7, 7, 7, 8, 3]。
add(2)：由大到小是 8, 7, 7, 7, 7, ...，第 4 大是 7。
add(10)：10, 8, 7, 7, 7, ...，第 4 大是 7。
add(9)：10, 9, 8, 7, 7, ...，第 4 大是 7。
add(9)：10, 9, 9, 8, 7, ...，第 4 大是 8。
```

## 提示

- `0 <= nums.length <= 10^4`
- `1 <= k <= nums.length + 1`
- `-10^4 <= nums[i] <= 10^4`
- `-10^4 <= val <= 10^4`
- `add` 最多被呼叫 `10^4` 次
