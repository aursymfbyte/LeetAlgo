# 380. O(1) 時間插入、刪除和取得隨機元素

- 難度：中等
- 連結：https://leetcode.com/problems/insert-delete-getrandom-o1/

## 題目

實作一個整數集合 `RandomizedSet`，支援插入、刪除和隨機取出一個元素，而且每個操作的平均時間複雜度都必須是 O(1)。

- `RandomizedSet()`：建立一個空集合。
- `bool insert(int val)`：如果 `val` 不在集合中，就把它加進去並回傳 `true`；如果已經在了，回傳 `false`。
- `bool remove(int val)`：如果 `val` 在集合中，就把它移除並回傳 `true`；如果不在，回傳 `false`。
- `int getRandom()`：從目前集合中隨機回傳一個元素，每個元素被選到的機率都要相同。呼叫時保證集合裡至少有一個元素。

## 範例

**範例 1：**

```text
輸入：
["RandomizedSet", "insert", "remove", "insert", "getRandom", "remove", "insert", "getRandom"]
[[], [1], [2], [2], [], [1], [2], []]
輸出：
[null, true, false, true, 2, true, false, 2]
解釋：
插入 1 成功；移除 2 失敗，因為 2 還不在集合裡；插入 2 成功，集合變成 {1, 2}。
這時 getRandom() 應該以相同機率回傳 1 或 2（範例輸出寫 2 只是其中一種可能）。
移除 1 成功，集合剩下 {2}；再插入 2 失敗，因為它已經在集合裡。
集合只剩 2，所以 getRandom() 一定回傳 2。
```

## 提示

- `-2^31 <= val <= 2^31 - 1`
- `insert`、`remove`、`getRandom` 合計最多呼叫 `2 * 10^5` 次。
- 呼叫 `getRandom` 時，資料結構中至少有一個元素。
