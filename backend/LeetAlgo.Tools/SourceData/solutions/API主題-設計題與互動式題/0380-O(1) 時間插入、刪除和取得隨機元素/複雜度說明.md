設計題依方法分別計算單次呼叫的成本。n 為目前集合中的元素個數。

### insert：平均 O(1)

- 先查詢雜湊表 `index_of` 是否已有此值，再存入其下標，最後將值附加到陣列 `values` 尾端。
- 雜湊表的查詢與存入多數情況下只需固定步數；僅在大量值擠在同一格時才會變慢，此情形很少發生。一般情況為固定時間，稱為**平均 O(1)**。
- 附加到陣列尾端亦為固定時間（陣列偶爾需擴大，平均每次仍為固定時間）。
- 為 **平均 O(1)**。

### remove：平均 O(1)

- 從陣列中間刪除一個元素，一般需將後方元素全部往前挪，最壞為 O(n)。
- 此寫法將陣列最後一個元素搬到被刪除的位置，再刪除陣列尾端，只動兩格，不需挪動。
- 其餘步驟為雜湊表的查詢、更新、刪除，平均各為 O(1)。
- 為 **平均 O(1)**。

### getRandom：O(1)

- 隨機選取 0 到 n − 1 的下標，再直接讀取陣列該格，皆一步完成，為 **O(1)**。
- 此即必須使用陣列的原因：雜湊表無法直接取得第 i 個元素，陣列可以。

### 空間 O(n)

- 陣列 `values` 存 n 個值，雜湊表 `index_of` 存 n 筆「值 → 下標」。
- 兩者皆為 n 筆，空間為 **O(n)**。
