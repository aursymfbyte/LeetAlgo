# 2296. 設計文字編輯器

- 難度：困難
- 連結：https://leetcode.com/problems/design-a-text-editor/

## 題目

設計一個帶有游標的簡單文字編輯器，支援：在游標處打字、刪除游標左邊的字（像按退格鍵）、把游標往左或往右移。

游標永遠停在文字範圍內，不能移出去，也就是 `0 <= 游標位置 <= 目前文字長度` 隨時成立。刪除時只會刪到游標左邊的字元。

請實作 `TextEditor` 類別：

- `TextEditor()`：建立一個內容為空的編輯器。
- `void addText(string text)`：在游標處插入 `text`，插入後游標停在 `text` 的右邊。
- `int deleteText(int k)`：刪除游標左邊的 `k` 個字元（左邊不足 `k` 個就全部刪掉），回傳實際刪掉了幾個字元。
- `string cursorLeft(int k)`：把游標往左移 `k` 次（到最左邊就停住）。回傳游標左邊最後 `min(10, len)` 個字元，`len` 是游標左邊的字元數。
- `string cursorRight(int k)`：把游標往右移 `k` 次（到最右邊就停住）。回傳值的定義和 `cursorLeft` 相同。

## 範例

**範例 1：**

```text
輸入：
["TextEditor", "addText", "deleteText", "addText", "cursorRight", "cursorLeft", "deleteText", "cursorLeft", "cursorRight"]
[[], ["leetcode"], [4], ["practice"], [3], [8], [10], [2], [6]]
輸出：
[null, null, 4, null, "etpractice", "leet", 4, "", "practi"]
解釋（用 | 表示游標位置）：
TextEditor()：內容是 "|"。
addText("leetcode")：內容變成 "leetcode|"。
deleteText(4)：刪掉 4 個字元，內容變成 "leet|"，回傳 4。
addText("practice")：內容變成 "leetpractice|"。
cursorRight(3)：游標已在最右邊，移不動；游標左邊最後 10 個字元是 "etpractice"。
cursorLeft(8)：內容變成 "leet|practice"；左邊只有 4 個字元，回傳 "leet"。
deleteText(10)：左邊只有 4 個字元可刪，內容變成 "|practice"，回傳 4。
cursorLeft(2)：游標已在最左邊，移不動；左邊沒有字元，回傳 ""。
cursorRight(6)：內容變成 "practi|ce"；回傳左邊的 "practi"。
```

## 提示

- `1 <= text.length, k <= 40`
- `text` 只包含小寫英文字母
- `addText`、`deleteText`、`cursorLeft`、`cursorRight` 合計最多被呼叫 `2 * 10^4` 次

## 進階

你能做到每次呼叫的時間複雜度都是 `O(k)` 嗎？
