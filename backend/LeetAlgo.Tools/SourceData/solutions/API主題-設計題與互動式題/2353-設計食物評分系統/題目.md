# 2353. 設計食物評分系統

- 難度：中等
- 連結：https://leetcode.com/problems/design-a-food-rating-system/

## 題目

設計一個食物評分系統，需要支援兩件事：修改某道食物的評分，以及查詢某種料理類型中評分最高的食物。

實作 `FoodRatings` 類別：

- `FoodRatings(String[] foods, String[] cuisines, int[] ratings)`：用三個長度都是 `n` 的陣列建立系統。`foods[i]` 是第 `i` 道食物的名稱，`cuisines[i]` 是它所屬的料理類型，`ratings[i]` 是它的初始評分。
- `void changeRating(String food, int newRating)`：把名稱為 `food` 的食物評分改成 `newRating`。
- `String highestRated(String cuisine)`：回傳料理類型 `cuisine` 中評分最高的食物名稱。如果有好幾道並列最高，回傳名稱字典序最小的那一道。

字典序的比較方式和查字典一樣：從第一個字元開始比，第一個不同的字元比較小的那個字串比較小；如果其中一個字串是另一個的前綴，較短的那個比較小。

## 範例

**範例 1：**

```text
輸入：
["FoodRatings", "highestRated", "highestRated", "changeRating", "highestRated", "changeRating", "highestRated"]
[[["kimchi", "miso", "sushi", "moussaka", "ramen", "bulgogi"], ["korean", "japanese", "japanese", "greek", "japanese", "korean"], [9, 12, 8, 15, 14, 7]], ["korean"], ["japanese"], ["sushi", 16], ["japanese"], ["ramen", 16], ["japanese"]]
輸出：
[null, "kimchi", "ramen", null, "sushi", null, "ramen"]
解釋：
韓式料理有 kimchi（9）和 bulgogi（7），最高的是 kimchi。
日式料理有 miso（12）、sushi（8）、ramen（14），最高的是 ramen。
把 sushi 改成 16 後，日式最高變成 sushi。
再把 ramen 也改成 16，sushi 和 ramen 並列 16，字典序較小的是 ramen。
```

## 提示

- `1 <= n <= 2 * 10^4`
- `n == foods.length == cuisines.length == ratings.length`
- `1 <= foods[i].length, cuisines[i].length <= 10`
- `foods[i]`、`cuisines[i]` 只包含小寫英文字母。
- `1 <= ratings[i] <= 10^8`
- `foods` 中的字串都不相同。
- 呼叫 `changeRating` 時，`food` 一定是系統中存在的食物。
- 呼叫 `highestRated` 時，`cuisine` 一定至少有一道食物。
- `changeRating` 和 `highestRated` 合計最多呼叫 `2 * 10^4` 次。
