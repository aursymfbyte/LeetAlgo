# 707. 設計鏈結串列

- 難度：中等
- 連結：https://leetcode.com/problems/design-linked-list/

## 題目

請自己實作一條鏈結串列，可以選擇單向或雙向。單向串列的節點有 `val`（節點的值）和 `next`（指向下一個節點）；如果做成雙向串列，還要多一個 `prev` 指向前一個節點。節點的下標從 0 開始算。不能使用程式語言內建的 LinkedList。

實作 `MyLinkedList` 類別：

- `MyLinkedList()`：建立一條空的串列。
- `int get(int index)`：回傳第 `index` 個節點的值；下標不合法就回傳 `-1`。
- `void addAtHead(int val)`：在串列最前面插入值為 `val` 的節點，插入後它就是新的第一個節點。
- `void addAtTail(int val)`：在串列最後面接上值為 `val` 的節點。
- `void addAtIndex(int index, int val)`：在第 `index` 個節點的前面插入值為 `val` 的節點。如果 `index` 剛好等於串列長度，就接在最後面；如果 `index` 比長度還大，就什麼都不做。
- `void deleteAtIndex(int index)`：如果下標合法，就刪除第 `index` 個節點。

## 範例

**範例 1：**

```text
輸入：
["MyLinkedList", "addAtHead", "addAtTail", "addAtIndex", "get", "deleteAtIndex", "get"]
[[], [1], [3], [1, 2], [1], [1], [1]]
輸出：
[null, null, null, null, 2, null, 3]
解釋：
先在開頭放 1、在結尾放 3，串列是 1 -> 3。
在下標 1 的前面插入 2，串列變成 1 -> 2 -> 3，此時 get(1) 是 2。
刪除下標 1 的節點後串列是 1 -> 3，get(1) 變成 3。
```

## 提示

- `0 <= index, val <= 1000`
- 請不要使用內建的 LinkedList 函式庫。
- `get`、`addAtHead`、`addAtTail`、`addAtIndex`、`deleteAtIndex` 合計最多呼叫 `2000` 次。
