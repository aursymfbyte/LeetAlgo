# 706. 設計雜湊映射

- 難度：簡單
- 連結：https://leetcode.com/problems/design-hashmap/

## 題目

不使用任何語言內建的雜湊表函式庫，自己做出一個雜湊映射 `MyHashMap`（key 對應到 value）：

- `MyHashMap()`：建立一個空的映射。
- `void put(int key, int value)`：存入 `(key, value)`。如果 `key` 已經存在，就把它對應的值改成新的 `value`。
- `int get(int key)`：回傳 `key` 對應的值；`key` 不存在時回傳 `-1`。
- `void remove(key)`：如果 `key` 存在，就把它和對應的值一起刪掉。

## 範例

**範例 1：**

```text
輸入：
["MyHashMap", "put", "put", "get", "get", "put", "get", "remove", "get"]
[[], [1, 1], [2, 2], [1], [3], [2, 1], [2], [2], [2]]
輸出：
[null, null, null, 1, -1, null, 1, null, -1]
解釋：
put(1, 1)、put(2, 2) 之後映射是 {1: 1, 2: 2}。
get(1)：回傳 1。
get(3)：3 不存在，回傳 -1。
put(2, 1)：2 已存在，把值改成 1，映射變成 {1: 1, 2: 1}。
get(2)：回傳 1。
remove(2)：刪掉 2，映射變成 {1: 1}。
get(2)：2 已被刪除，回傳 -1。
```

## 提示

- `0 <= key, value <= 10^6`
- `put`、`get`、`remove` 合計最多被呼叫 `10^4` 次
