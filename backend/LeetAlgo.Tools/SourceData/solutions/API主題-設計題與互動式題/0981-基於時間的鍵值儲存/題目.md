# 981. 基於時間的鍵值儲存

- 難度：中等
- 連結：https://leetcode.com/problems/time-based-key-value-store/

## 題目

設計一個帶時間戳的鍵值儲存結構：同一個 key 可以在不同時間點存入不同的值，查詢時給一個時間點，要找出「那個時間點當下」這個 key 的值。

實作 `TimeMap` 類別：

- `TimeMap()`：建立一個空的資料結構。
- `void set(String key, String value, int timestamp)`：在時間 `timestamp` 把 `key` 的值存成 `value`。
- `String get(String key, int timestamp)`：在所有對 `key` 做過的 `set` 裡，找時間戳 `timestamp_prev <= timestamp` 的那些紀錄，回傳其中時間戳最大那一筆的值。如果一筆都沒有，回傳空字串 `""`。

## 範例

**範例 1：**

```text
輸入：
["TimeMap", "set", "get", "get", "set", "get", "get"]
[[], ["foo", "bar", 1], ["foo", 1], ["foo", 3], ["foo", "bar2", 4], ["foo", 4], ["foo", 5]]
輸出：
[null, null, "bar", "bar", null, "bar2", "bar2"]
解釋：
在時間 1 存入 foo = "bar"。
查詢時間 1 得到 "bar"；查詢時間 3 時，時間 2、3 都沒有紀錄，最接近且不超過 3 的是時間 1，所以還是 "bar"。
在時間 4 存入 foo = "bar2"。
查詢時間 4 得到 "bar2"；查詢時間 5 時最近的紀錄是時間 4，也是 "bar2"。
```

## 提示

- `1 <= key.length, value.length <= 100`
- `key` 和 `value` 只包含小寫英文字母和數字。
- `1 <= timestamp <= 10^7`
- 所有 `set` 呼叫的 `timestamp` 嚴格遞增。
- `set` 和 `get` 合計最多呼叫 `2 * 10^5` 次。
