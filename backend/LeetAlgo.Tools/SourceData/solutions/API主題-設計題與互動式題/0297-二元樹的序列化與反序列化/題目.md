# 297. 二元樹的序列化與反序列化

- 難度：困難
- 連結：https://leetcode.com/problems/serialize-and-deserialize-binary-tree/

## 題目

「序列化」是把一個資料結構轉成一串文字（或位元），方便存檔或透過網路傳送，之後再「反序列化」把它還原回原本的結構。

請實作 `Codec` 類別，提供兩個方法：

- `serialize(root)`：把一棵二元樹轉成一個字串並回傳。
- `deserialize(data)`：讀入 `serialize` 產生的字串，還原出和原本結構、數值完全相同的二元樹，回傳它的根節點。

字串要用什麼格式完全由你決定，只要「先序列化、再反序列化」之後能得到一棵一模一樣的樹即可。評測時會先呼叫 `serialize`，再把結果交給 `deserialize`，最後比對還原出來的樹。

下面範例的輸入輸出沿用 LeetCode 表示二元樹的方式：按層由上到下、由左到右列出節點，`null` 代表空節點；這只是範例的表示法，不代表你的字串必須長這樣。

## 範例

**範例 1：**

```text
輸入：root = [1,2,3,null,null,4,5]
輸出：[1,2,3,null,null,4,5]
解釋：樹的形狀如下：
      1
     / \
    2   3
       / \
      4   5
序列化再反序列化後，要得到同樣的這棵樹。
```

**範例 2：**

```text
輸入：root = []
輸出：[]
解釋：空樹經過序列化和反序列化後，仍然是空樹。
```

## 提示

- 樹中節點數在 `[0, 10^4]` 範圍內
- `-1000 <= Node.val <= 1000`
