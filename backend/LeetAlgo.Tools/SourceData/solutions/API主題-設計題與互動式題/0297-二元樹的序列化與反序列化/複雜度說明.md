兩個方法分別計算。n 為樹的節點數。

### serialize：O(n)

- 前序遍歷會拜訪每個節點一次，也會拜訪每個空位置（空子節點）一次。
- n 個節點的二元樹恰有 n + 1 個空位置，因此共寫出 2n + 1 個記號（節點值或 "#"）。
- 每寫一個記號為固定步數；最後以 `",".join` 串接成字串，耗時與字串長度成正比，亦為 O(n)。
- 總計 **O(n)**。

### deserialize：O(n)

- 先以 `split` 將字串切回 2n + 1 個記號，耗時與字串長度成正比，為 O(n)。
- `build` 每呼叫一次讀取一個記號，每個記號只讀一次：讀到 "#" 直接回傳，讀到數字則建立一個節點。共 2n + 1 次，每次固定步數。
- 總計 **O(n)**。

### 空間 O(n)

- 字串與記號清單 `tokens` 皆有 2n + 1 個記號，為 O(n)。
- 兩個方向皆為遞迴，每往下一層多一層尚未結束的函式呼叫，存放於呼叫堆疊（記錄尚未結束之函式呼叫的記憶體區域）。呼叫堆疊深度等於樹高：平衡的樹約 log₂n 層，樹退化成一條鏈時為 n 層。
- 最壞情況下兩部分皆為 O(n)，空間為 **O(n)**。
- 建出的新樹為題目要求的回傳值，不計入額外空間；即使計入也只有 n 個節點，結論仍為 O(n)。
