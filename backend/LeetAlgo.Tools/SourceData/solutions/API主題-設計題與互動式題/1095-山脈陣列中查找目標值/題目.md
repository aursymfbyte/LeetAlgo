# 1095. 山脈陣列中查找目標值

- 難度：困難
- 連結：https://leetcode.com/problems/find-in-mountain-array/

## 題目

（這是一道互動題。）

一個陣列 `arr` 稱為「山脈陣列」，當且僅當：

- `arr.length >= 3`
- 存在某個下標 `i`（`0 < i < arr.length - 1`），使得
  - `arr[0] < arr[1] < ... < arr[i - 1] < arr[i]`（先嚴格遞增到山頂）
  - `arr[i] > arr[i + 1] > ... > arr[arr.length - 1]`（再嚴格遞減）

給你一個山脈陣列 `mountainArr` 和目標值 `target`，請回傳滿足 `mountainArr.get(index) == target` 的最小下標 `index`；如果 `target` 不在陣列裡，回傳 `-1`。

你不能直接讀取陣列，只能透過 `MountainArray` 介面存取：

- `get(k)`：回傳下標 `k`（從 0 開始）的元素。
- `length()`：回傳陣列長度。

各語言的呼叫方式：Python、C++ 是 `mountainArr.get(k)` / `mountainArr.length()`；C# 是 `mountainArr.Get(k)` / `mountainArr.Length()`；C 是 `get(mountainArr, k)` / `length(mountainArr)`。

呼叫 `get` 超過 100 次會直接判為答案錯誤；任何想繞過評測系統的作法也會被取消資格。

## 範例

**範例 1：**

```text
輸入：mountainArr = [1,2,3,4,5,3,1], target = 3
輸出：2
解釋：3 出現在下標 2 和下標 5，要回傳比較小的 2。
```

**範例 2：**

```text
輸入：mountainArr = [0,1,2,4,2,1], target = 3
輸出：-1
解釋：陣列中沒有 3，回傳 -1。
```

## 提示

- `3 <= mountainArr.length() <= 10^4`
- `0 <= target <= 10^9`
- `0 <= mountainArr.get(index) <= 10^9`
