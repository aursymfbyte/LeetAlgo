# 1396. 設計地鐵系統

- 難度：中等
- 連結：https://leetcode.com/problems/design-underground-system/

## 題目

一個地鐵系統會記錄乘客在各站之間的搭乘時間，並用這些資料計算從某一站到另一站的平均花費時間。

實作 `UndergroundSystem` 類別：

- `void checkIn(int id, string stationName, int t)`：卡號為 `id` 的乘客在時間 `t` 從 `stationName` 站進站。同一位乘客同一時間只會在一個地方進站。
- `void checkOut(int id, string stationName, int t)`：卡號為 `id` 的乘客在時間 `t` 從 `stationName` 站出站。
- `double getAverageTime(string startStation, string endStation)`：回傳從 `startStation` 到 `endStation` 的平均花費時間。
  - 只計算「直接」從 `startStation` 進站、從 `endStation` 出站的那些行程。
  - A 到 B 和 B 到 A 是不同的路線，平均時間可能不一樣。
  - 呼叫時保證至少有一位乘客走過這條路線。

可以假設所有進出站的呼叫都是合理的：乘客在 `t1` 進站、`t2` 出站，一定有 `t1 < t2`，而且所有事件都依時間先後發生。

## 範例

**範例 1：**

```text
輸入：
["UndergroundSystem","checkIn","checkIn","checkIn","checkOut","checkOut","checkOut","getAverageTime","getAverageTime","checkIn","getAverageTime","checkOut","getAverageTime"]
[[],[45,"Leyton",3],[32,"Paradise",8],[27,"Leyton",10],[45,"Waterloo",15],[27,"Waterloo",20],[32,"Cambridge",22],["Paradise","Cambridge"],["Leyton","Waterloo"],[10,"Leyton",24],["Leyton","Waterloo"],[10,"Waterloo",38],["Leyton","Waterloo"]]
輸出：
[null,null,null,null,null,null,null,14.00000,11.00000,null,11.00000,null,12.00000]
解釋：
乘客 45 從 Leyton 到 Waterloo，花了 15 - 3 = 12。
乘客 27 從 Leyton 到 Waterloo，花了 20 - 10 = 10。
乘客 32 從 Paradise 到 Cambridge，花了 22 - 8 = 14。
Paradise -> Cambridge 只有一趟，平均 14；Leyton -> Waterloo 有兩趟，平均 (12 + 10) / 2 = 11。
乘客 10 在時間 24 從 Leyton 進站，但還沒出站，不影響平均，仍是 11。
乘客 10 在時間 38 於 Waterloo 出站，花了 14，三趟平均 (12 + 10 + 14) / 3 = 12。
```

**範例 2：**

```text
輸入：
["UndergroundSystem","checkIn","checkOut","getAverageTime","checkIn","checkOut","getAverageTime","checkIn","checkOut","getAverageTime"]
[[],[10,"Leyton",3],[10,"Paradise",8],["Leyton","Paradise"],[5,"Leyton",10],[5,"Paradise",16],["Leyton","Paradise"],[2,"Leyton",21],[2,"Paradise",30],["Leyton","Paradise"]]
輸出：
[null,null,null,5.00000,null,null,5.50000,null,null,6.66667]
解釋：
三位乘客都走 Leyton -> Paradise，分別花了 5、6、9。
每次查詢時的平均依序是 5 / 1 = 5、(5 + 6) / 2 = 5.5、(5 + 6 + 9) / 3 ≈ 6.66667。
```

## 提示

- `1 <= id, t <= 10^6`
- `1 <= stationName.length, startStation.length, endStation.length <= 10`
- 所有字串只包含大小寫英文字母和數字。
- `checkIn`、`checkOut`、`getAverageTime` 合計最多呼叫 `2 * 10^4` 次。
- 和正確答案誤差在 `10^-5` 以內都視為正確。
