# 216. 組合總和 III

- 難度：中等
- 連結：https://leetcode.com/problems/combination-sum-iii/

## 題目

請找出所有「剛好 `k` 個數字、加起來等於 `n`」的組合，並滿足：

- 只能使用 `1` 到 `9` 這些數字。
- 每個數字在同一個組合裡最多使用一次。

回傳所有符合條件的組合。同一個組合（不看順序）不能出現兩次，組合之間的順序不限。

## 範例

**範例 1：**

```text
輸入：k = 3, n = 7
輸出：[[1,2,4]]
解釋：三個不同數字加起來是 7，只有 1 + 2 + 4 這一種。
```

**範例 2：**

```text
輸入：k = 3, n = 9
輸出：[[1,2,6],[1,3,5],[2,3,4]]
解釋：1 + 2 + 6、1 + 3 + 5、2 + 3 + 4 都等於 9，除此之外沒有別的組合。
```

**範例 3：**

```text
輸入：k = 4, n = 1
輸出：[]
解釋：四個不同的數字最小也有 1 + 2 + 3 + 4 = 10，比 1 大，所以不可能湊出來。
```

## 提示

- `2 <= k <= 9`
- `1 <= n <= 60`
