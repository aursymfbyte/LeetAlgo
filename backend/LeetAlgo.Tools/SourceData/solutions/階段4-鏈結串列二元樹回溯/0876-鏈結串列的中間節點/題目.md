# 876. 鏈結串列的中間節點

- 難度：簡單
- 連結：https://leetcode.com/problems/middle-of-the-linked-list/

## 題目

給你一條單向鏈結串列的頭節點 `head`，請回傳位在串列正中間的那個節點。

如果節點數是偶數，中間會有兩個節點，這時要回傳後面那一個。

## 範例

**範例 1：**

```text
輸入：head = [1,2,3,4,5]
輸出：[3,4,5]
解釋：5 個節點的正中間是值為 3 的節點，回傳它，從它往後看就是 [3,4,5]。
```

**範例 2：**

```text
輸入：head = [1,2,3,4,5,6]
輸出：[4,5,6]
解釋：6 個節點的中間有值 3 和值 4 兩個節點，要回傳後面那個（值為 4）。
```

## 提示

- 串列的節點數在 `[1, 100]` 範圍內
- `1 <= Node.val <= 100`
