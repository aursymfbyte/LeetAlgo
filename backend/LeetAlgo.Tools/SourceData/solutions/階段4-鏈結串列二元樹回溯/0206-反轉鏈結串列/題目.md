# 206. 反轉鏈結串列

- 難度：簡單
- 連結：https://leetcode.com/problems/reverse-linked-list/

## 題目

給你一條單向鏈結串列的頭節點 `head`，請把整條串列的方向倒過來（原本的最後一個節點變成第一個，每個節點的 `next` 都改成指向原本的前一個節點），並回傳反轉後串列的頭節點。

## 範例

**範例 1：**

```text
輸入：head = [1,2,3,4,5]
輸出：[5,4,3,2,1]
解釋：原串列 1 -> 2 -> 3 -> 4 -> 5，反轉後變成 5 -> 4 -> 3 -> 2 -> 1。
```

**範例 2：**

```text
輸入：head = [1,2]
輸出：[2,1]
解釋：原串列 1 -> 2，反轉後變成 2 -> 1。
```

**範例 3：**

```text
輸入：head = []
輸出：[]
解釋：空串列反轉後還是空串列。
```

## 提示

- 串列的節點數在 `[0, 5000]` 範圍內
- `-5000 <= Node.val <= 5000`

## 進階

鏈結串列可以用迭代或遞迴兩種方式反轉，你能兩種都寫出來嗎？
