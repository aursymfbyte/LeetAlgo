# 543. 二元樹的直徑

- 難度：簡單
- 連結：https://leetcode.com/problems/diameter-of-binary-tree/

## 題目

給你一棵二元樹的根節點 `root`，請回傳這棵樹的直徑。

直徑指的是樹中任意兩個節點之間「最長路徑」的長度，長度用路徑經過的**邊數**計算（不是節點數）。這條最長路徑不一定會經過根節點。

## 範例

**範例 1：**

```text
輸入：root = [1,2,3,4,5]
輸出：3
解釋：樹的形狀如下
          1
         / \
        2   3
       / \
      4   5
最長路徑是 4 → 2 → 1 → 3（或 5 → 2 → 1 → 3），共經過 3 條邊。
```

**範例 2：**

```text
輸入：root = [1,2]
輸出：1
解釋：樹的形狀如下
        1
       /
      2
只有一條邊 1 — 2，直徑是 1。
```

## 提示

- 樹中節點數目在範圍 `[1, 10^4]` 內
- `-100 <= Node.val <= 100`
