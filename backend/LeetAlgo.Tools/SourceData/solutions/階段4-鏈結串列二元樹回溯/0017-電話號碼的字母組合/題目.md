# 17. 電話號碼的字母組合

- 難度：中等
- 連結：https://leetcode.com/problems/letter-combinations-of-a-phone-number/

## 題目

給你一個只由數字 `2` 到 `9` 組成的字串 `digits`。在傳統手機的按鍵上，每個數字都對應幾個英文字母（數字 `1` 不對應任何字母）：

```text
2：abc    3：def    4：ghi    5：jkl
6：mno    7：pqrs   8：tuv    9：wxyz
```

請找出這串數字按下去之後，所有可能拼出的字母字串（每個數字挑一個它對應的字母，依序接起來），全部回傳。答案的順序不限。

## 範例

**範例 1：**

```text
輸入：digits = "23"
輸出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
解釋：2 可以是 a、b、c，3 可以是 d、e、f，兩兩搭配共 3 × 3 = 9 種。
```

**範例 2：**

```text
輸入：digits = "2"
輸出：["a","b","c"]
解釋：只有一個數字，它對應的三個字母各自就是一種答案。
```

## 提示

- `1 <= digits.length <= 4`
- `digits[i]` 是範圍 `['2', '9']` 內的數字。
