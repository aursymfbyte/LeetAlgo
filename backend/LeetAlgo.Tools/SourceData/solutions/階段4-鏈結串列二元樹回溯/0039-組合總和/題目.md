# 39. 組合總和

- 難度：中等
- 連結：https://leetcode.com/problems/combination-sum/

## 題目

給你一個由互不相同的整數組成的陣列 `candidates`，以及一個目標值 `target`。請找出所有「從 `candidates` 中挑數字、總和剛好等於 `target`」的組合，全部回傳，順序不限。

同一個數字可以被挑選任意多次。兩個組合只要有某個數字被挑的次數不同，就算是不同的組合；只是順序不同（例如 `[2,2,3]` 和 `[2,3,2]`）則算同一個，只能出現一次。

測資保證對給定的輸入，符合條件的組合少於 `150` 個。

## 範例

**範例 1：**

```text
輸入：candidates = [2,3,6,7], target = 7
輸出：[[2,2,3],[7]]
解釋：2 可以重複使用，2 + 2 + 3 = 7；7 本身也等於 7。除此之外沒有其他組合。
```

**範例 2：**

```text
輸入：candidates = [2,3,5], target = 8
輸出：[[2,2,2,2],[2,3,3],[3,5]]
解釋：四個 2、一個 2 加兩個 3、以及 3 + 5，總和都是 8。
```

**範例 3：**

```text
輸入：candidates = [2], target = 1
輸出：[]
解釋：只有 2 可以用，怎麼加都不會剛好是 1。
```

## 提示

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 的所有元素互不相同。
- `1 <= target <= 40`
