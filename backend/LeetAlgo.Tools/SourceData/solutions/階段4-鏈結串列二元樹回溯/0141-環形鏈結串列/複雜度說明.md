### 時間 O(n)

n 為串列的節點數。

迴圈最多執行次數分兩種情況：

- 無環：`fast` 每次走兩步，約 n / 2 次走到 `None`，迴圈結束。
- 有環：
  - `slow` 進入環之前，最多走環外那段的長度，不超過 n 步。
  - 兩個指標皆進入環後，`fast` 每輪比 `slow` 多走一步，兩者距離每輪縮短 1。此距離起始時必小於環的長度，而環的長度不超過 n，因此最多再 n 輪即相遇。
  - 兩段合計不超過 2n 輪。
- 每一輪僅移動兩個指標並比較一次，為 O(1)。
- 不論哪種情況，時間皆為 **O(n)**。

### 空間 O(1)

- 額外僅使用 `slow`、`fast` 兩個指標，數量固定。
- 以雜湊集合記錄走過節點的寫法最多需存 n 個節點，空間為 O(n)。快慢指標不記錄任何走過的節點，空間為 **O(1)**。
