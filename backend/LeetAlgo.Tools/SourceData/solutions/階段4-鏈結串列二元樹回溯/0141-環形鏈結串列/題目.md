# 141. 環形鏈結串列

- 難度：簡單
- 連結：https://leetcode.com/problems/linked-list-cycle/

## 題目

給你一條鏈結串列的頭節點 `head`，請判斷這條串列裡有沒有環。

所謂「有環」，是指從某個節點出發一直沿著 `next` 往下走，最後又會回到之前走過的節點，永遠走不到盡頭。

範例中的 `pos` 只是用來說明測資長什麼樣子：它代表最後一個節點的 `next` 接回到第幾個節點（從 0 開始數），`pos = -1` 表示沒有環。`pos` 不會當作參數傳給你的函式。

有環就回傳 `true`，沒有就回傳 `false`。

## 範例

**範例 1：**

```text
輸入：head = [3,2,0,-4], pos = 1
輸出：true
解釋：結構如下，最後一個節點 -4 接回下標 1 的節點 2：
      3 -> 2 -> 0 -> -4
           ^          |
           +----------+
```

**範例 2：**

```text
輸入：head = [1,2], pos = 0
輸出：true
解釋：結構如下，最後一個節點 2 接回下標 0 的節點 1：
      1 -> 2
      ^    |
      +----+
```

**範例 3：**

```text
輸入：head = [1], pos = -1
輸出：false
解釋：只有一個節點，它的 next 是空的，沒有環。
```

## 提示

- 串列的節點數在 `[0, 10^4]` 範圍內
- `-10^5 <= Node.val <= 10^5`
- `pos` 是 `-1` 或串列中合法的下標

## 進階

你能只用 O(1)（常數）的額外空間解決嗎？
