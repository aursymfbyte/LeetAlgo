### 時間 O(n)

n 為陣列 `preorder`（即樹）的節點數。

- 建立雜湊表 `index_in_inorder`：走訪中序一遍，存入 n 筆，每筆 O(1)，共 O(n)。
- 遞迴 `build`：每次 `size > 0` 的呼叫恰建立一個節點，此類呼叫共 n 次；`size == 0` 的呼叫對應空孩子，最多 n + 1 次，立即回傳。
- 每次呼叫的工作固定：取前序的第一個數、查雜湊表找出根在中序的位置、計算左子樹大小。雜湊表查詢平均為 O(1)，且遞迴僅傳遞起點與大小，不複製陣列，因此每次為 O(1)。
- 總計 O(n) + O(n) = **O(n)**。

直覺寫法：若每次都在中序中從頭搜尋根的位置，或每次將陣列切片複製後往下傳，每次呼叫需 O(n)，樹嚴重傾斜時總計達 O(n²)。

### 空間 O(n)

- 雜湊表存放 n 筆位置，為 O(n)。C 版改用固定大小的陣列（節點值範圍 -3000 到 3000，以值 + 3000 作為下標，共 6001 格），大小不隨 n 改變。
- 遞迴的呼叫堆疊（記錄尚未執行完之函式的記憶體區域）最多累積至樹高的層數。樹退化成一條直線時樹高為 n，為 O(n)。
- 建出的樹本身有 n 個節點，亦為 O(n)。
- 空間為 **O(n)**。
