# 105. 從前序與中序遍歷序列建構二元樹

- 難度：中等
- 連結：https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

## 題目

給你兩個整數陣列 `preorder` 和 `inorder`，它們分別是同一棵二元樹的前序遍歷（根 → 左 → 右）和中序遍歷（左 → 根 → 右）結果。請根據這兩個序列把原本的二元樹重建出來，並回傳它的根節點。

樹中每個節點的值都不相同。

## 範例

**範例 1：**

```text
輸入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
輸出：[3,9,20,null,null,15,7]
解釋：重建出來的樹如下
        3
       / \
      9   20
         /  \
        15   7
前序第一個 3 是根；在中序中 3 左邊只有 9，所以左子樹是 9，右邊的 15, 20, 7 組成右子樹。
```

**範例 2：**

```text
輸入：preorder = [-1], inorder = [-1]
輸出：[-1]
解釋：只有一個節點 -1。
```

## 提示

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 中的值都互不相同
- `inorder` 中的每個值都會出現在 `preorder` 中
- 保證 `preorder` 是這棵樹的前序遍歷
- 保證 `inorder` 是這棵樹的中序遍歷
