# 110. 平衡二元樹

- 難度：簡單
- 連結：https://leetcode.com/problems/balanced-binary-tree/

## 題目

給你一棵二元樹，請判斷它是不是「高度平衡」的二元樹。

高度平衡的定義是：樹中**每一個**節點，它的左子樹高度和右子樹高度相差都不超過 1。只檢查根節點不夠，所有節點都要符合。是的話回傳 `true`，否則回傳 `false`。空樹視為平衡。

## 範例

**範例 1：**

```text
輸入：root = [3,9,20,null,null,15,7]
輸出：true
解釋：樹的形狀如下
        3
       / \
      9   20
         /  \
        15   7
根節點左子樹高度 1、右子樹高度 2，相差 1；其他節點也都符合，所以是平衡的。
```

**範例 2：**

```text
輸入：root = [1,2,2,3,3,null,null,4,4]
輸出：false
解釋：樹的形狀如下
            1
           / \
          2   2
         / \
        3   3
       / \
      4   4
根節點左子樹高度 3、右子樹高度 1，相差 2，不平衡。
```

**範例 3：**

```text
輸入：root = []
輸出：true
解釋：空樹算是平衡的。
```

## 提示

- 樹中節點數目在範圍 `[0, 5000]` 內
- `-10^4 <= Node.val <= 10^4`
