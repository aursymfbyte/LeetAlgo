# 77. 組合

- 難度：中等
- 連結：https://leetcode.com/problems/combinations/

## 題目

給你兩個整數 `n` 和 `k`，請從 `1` 到 `n` 這些數字中挑出 `k` 個，回傳所有可能的挑法。

組合不考慮順序，例如 `[1,2]` 和 `[2,1]` 算同一種，只能出現一次。答案的順序不限。

## 範例

**範例 1：**

```text
輸入：n = 4, k = 2
輸出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
解釋：從 1~4 中挑 2 個，共有 C(4, 2) = 6 種挑法。
```

**範例 2：**

```text
輸入：n = 1, k = 1
輸出：[[1]]
解釋：只有數字 1 可以挑，所以只有一種。
```

## 提示

- `1 <= n <= 20`
- `1 <= k <= n`
