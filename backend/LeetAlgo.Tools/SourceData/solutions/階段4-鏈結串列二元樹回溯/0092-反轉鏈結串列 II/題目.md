# 92. 反轉鏈結串列 II

- 難度：中等
- 連結：https://leetcode.com/problems/reverse-linked-list-ii/

## 題目

給你一條單向鏈結串列的頭節點 `head`，以及兩個整數 `left` 和 `right`（`left <= right`，位置從 1 開始數）。

請只把第 `left` 個到第 `right` 個節點這一段的順序倒過來，其他節點維持原位，然後回傳整條串列的頭節點。

## 範例

**範例 1：**

```text
輸入：head = [1,2,3,4,5], left = 2, right = 4
輸出：[1,4,3,2,5]
解釋：第 2 到第 4 個節點是 2 -> 3 -> 4，倒過來變成 4 -> 3 -> 2，前後的 1 和 5 不動。
```

**範例 2：**

```text
輸入：head = [5], left = 1, right = 1
輸出：[5]
解釋：要反轉的區段只有一個節點，串列不變。
```

## 提示

- 串列的節點數為 `n`
- `1 <= n <= 500`
- `-500 <= Node.val <= 500`
- `1 <= left <= right <= n`

## 進階

你能只走訪串列一趟就完成嗎？
