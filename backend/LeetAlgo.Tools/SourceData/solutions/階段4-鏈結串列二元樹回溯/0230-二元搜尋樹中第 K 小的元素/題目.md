# 230. 二元搜尋樹中第 K 小的元素

- 難度：中等
- 連結：https://leetcode.com/problems/kth-smallest-element-in-a-bst/

## 題目

給你一棵二元搜尋樹的根節點 `root` 和一個整數 `k`，請回傳樹中所有節點值裡第 `k` 小的那個值（`k` 從 1 開始算，`k = 1` 就是最小值）。

## 範例

**範例 1：**

```text
輸入：root = [3,1,4,null,2], k = 1
輸出：1
解釋：樹的形狀如下
        3
       / \
      1   4
       \
        2
由小到大是 1, 2, 3, 4，第 1 小是 1。
```

**範例 2：**

```text
輸入：root = [5,3,6,2,4,null,null,1], k = 3
輸出：3
解釋：樹的形狀如下
            5
           / \
          3   6
         / \
        2   4
       /
      1
由小到大是 1, 2, 3, 4, 5, 6，第 3 小是 3。
```

## 提示

- 樹中的節點數為 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`
