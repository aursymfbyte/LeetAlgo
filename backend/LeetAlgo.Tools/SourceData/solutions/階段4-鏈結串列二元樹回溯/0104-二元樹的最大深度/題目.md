# 104. 二元樹的最大深度

- 難度：簡單
- 連結：https://leetcode.com/problems/maximum-depth-of-binary-tree/

## 題目

給你一棵二元樹的根節點 `root`，請回傳這棵樹的最大深度。

最大深度的意思是：從根節點出發，一路往下走到最遠的葉子節點，這條路徑上總共有幾個節點（根和葉子都要算）。空樹的深度是 0。

## 範例

**範例 1：**

```text
輸入：root = [3,9,20,null,null,15,7]
輸出：3
解釋：樹的形狀如下
        3
       / \
      9   20
         /  \
        15   7
最長的路徑是 3 → 20 → 15（或 3 → 20 → 7），經過 3 個節點。
```

**範例 2：**

```text
輸入：root = [1,null,2]
輸出：2
解釋：樹的形狀如下
    1
     \
      2
只有一條路徑 1 → 2，經過 2 個節點。
```

## 提示

- 樹中節點數目在範圍 `[0, 10^4]` 內
- `-100 <= Node.val <= 100`
