# 2. 兩數相加

- 難度：中等
- 連結：https://leetcode.com/problems/add-two-numbers/

## 題目

給你兩條非空的鏈結串列，各自代表一個非負整數。數字是倒過來存的：串列的第一個節點是個位數，第二個是十位數，依此類推，每個節點只放一個位數（0 到 9）。

請算出這兩個整數的和，並用同樣「倒著存、每個節點一位」的方式做成一條鏈結串列回傳。

除了數字 0 本身以外，這兩個數都不會有前導零。

## 範例

**範例 1：**

```text
輸入：l1 = [2,4,3], l2 = [5,6,4]
輸出：[7,0,8]
解釋：l1 代表 342，l2 代表 465，相加得 807，倒著存就是 [7,0,8]。
```

**範例 2：**

```text
輸入：l1 = [0], l2 = [0]
輸出：[0]
解釋：0 + 0 = 0。
```

**範例 3：**

```text
輸入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
輸出：[8,9,9,9,0,0,0,1]
解釋：9999999 + 9999 = 10009998，倒著存就是 [8,9,9,9,0,0,0,1]，最高位的進位會多出一個節點。
```

## 提示

- 每條串列的節點數在 `[1, 100]` 範圍內
- `0 <= Node.val <= 9`
- 保證串列代表的數字沒有前導零
