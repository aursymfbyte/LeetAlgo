### 時間 O(n)

n 為樹的節點數。

- 每個節點恰好進出佇列各一次，出佇列時記錄值並將孩子放入佇列，皆為 O(1)。
- 外層 `while` 每輪處理一層，內層 `for` 處理該層的節點。兩層迴圈並非相乘，內層合計僅執行所有層節點數總和 = n 次。
- Python 使用 `deque`，從前端取出 `popleft` 為 O(1)。若改用一般 list 的 `pop(0)`，每次需將後方元素全部前移，為 O(n)，整體退化為 O(n²)。
- 總時間為 **O(n)**。

### 空間 O(n)

使用記憶體的有兩處：

- 佇列 `queue`：同一時間最多存放一整層（加上下一層的一部分）節點。最寬的一層可能很寬，例如完全填滿的二元樹，最底層約有 n / 2 個節點，因此佇列最多為 O(n)。
- 答案 `result`：存放每個節點的值，恰為 n 個。
- 兩者皆為 O(n)，空間為 **O(n)**。
