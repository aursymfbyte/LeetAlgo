# 102. 二元樹的層序遍歷

- 難度：中等
- 連結：https://leetcode.com/problems/binary-tree-level-order-traversal/

## 題目

給你一棵二元樹的根節點 `root`，請一層一層地走訪這棵樹：從根節點那一層開始往下，每一層內由左到右。

回傳一個二維陣列，第 `i` 個子陣列裝的是第 `i` 層所有節點的值（由左到右）。空樹回傳空陣列。

## 範例

**範例 1：**

```text
輸入：root = [3,9,20,null,null,15,7]
輸出：[[3],[9,20],[15,7]]
解釋：樹的形狀如下
        3
       / \
      9   20
         /  \
        15   7
第 1 層是 3，第 2 層是 9、20，第 3 層是 15、7。
```

**範例 2：**

```text
輸入：root = [1]
輸出：[[1]]
解釋：只有根節點一層。
```

**範例 3：**

```text
輸入：root = []
輸出：[]
解釋：空樹沒有任何一層。
```

## 提示

- 樹中節點數目在範圍 `[0, 2000]` 內
- `-1000 <= Node.val <= 1000`
