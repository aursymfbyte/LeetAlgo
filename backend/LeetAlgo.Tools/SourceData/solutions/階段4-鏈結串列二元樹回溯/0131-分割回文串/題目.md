# 131. 分割回文串

- 難度：中等
- 連結：https://leetcode.com/problems/palindrome-partitioning/

## 題目

給你一個字串 `s`，請把它切成若干段連續的子字串，而且每一段都必須是回文（正著讀和反著讀一樣）。

請回傳所有符合條件的切法。每一種切法用一個字串串列表示，依原本的順序列出各段；切法之間的順序不限。

## 範例

**範例 1：**

```text
輸入：s = "aab"
輸出：[["a","a","b"],["aa","b"]]
解釋：可以每個字元各自一段，也可以把前面的 "aa" 合成一段；"aab"、"ab" 都不是回文，不能當成一段。
```

**範例 2：**

```text
輸入：s = "a"
輸出：[["a"]]
解釋：只有一個字元，唯一的切法就是它自己一段。
```

## 提示

- `1 <= s.length <= 16`
- `s` 只包含小寫英文字母。
