### 時間 O(n·2ⁿ)

n 為字串 `s` 的長度（題目限制最多 16）。

切法數量上限：
- 長度 n 的字串，相鄰兩字元之間有一個切點，共 n − 1 個切點。
- 每個切點只有「切」或「不切」兩種選擇，所有切法最多 2ⁿ⁻¹ 種。
- 最壞情況為所有字元相同，例如 `"aaaa"`，任何一段皆為回文，2ⁿ⁻¹ 種切法全部合法，答案最多。n = 16 時約 3 萬種。

時間計算：遞迴過程可畫成一棵遞迴樹，每次 `dfs` 呼叫為一個節點，切下一段即往下一層。
- 每找到一種切法（`start == n`），需複製一份 `path`，片段總長為 n 個字元，每個答案需 O(n)。最多 2ⁿ⁻¹ 個答案，此部分為 O(n·2ⁿ)。
- 中間節點需嘗試每個可能的結尾 `end`，每次以 `is_palindrome` 檢查，最多需 O(n)。遞迴樹越往下節點越多，但剩餘未切的字串也越短，檢查回文的成本隨之降低；整棵樹合計，此部分仍不超過 n·2ⁿ 等級。
- 總計 **O(n·2ⁿ)**（2ⁿ⁻¹ 與 2ⁿ 僅差常數 2，大 O 中寫成 2ⁿ）。

時間主要由輸出大小決定：最壞情況下答案本身有 2ⁿ⁻¹ 種切法、每種 n 個字元，僅輸出即需這麼多步。

### 空間 O(n)（不計答案）

- `path` 存放目前切下的片段，最多 n 段，總長最多 n 個字元。
- 遞迴的呼叫堆疊（記錄尚未執行完之函式的記憶體區域）每往下一層至少切下一個字元，最多 n + 1 層。
- 空間為 **O(n)**。不計答案的原因：答案本身可能有 2ⁿ⁻¹ 種切法，為題目要求必須回傳的內容，任何寫法都無法省略。
