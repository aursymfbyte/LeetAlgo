# 199. 二元樹的右視圖

- 難度：中等
- 連結：https://leetcode.com/problems/binary-tree-right-side-view/

## 題目

給你一棵二元樹的根節點 `root`。想像你站在這棵樹的右手邊往左看，每一層只看得到最右邊的那個節點（同一層的其他節點會被它擋住）。

請由上到下，回傳你看得到的節點值。空樹回傳空陣列。

## 範例

**範例 1：**

```text
輸入：root = [1,2,3,null,5,null,4]
輸出：[1,3,4]
解釋：樹的形狀如下
        1      ← 看到 1
       / \
      2   3    ← 看到 3
       \   \
        5   4  ← 看到 4（5 被 4 擋住）
```

**範例 2：**

```text
輸入：root = [1,2,3,4,null,null,null,5]
輸出：[1,3,4,5]
解釋：樹的形狀如下
          1      ← 看到 1
         / \
        2   3    ← 看到 3
       /
      4          ← 看到 4
     /
    5            ← 看到 5
第 3、4 層只有左邊有節點，右邊沒有東西擋住，所以從右側也看得到。
```

**範例 3：**

```text
輸入：root = [1,null,3]
輸出：[1,3]
解釋：樹的形狀如下
    1
     \
      3
```

**範例 4：**

```text
輸入：root = []
輸出：[]
解釋：空樹什麼都看不到。
```

## 提示

- 樹中節點數目在範圍 `[0, 100]` 內
- `-100 <= Node.val <= 100`
