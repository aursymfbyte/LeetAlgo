# 160. 相交鏈結串列

- 難度：簡單
- 連結：https://leetcode.com/problems/intersection-of-two-linked-lists/

## 題目

給你兩條單向鏈結串列的頭節點 `headA` 和 `headB`。這兩條串列可能從某個節點開始「合流」：從那個節點起，後面的節點是兩條串列共用的同一批節點（同一塊記憶體，不只是值相同）。

請找出兩條串列開始共用的第一個節點並回傳它；如果兩條串列完全沒有共用節點，回傳 `null`。

例如下面這兩條串列從節點 `c1` 開始相交：

```text
A:       a1 -> a2
                  \
                   c1 -> c2 -> c3
                  /
B: b1 -> b2 -> b3
```

保證整個結構裡沒有環。函式結束後，兩條串列必須維持原本的結構（不能改動節點的連接方式）。

**評測方式說明**：評測系統會用下面這些資料建出測資，但這些資料不會傳給你的函式，你只會拿到 `headA` 和 `headB`：

- `intersectVal`：交點節點的值，沒有交點時為 `0`
- `listA`：第一條串列
- `listB`：第二條串列
- `skipA`：在 `listA` 從頭往後跳過幾個節點會到達交點
- `skipB`：在 `listB` 從頭往後跳過幾個節點會到達交點

評測系統會依這些資料把兩條串列接起來，只要你回傳的正好是那個交點節點就算正確。

## 範例

**範例 1：**

```text
輸入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
輸出：Intersected at '8'
解釋：A 跳過前 2 個節點（4、1）、B 跳過前 3 個節點（5、6、1）後，會到達同一個值為 8 的節點，
      後面的 4、5 也都是共用的：
      A:      4 -> 1
                     \
                      8 -> 4 -> 5
                     /
      B: 5 -> 6 -> 1
      注意 A 裡的 1 和 B 裡的 1 只是值剛好一樣，是兩個不同的節點，所以交點是 8 而不是 1。
```

**範例 2：**

```text
輸入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1
輸出：Intersected at '2'
解釋：A 跳過 3 個節點（1、9、1）、B 跳過 1 個節點（3）後，會到達同一個值為 2 的節點：
      A: 1 -> 9 -> 1
                     \
                      2 -> 4
                     /
      B:            3
```

**範例 3：**

```text
輸入：intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2
輸出：No intersection
解釋：A 是 2 -> 6 -> 4，B 是 1 -> 5，兩條沒有任何共用節點，所以回傳 null。
      沒有交點時 intersectVal 為 0，skipA、skipB 可以是任意值。
```

## 提示

- `listA` 的節點數為 `m`
- `listB` 的節點數為 `n`
- `1 <= m, n <= 3 * 10^4`
- `1 <= Node.val <= 10^5`
- `0 <= skipA <= m`
- `0 <= skipB <= n`
- 如果 `listA` 和 `listB` 沒有相交，`intersectVal` 為 `0`
- 如果 `listA` 和 `listB` 有相交，`intersectVal == listA[skipA] == listB[skipB]`

## 進階

你能寫出時間 O(m + n)、只用 O(1) 額外空間的解法嗎？
