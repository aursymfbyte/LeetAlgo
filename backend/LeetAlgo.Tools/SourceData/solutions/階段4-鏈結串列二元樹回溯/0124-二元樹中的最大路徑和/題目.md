# 124. 二元樹中的最大路徑和

- 難度：困難
- 連結：https://leetcode.com/problems/binary-tree-maximum-path-sum/

## 題目

在二元樹中，「路徑」是一串節點，序列中每兩個相鄰的節點之間都有一條邊直接相連，而且同一個節點在序列中最多只能出現一次。路徑至少要包含一個節點，也不一定要經過根節點。

路徑和就是路徑上所有節點值加起來的總和。

給你一棵二元樹的根節點 `root`，請回傳所有非空路徑中最大的路徑和。

## 範例

**範例 1：**

```text
輸入：root = [1,2,3]
輸出：6
解釋：樹的形狀如下
        1
       / \
      2   3
選 2 → 1 → 3 這條路徑，總和 2 + 1 + 3 = 6 最大。
```

**範例 2：**

```text
輸入：root = [-10,9,20,null,null,15,7]
輸出：42
解釋：樹的形狀如下
       -10
       /  \
      9    20
          /  \
         15   7
選 15 → 20 → 7 這條路徑（不經過根節點），總和 15 + 20 + 7 = 42 最大。
```

## 提示

- 樹中節點數目在範圍 `[1, 3 * 10^4]` 內
- `-1000 <= Node.val <= 1000`
