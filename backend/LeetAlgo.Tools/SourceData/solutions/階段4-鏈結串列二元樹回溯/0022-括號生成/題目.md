# 22. 括號生成

- 難度：中等
- 連結：https://leetcode.com/problems/generate-parentheses/

## 題目

給你一個整數 `n`，代表有 `n` 對小括號。請產生所有由這 `n` 個 `(` 和 `n` 個 `)` 排成、而且括號能正確配對的字串，全部回傳。

「正確配對」指的是每個 `(` 都能在它右邊找到對應的 `)`，而且從左往右讀的任何時刻，出現過的 `)` 都不會比 `(` 多。答案的順序不限。

## 範例

**範例 1：**

```text
輸入：n = 3
輸出：["((()))","(()())","(())()","()(())","()()()"]
解釋：3 對括號共有這 5 種合法排法。
```

**範例 2：**

```text
輸入：n = 1
輸出：["()"]
解釋：只有一對括號時，唯一合法的就是 "()"。
```

## 提示

- `1 <= n <= 8`
