### 時間 O(n)

n 為串列的節點數。

程式分為兩個階段，兩階段先後執行（相加），並非一個包在另一個內重複執行（相乘）：

- 第一階段：與 141 題相同，以快慢指標找相遇點。`slow` 進環前最多走 n 步，進環後兩者距離每輪縮短 1，最多再 n 輪即相遇，為 O(n)。若無環，`fast` 約 n / 2 輪走到 `None`。
- 第二階段：`entry` 從頭出發、`slow` 從相遇點出發，每次各走一步，直到在入環點相遇。`entry` 的步數為頭到入環點的距離 a，a 必小於 n，為 O(n)。
- 程式中第二個 `while` 雖寫在第一個 `while` 內，但僅在相遇時執行一次，執行完即 `return`，因此為相加而非相乘。
- O(n) + O(n) = **O(n)**。

### 空間 O(1)

- 額外僅使用 `slow`、`fast`、`entry` 三個指標，數量固定。
- 以雜湊集合記錄走過的節點、第一個重複出現者即為入環點的寫法，空間為 O(n)。此寫法的空間為 **O(1)**。
