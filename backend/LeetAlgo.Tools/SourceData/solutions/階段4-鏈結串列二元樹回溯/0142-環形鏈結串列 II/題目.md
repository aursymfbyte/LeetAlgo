# 142. 環形鏈結串列 II

- 難度：中等
- 連結：https://leetcode.com/problems/linked-list-cycle-ii/

## 題目

給你一條鏈結串列的頭節點 `head`。如果串列裡有環，請回傳「進入環的第一個節點」（從頭往下走，第一個會被走到第二次的節點）；如果沒有環，回傳 `null`。

範例中的 `pos` 只是用來說明測資：它代表最後一個節點的 `next` 接回到第幾個節點（從 0 開始數），`pos = -1` 表示沒有環。`pos` 不會當作參數傳給你的函式。

不可以修改串列的結構。

## 範例

**範例 1：**

```text
輸入：head = [3,2,0,-4], pos = 1
輸出：tail connects to node index 1
解釋：最後一個節點 -4 接回下標 1 的節點 2，所以要回傳值為 2 的那個節點：
      3 -> 2 -> 0 -> -4
           ^          |
           +----------+
```

**範例 2：**

```text
輸入：head = [1,2], pos = 0
輸出：tail connects to node index 0
解釋：最後一個節點 2 接回下標 0 的節點 1，所以要回傳第一個節點：
      1 -> 2
      ^    |
      +----+
```

**範例 3：**

```text
輸入：head = [1], pos = -1
輸出：no cycle
解釋：串列沒有環，回傳 null。
```

## 提示

- 串列的節點數在 `[0, 10^4]` 範圍內
- `-10^5 <= Node.val <= 10^5`
- `pos` 是 `-1` 或串列中合法的下標

## 進階

你能只用 O(1)（常數）的額外空間解決嗎？
