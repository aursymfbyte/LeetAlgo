### 時間 O(n)

n 為串列的節點數。

程式分三步依序執行，時間相加：

- 找中點 `middleNode`：快慢指標，`fast` 一次走兩步，約執行 n / 2 次。
- 反轉後半段 `reverseList`：後半段約 n / 2 個節點，每個節點修改一次指標。
- 交錯合併：每一輪接上前半與後半各一個節點，約執行 n / 2 輪。
- 每一步僅移動或修改固定幾個指標，為 O(1)。
- 合計約 n / 2 + n / 2 + n / 2 = 1.5n，省略常數後為 **O(n)**。

### 空間 O(1)

- 三個步驟皆直接修改原節點的 `next` 指標，不建立新節點。
- 兩個輔助函式皆以迴圈實作而非遞迴，不會在呼叫堆疊（記錄尚未執行完之函式的記憶體區域）中逐層累積。
- 額外僅使用 `slow`、`fast`、`pre`、`cur`、`first`、`second` 等固定幾個指標，空間為 **O(1)**。

直覺寫法：將所有節點放入陣列，再以左右兩個下標交錯串接，實作較簡單，但需多存 n 個節點，空間為 O(n)。
