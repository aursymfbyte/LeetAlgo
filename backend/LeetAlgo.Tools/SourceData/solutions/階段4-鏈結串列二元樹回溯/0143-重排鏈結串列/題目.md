# 143. 重排鏈結串列

- 難度：中等
- 連結：https://leetcode.com/problems/reorder-list/

## 題目

給你一條單向鏈結串列的頭節點 `head`，串列的節點依序是：

```text
L0 -> L1 -> … -> Ln-1 -> Ln
```

請把它重新排成「頭一個、尾一個」交錯的順序：

```text
L0 -> Ln -> L1 -> Ln-1 -> L2 -> Ln-2 -> …
```

不能改節點裡的值，只能改變節點之間的連接方式。函式不用回傳任何東西，直接在原串列上修改。

## 範例

**範例 1：**

```text
輸入：head = [1,2,3,4]
輸出：[1,4,2,3]
解釋：依序取第一個 1、最後一個 4、第二個 2、倒數第二個 3。
```

**範例 2：**

```text
輸入：head = [1,2,3,4,5]
輸出：[1,5,2,4,3]
解釋：依序取 1、5、2、4，最後剩下中間的 3 放在最後。
```

## 提示

- 串列的節點數在 `[1, 5 * 10^4]` 範圍內
- `1 <= Node.val <= 1000`
