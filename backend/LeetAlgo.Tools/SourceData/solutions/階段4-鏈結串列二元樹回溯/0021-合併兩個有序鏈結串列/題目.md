# 21. 合併兩個有序鏈結串列

- 難度：簡單
- 連結：https://leetcode.com/problems/merge-two-sorted-lists/

## 題目

給你兩條已經由小到大（非遞減）排好序的鏈結串列，頭節點分別是 `list1` 和 `list2`。

請把它們合併成一條同樣由小到大排好序的串列，而且要直接重新串接原本兩條串列的節點來組成（不是另外複製新節點），最後回傳合併後串列的頭節點。

## 範例

**範例 1：**

```text
輸入：list1 = [1,2,4], list2 = [1,3,4]
輸出：[1,1,2,3,4,4]
解釋：兩條串列的節點依大小交錯接起來：1 -> 1 -> 2 -> 3 -> 4 -> 4。
```

**範例 2：**

```text
輸入：list1 = [], list2 = []
輸出：[]
解釋：兩條都是空的，合併結果也是空的。
```

**範例 3：**

```text
輸入：list1 = [], list2 = [0]
輸出：[0]
解釋：只有 list2 有節點，結果就是 list2 本身。
```

## 提示

- 兩條串列的節點數都在 `[0, 50]` 範圍內
- `-100 <= Node.val <= 100`
- `list1` 和 `list2` 都已依非遞減順序排序
