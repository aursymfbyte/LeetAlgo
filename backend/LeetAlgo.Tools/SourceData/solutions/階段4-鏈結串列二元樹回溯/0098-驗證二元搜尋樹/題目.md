# 98. 驗證二元搜尋樹

- 難度：中等
- 連結：https://leetcode.com/problems/validate-binary-search-tree/

## 題目

給你一棵二元樹的根節點 `root`，請判斷它是不是一棵合法的二元搜尋樹（BST）。

合法的 BST 要滿足以下所有條件：

- 任一節點的左子樹中，**所有**節點的值都嚴格小於該節點的值。
- 任一節點的右子樹中，**所有**節點的值都嚴格大於該節點的值。
- 左子樹和右子樹本身也都必須是合法的 BST。

注意是「嚴格」大於或小於，值相等也不合法。合法就回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：root = [2,1,3]
輸出：true
解釋：樹的形狀如下
        2
       / \
      1   3
左邊 1 < 2，右邊 3 > 2，符合 BST 的規則。
```

**範例 2：**

```text
輸入：root = [5,1,4,null,null,3,6]
輸出：false
解釋：樹的形狀如下
        5
       / \
      1   4
         / \
        3   6
根節點是 5，但它的右孩子 4 比 5 小，違反「右子樹都要比根大」的規則。
```

## 提示

- 樹中節點數目在範圍 `[1, 10^4]` 內
- `-2^31 <= Node.val <= 2^31 - 1`
