# 101. 對稱二元樹

- 難度：簡單
- 連結：https://leetcode.com/problems/symmetric-tree/

## 題目

給你一棵二元樹的根節點 `root`，請判斷這棵樹是不是左右對稱的：想像在根節點正中間立一面鏡子，左半邊照出來的樣子要和右半邊一模一樣（形狀相同，對應位置的值也相同）。對稱就回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：root = [1,2,2,3,4,4,3]
輸出：true
解釋：樹的形狀如下
          1
        /   \
       2     2
      / \   / \
     3   4 4   3
以中間為軸，左右兩邊互為鏡像。
```

**範例 2：**

```text
輸入：root = [1,2,2,null,3,null,3]
輸出：false
解釋：樹的形狀如下
        1
      /   \
     2     2
      \     \
       3     3
左邊的 3 掛在右側，右邊的 3 也掛在右側；鏡像的話右邊的 3 應該掛在左側才對。
```

## 提示

- 樹中節點數目在範圍 `[1, 1000]` 內
- `-100 <= Node.val <= 100`

## 進階

你能分別用遞迴和迭代（例如用佇列一次放入一對要比較的節點）兩種方式解出來嗎？
