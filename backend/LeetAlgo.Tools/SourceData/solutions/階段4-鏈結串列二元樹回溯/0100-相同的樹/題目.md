# 100. 相同的樹

- 難度：簡單
- 連結：https://leetcode.com/problems/same-tree/

## 題目

給你兩棵二元樹的根節點 `p` 和 `q`，請判斷這兩棵樹是不是相同的樹。

「相同」要同時滿足兩個條件：兩棵樹的形狀完全一樣（每個位置有沒有節點都一致），而且對應位置上的節點值也都相等。相同就回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：p = [1,2,3], q = [1,2,3]
輸出：true
解釋：兩棵樹都長這樣
      1
     / \
    2   3
形狀和每個位置的值都一致。
```

**範例 2：**

```text
輸入：p = [1,2], q = [1,null,2]
輸出：false
解釋：
    p:   1        q:   1
        /               \
       2                 2
p 的 2 掛在左邊，q 的 2 掛在右邊，形狀不同。
```

**範例 3：**

```text
輸入：p = [1,2,1], q = [1,1,2]
輸出：false
解釋：
    p:   1        q:   1
        / \           / \
       2   1         1   2
形狀一樣，但左右孩子的值剛好對調，所以不算相同。
```

## 提示

- 兩棵樹中的節點數目都在範圍 `[0, 100]` 內
- `-10^4 <= Node.val <= 10^4`
