# 78. 子集

- 難度：中等
- 連結：https://leetcode.com/problems/subsets/

## 題目

給你一個整數陣列 `nums`，裡面的數字彼此都不相同。請回傳它的所有子集（也就是冪集合：從 `nums` 裡挑出任意幾個數，包含一個都不挑的空集合）。

同一個子集不能出現兩次，子集之間的順序不限。

## 範例

**範例 1：**

```text
輸入：nums = [1,2,3]
輸出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
解釋：3 個數字每個都可以選或不選，共 2^3 = 8 個子集。
```

**範例 2：**

```text
輸入：nums = [0]
輸出：[[],[0]]
解釋：只有空集合與 [0] 本身兩種。
```

## 提示

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有數字互不相同。
