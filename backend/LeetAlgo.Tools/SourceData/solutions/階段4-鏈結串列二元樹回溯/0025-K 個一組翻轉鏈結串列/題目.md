# 25. K 個一組翻轉鏈結串列

- 難度：困難
- 連結：https://leetcode.com/problems/reverse-nodes-in-k-group/

## 題目

給你一條鏈結串列的頭節點 `head` 和一個正整數 `k`（`k` 不會超過串列長度）。

請從頭開始，每 `k` 個節點分成一組，把每一組內部的順序倒過來，最後回傳修改後串列的頭節點。如果節點總數不是 `k` 的倍數，最後剩下不足 `k` 個的節點維持原本的順序。

不能只交換節點裡的值，必須真的改變節點的連接方式。

## 範例

**範例 1：**

```text
輸入：head = [1,2,3,4,5], k = 2
輸出：[2,1,4,3,5]
解釋：分組為 [1,2]、[3,4]、[5]，前兩組各自反轉，最後的 5 不足兩個，保持不動。
```

**範例 2：**

```text
輸入：head = [1,2,3,4,5], k = 3
輸出：[3,2,1,4,5]
解釋：分組為 [1,2,3]、[4,5]，第一組反轉成 3,2,1，剩下的 4,5 不足三個，保持不動。
```

## 提示

- 串列的節點數為 `n`
- `1 <= k <= n <= 5000`
- `0 <= Node.val <= 1000`

## 進階

你能只用 O(1) 的額外空間解決嗎？
