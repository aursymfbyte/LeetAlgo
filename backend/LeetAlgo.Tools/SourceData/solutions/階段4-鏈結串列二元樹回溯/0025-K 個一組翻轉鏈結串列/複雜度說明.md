### 時間 O(n)

n 為串列的節點數，k 為每一組的節點數。

- 第一步：走一遍數出長度 `length`，執行 n 次。
- 第二步：外層 `while` 每處理一組就扣掉 k，最多執行 n / k 次；每組內的 `for` 迴圈反轉 k 個節點，執行 k 次。
- 兩層迴圈並非 n × k。外層僅執行 n / k 次，內層總共執行 (n / k) × k = n 次以內，即每個節點只被反轉一次。
- 每組反轉後接回僅修改幾個指標，為 O(1)。
- 合計約 n + n = 2n 步，為 **O(n)**。

注意：兩層迴圈不一定是 O(n²)，需計算內層總共執行幾次。

### 空間 O(1)

- 反轉直接修改原節點的 `next` 指標，不另外存放節點。
- 額外僅使用 `dummy`、`before`、`pre`、`cur`、`nxt`、`group_tail` 幾個變數，數量固定，與 n 和 k 皆無關，空間為 **O(1)**。
