# 226. 翻轉二元樹

- 難度：簡單
- 連結：https://leetcode.com/problems/invert-binary-tree/

## 題目

給你一棵二元樹的根節點 `root`，請把它左右翻轉（變成原來的鏡像），然後回傳翻轉後的根節點。

翻轉的意思是：樹中每一個節點的左孩子和右孩子都要互換位置。

## 範例

**範例 1：**

```text
輸入：root = [4,2,7,1,3,6,9]
輸出：[4,7,2,9,6,3,1]
解釋：
    翻轉前：                翻轉後：
          4                       4
        /   \                   /   \
       2     7                 7     2
      / \   / \               / \   / \
     1   3 6   9             9   6 3   1
每個節點的左右孩子都對調了。
```

**範例 2：**

```text
輸入：root = [2,1,3]
輸出：[2,3,1]
解釋：
    翻轉前：      翻轉後：
        2             2
       / \           / \
      1   3         3   1
```

**範例 3：**

```text
輸入：root = []
輸出：[]
解釋：空樹翻轉後仍是空樹。
```

## 提示

- 樹中節點數目在範圍 `[0, 100]` 內
- `-100 <= Node.val <= 100`
