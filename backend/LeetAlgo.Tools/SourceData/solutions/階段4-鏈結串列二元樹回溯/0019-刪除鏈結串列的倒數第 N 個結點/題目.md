# 19. 刪除鏈結串列的倒數第 N 個結點

- 難度：中等
- 連結：https://leetcode.com/problems/remove-nth-node-from-end-of-list/

## 題目

給你一條鏈結串列的頭節點 `head` 和一個整數 `n`，請把從尾巴往回數第 `n` 個節點（最後一個節點算倒數第 1 個）從串列中移除，然後回傳移除後串列的頭節點。

## 範例

**範例 1：**

```text
輸入：head = [1,2,3,4,5], n = 2
輸出：[1,2,3,5]
解釋：倒數第 2 個節點是 4，拿掉後變成 1 -> 2 -> 3 -> 5。
```

**範例 2：**

```text
輸入：head = [1], n = 1
輸出：[]
解釋：唯一的節點就是倒數第 1 個，拿掉後串列變成空的。
```

**範例 3：**

```text
輸入：head = [1,2], n = 1
輸出：[1]
解釋：倒數第 1 個節點是 2，拿掉後只剩 1。
```

## 提示

- 串列的節點數為 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

## 進階

你能只走訪串列一趟就完成嗎？
