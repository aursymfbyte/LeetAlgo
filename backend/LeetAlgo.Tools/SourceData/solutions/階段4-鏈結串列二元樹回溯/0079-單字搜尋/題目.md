# 79. 單字搜尋

- 難度：中等
- 連結：https://leetcode.com/problems/word-search/

## 題目

給你一個 `m x n` 的字母網格 `board`，以及一個字串 `word`。請判斷能不能在網格裡找到 `word`，可以就回傳 `true`，否則回傳 `false`。

「找到」的意思是：從某一格出發，每次移動到上、下、左、右相鄰的格子，依序經過的字母剛好拼成 `word`。同一個格子在同一條路徑中不能使用兩次。

## 範例

三個範例使用同一個網格：

```text
A B C E
S F C S
A D E E
```

**範例 1：**

```text
輸入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
輸出：true
解釋：從左上角的 A 出發，往右走到 B、C，往下到 C，再往下到 E，最後往左到 D，就拼出 "ABCCED"。
```

**範例 2：**

```text
輸入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
輸出：true
解釋：從第二列最右邊的 S 出發，往下到 E，再往左到 E。
```

**範例 3：**

```text
輸入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
輸出：false
解釋：走完 A、B、C 之後，要再回到 B 只能重複使用剛才那格 B，這是不允許的。
```

## 提示

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 只由大小寫英文字母組成。

## 進階

如果網格變得更大，你能用哪些剪枝技巧讓搜尋更快？
