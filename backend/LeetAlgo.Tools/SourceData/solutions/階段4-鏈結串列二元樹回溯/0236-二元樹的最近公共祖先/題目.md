# 236. 二元樹的最近公共祖先

- 難度：中等
- 連結：https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/

## 題目

給你一棵二元樹的根節點 `root`，以及樹中的兩個節點 `p` 和 `q`，請找出它們的「最近公共祖先」並回傳該節點。

公共祖先是指：`p` 和 `q` 都在它的子樹裡（一個節點也算是自己的子孫，所以 `p` 本身也可以是 `p` 和 `q` 的公共祖先）。在所有公共祖先之中，深度最深、離 `p`、`q` 最近的那一個，就是最近公共祖先。

函式收到的 `p`、`q` 是樹中實際的節點，回傳的也要是樹中的節點。

## 範例

以下範例 1、2 使用同一棵樹：

```text
            3
          /   \
         5     1
        / \   / \
       6   2 0   8
          / \
         7   4
```

**範例 1：**

```text
輸入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
輸出：3
解釋：5 在根的左邊、1 在根的右邊，兩者第一次會合的地方是根節點 3。
```

**範例 2：**

```text
輸入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
輸出：5
解釋：4 在 5 的子樹裡，而節點可以算是自己的子孫，所以最近公共祖先就是 5 本身。
```

**範例 3：**

```text
輸入：root = [1,2], p = 1, q = 2
輸出：1
解釋：樹的形狀如下
        1
       /
      2
2 是 1 的孩子，最近公共祖先是 1。
```

## 提示

- 樹中節點數目在範圍 `[2, 10^5]` 內
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`
- `p` 和 `q` 都一定存在於樹中
