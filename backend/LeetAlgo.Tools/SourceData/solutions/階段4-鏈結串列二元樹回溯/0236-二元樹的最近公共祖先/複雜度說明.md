### 時間 O(n)

n 為樹的節點數，h 為樹高（從根到最深葉子經過的層數）。

- 每次呼叫扣除遞迴部分，僅做幾個判斷（是否為空、是否為 `p` 或 `q`、左右結果是否為空），為 O(1)。
- 遇到 `p` 或 `q` 即直接回傳，不再往其下方走，因此部分節點不會被拜訪。
- 最壞情況下（例如 `p`、`q` 皆位於很深的位置），幾乎每個節點都需拜訪一次，空孩子的呼叫最多 n + 1 次。
- 時間為 **O(n)**。

### 空間 O(h)

- 程式不使用額外的陣列或雜湊表，空間來自遞迴的呼叫堆疊。
- 呼叫堆疊為記錄尚未執行完之函式的記憶體區域：遞迴呼叫時外層需等左右兩側結果皆返回才能判斷，因此先被保留，逐層累積。
- 同時累積的層數最多為樹高 h，空間為 **O(h)**。
- 平衡樹的 h 約為 log₂n（n 需除以 2 幾次才變成 1），n = 10⁵ 時約 17 層；樹退化成一條直線時 h = n。

另一種寫法：先以雜湊表記錄每個節點的父節點，再從 `p` 往上存下所有祖先、從 `q` 往上找第一個共同祖先。時間同為 O(n)，但雜湊表需存 n 筆，空間必為 O(n)。
