### 時間 O(m + n)

m 為 `word1` 的長度，n 為 `word2` 的長度。

- 迴圈次數為兩字串中較長者的長度。每一輪最多從兩字串各取一個字元，附加到結果尾端。
- 以字元計算：`word1` 與 `word2` 的每個字元各恰好被取一次，附加動作共 m + n 次。
- 附加字元到結果尾端通常為固定步數；容量不足時需配置更大的空間並搬移舊資料，但因每次按比例放大，平均每次仍為固定時間，稱為均攤 O(1)。
- Python 最後以 `join` 將 m + n 個字元接成字串，亦為 O(m + n)。
- 合計為 **O(m + n)**。

### 空間 O(m + n)

- 結果字串（Python 先存於串列 `result`）包含兩字串的所有字元，共 m + n 個，為 **O(m + n)**。
- 此題的檔頭將回傳結果計入空間。除結果外，僅使用下標 `i` 等固定數量的變數。
