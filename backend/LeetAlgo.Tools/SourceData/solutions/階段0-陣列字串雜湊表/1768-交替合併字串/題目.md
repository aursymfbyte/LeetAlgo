# 1768. 交替合併字串

- 難度：簡單
- 連結：https://leetcode.com/problems/merge-strings-alternately/

## 題目

給你兩個字串 `word1` 和 `word2`。從 `word1` 開始，兩個字串輪流各取一個字母，接成一個新字串。如果其中一個字串比較長，等短的那個用完之後，把長的那個剩下的字母直接接在最後面。

回傳合併後的字串。

## 範例

**範例 1：**

```text
輸入：word1 = "abc", word2 = "pqr"
輸出："apbqcr"
解釋：輪流取字母：a、p、b、q、c、r。
```

**範例 2：**

```text
輸入：word1 = "ab", word2 = "pqrs"
輸出："apbqrs"
解釋：先輪流取出 a、p、b、q，word1 用完了，再把 word2 剩下的 "rs" 接在後面。
```

**範例 3：**

```text
輸入：word1 = "abcd", word2 = "pq"
輸出："apbqcd"
解釋：先輪流取出 a、p、b、q，word2 用完了，再把 word1 剩下的 "cd" 接在後面。
```

## 提示

- `1 <= word1.length, word2.length <= 100`
- `word1` 和 `word2` 只包含小寫英文字母
