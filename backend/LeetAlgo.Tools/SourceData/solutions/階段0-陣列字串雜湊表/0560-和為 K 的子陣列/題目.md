# 560. 和為 K 的子陣列

- 難度：中等
- 連結：https://leetcode.com/problems/subarray-sum-equals-k/

## 題目

給你一個整數陣列 `nums` 和一個整數 `k`，請算出有幾個子陣列的元素總和剛好等於 `k`。

子陣列是指陣列中一段連續、而且不是空的元素。

## 範例

**範例 1：**

```text
輸入：nums = [1,1,1], k = 2
輸出：2
解釋：下標 0~1 的 [1,1] 和下標 1~2 的 [1,1]，總和都是 2。
```

**範例 2：**

```text
輸入：nums = [1,2,3], k = 3
輸出：2
解釋：[1,2] 和 [3] 的總和都是 3。
```

## 提示

- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`
