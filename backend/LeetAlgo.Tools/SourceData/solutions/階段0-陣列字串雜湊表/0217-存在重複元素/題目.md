# 217. 存在重複元素

- 難度：簡單
- 連結：https://leetcode.com/problems/contains-duplicate/

## 題目

給你一個整數陣列 `nums`。只要有任何一個值在陣列中出現兩次以上，就回傳 `true`；如果每個元素都不一樣，就回傳 `false`。

## 範例

**範例 1：**

```text
輸入：nums = [1,2,3,1]
輸出：true
解釋：1 出現在下標 0 和下標 3。
```

**範例 2：**

```text
輸入：nums = [1,2,3,4]
輸出：false
解釋：四個數字都不一樣。
```

**範例 3：**

```text
輸入：nums = [1,1,1,3,3,4,3,2,4,2]
輸出：true
解釋：1、2、3、4 都出現不只一次。
```

## 提示

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
