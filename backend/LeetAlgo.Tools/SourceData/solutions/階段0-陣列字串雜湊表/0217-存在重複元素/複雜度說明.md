### 效能版

**時間 O(n)**

n 為陣列 `nums` 的長度。

- 程式由左至右走訪陣列一次，最多 n 次（找到重複即提早結束）。
- 每次迭代做兩件事：查詢集合 `seen` 中是否已有該數，若無則存入。集合以雜湊表實作，查詢與存入平均皆為固定步數，與已存放的資料量無關，記作 O(1)。
- 總計 n × O(1) = **O(n)**。

**空間 O(n)**

- 額外記憶體僅有集合 `seen`。
- 最壞情況為陣列中完全沒有重複，n 個數全部存入，為 **O(n)**。

### 可讀性版

C#、Python、C++ 的寫法與效能版相同，時間 **O(n)**、空間 **O(n)**。僅 C 版不同：

**時間：C 版 O(n log n)**

- C 版先以 `qsort` 排序，使相同的數相鄰，再檢查相鄰兩數一次。
- 排序 n 個數約需 n log n 次比較。log n 為 n 反覆除以 2 直到剩 1 所需的次數，n = 10⁵ 時約為 17。後續檢查相鄰僅 O(n)，總計為 **O(n log n)**。
- 較效能版慢，因為排序多出約 log n 倍的工作。

**空間：C 版 O(log n)**

- 排序直接在原陣列上進行，不另外配置陣列。但 `qsort` 通常以遞迴實作，每層遞迴都會在呼叫堆疊上保存一筆紀錄。呼叫堆疊是系統保存函式返回位置與區域變數的記憶體，遞迴深度約 log n 層，為 **O(log n)**。
- 比效能版省空間，因為不需要集合，代價為時間較慢。
