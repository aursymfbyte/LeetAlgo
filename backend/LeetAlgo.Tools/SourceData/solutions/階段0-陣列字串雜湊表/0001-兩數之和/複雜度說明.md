### 時間 O(n)

n 為陣列 `nums` 的長度。

- 迴圈由左至右走訪陣列一次，共 n 次。
- 每次迭代各做一次雜湊表查詢（`target - num`）與寫入，兩者平均皆為 O(1)，與雜湊表已存放的資料量無關。
- 總計 n × O(1) = **O(n)**。

暴力解：以兩層迴圈檢查所有數對，約 n²/2 次，為 O(n²)。n = 10⁴ 時暴力解約需 5,000 萬次比較，此寫法約 1 萬次。

### 空間 O(n)

- 額外記憶體僅有雜湊表 `index_of`。
- 最壞情況下答案位於陣列末端，前 n − 1 個數皆已存入雜湊表，最多存放 n 筆，空間為 **O(n)**。
- 回傳值只有兩個下標，大小固定，不影響複雜度。
