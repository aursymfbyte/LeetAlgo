# 1. 兩數之和

- 難度：簡單
- 連結：https://leetcode.com/problems/two-sum/

## 題目

給你一個整數陣列 `nums` 和一個整數 `target`，請在陣列中找出兩個數，使它們的和等於 `target`，並回傳這兩個數的下標。

題目保證每組輸入剛好只有一組答案，而且同一個元素不能使用兩次。回傳的兩個下標順序不限。

## 範例

**範例 1：**

```text
輸入：nums = [2,7,11,15], target = 9
輸出：[0,1]
解釋：nums[0] + nums[1] = 2 + 7 = 9，所以回傳 [0,1]。
```

**範例 2：**

```text
輸入：nums = [3,2,4], target = 6
輸出：[1,2]
解釋：nums[1] + nums[2] = 2 + 4 = 6。注意不能把 nums[0] 的 3 用兩次。
```

**範例 3：**

```text
輸入：nums = [3,3], target = 6
輸出：[0,1]
解釋：兩個不同位置的 3 相加剛好是 6。
```

## 提示

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- 只會存在一組有效答案

## 進階

你能想出時間複雜度低於 O(n^2) 的演算法嗎？
