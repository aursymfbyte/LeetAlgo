# 303. 區域和檢索 - 陣列不可變

- 難度：簡單
- 連結：https://leetcode.com/problems/range-sum-query-immutable/

## 題目

給你一個整數陣列 `nums`，之後會有很多次查詢，每次查詢要算出下標 `left` 到 `right`（兩端都包含，`left <= right`）之間所有元素的總和。陣列內容在查詢過程中不會改變。

請實作 `NumArray` 類別：

- `NumArray(int[] nums)`：用陣列 `nums` 初始化物件。
- `int sumRange(int left, int right)`：回傳 `nums[left] + nums[left + 1] + ... + nums[right]`。

C 語言版要實作 `numArrayCreate`、`numArraySumRange`、`numArrayFree` 三個函式，分別對應建構、查詢和釋放物件。

## 範例

**範例 1：**

```text
輸入：
["NumArray", "sumRange", "sumRange", "sumRange"]
[[[-2, 0, 3, -5, 2, -1]], [0, 2], [2, 5], [0, 5]]
輸出：
[null, 1, -1, -3]
解釋：
NumArray numArray = new NumArray([-2, 0, 3, -5, 2, -1]);
numArray.sumRange(0, 2);  // 下標 0 到 2：-2 + 0 + 3 = 1
numArray.sumRange(2, 5);  // 下標 2 到 5：3 + (-5) + 2 + (-1) = -1
numArray.sumRange(0, 5);  // 整個陣列：(-2) + 0 + 3 + (-5) + 2 + (-1) = -3
```

## 提示

- `1 <= nums.length <= 10^4`
- `-10^5 <= nums[i] <= 10^5`
- `0 <= left <= right < nums.length`
- `sumRange` 最多被呼叫 `10^4` 次
