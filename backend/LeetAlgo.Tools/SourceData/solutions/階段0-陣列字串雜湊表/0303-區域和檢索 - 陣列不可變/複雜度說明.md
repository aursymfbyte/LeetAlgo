設計題需分別計算建構物件與每次查詢的成本。n 為陣列 `nums` 的長度。

### 建構：O(n)

- 建構時走訪 `nums` 一次，共 n 次。
- 每次僅執行 `prefix[i + 1] = prefix[i] + num`，一次加法，固定步數。
- 建構為 n × O(1) = **O(n)**，且只在一開始執行一次。

### sumRange：O(1)

- 每次查詢僅讀取 `prefix` 中的兩個值，相減一次即得答案。
- 無論區間 `[left, right]` 多長，步數皆相同，為 **O(1)**。

直覺寫法：每次查詢從 `left` 加總到 `right`，單次查詢最多 O(n)。題目限制最多查詢 10⁴ 次、n 最多 10⁴，直覺寫法最壞需 10⁴ × 10⁴ = 1 億步；前綴和僅需建構 1 萬步加上查詢 1 萬步。

### 空間 O(n)

- 額外記憶體僅有前綴和陣列 `prefix`，長度為 n + 1，為 **O(n)**。
- 查詢時不再使用額外記憶體。
