# 347. 前 K 個高頻元素

- 難度：中等
- 連結：https://leetcode.com/problems/top-k-frequent-elements/

## 題目

給你一個整數陣列 `nums` 和一個整數 `k`，請回傳出現次數最多的前 `k` 個元素。回傳的順序不限。

題目保證答案是唯一的（不會出現第 `k` 名和第 `k + 1` 名次數相同、無法決定的情況）。

## 範例

**範例 1：**

```text
輸入：nums = [1,1,1,2,2,3], k = 2
輸出：[1,2]
解釋：1 出現 3 次、2 出現 2 次、3 出現 1 次，次數最多的兩個是 1 和 2。
```

**範例 2：**

```text
輸入：nums = [1], k = 1
輸出：[1]
解釋：只有一種數字。
```

**範例 3：**

```text
輸入：nums = [1,2,1,2,1,2,3,1,3,2], k = 2
輸出：[1,2]
解釋：1 和 2 各出現 4 次，3 出現 2 次，所以前兩名是 1 和 2。
```

## 提示

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` 的範圍是 `[1, 陣列中不同元素的個數]`
- 保證答案唯一

## 進階

你的演算法時間複雜度要比 O(n log n) 更好，`n` 是陣列長度。
