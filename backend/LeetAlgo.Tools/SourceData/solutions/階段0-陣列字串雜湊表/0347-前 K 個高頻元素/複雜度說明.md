### 效能版

**時間 O(n)**

n 為陣列 `nums` 的長度，k 為要回傳的數字個數。

- 計數：走訪 `nums` 一次，每個數在雜湊表 `count` 中將次數加一。雜湊表的查詢與更新平均皆為固定步數，記作 O(1)，此段為 O(n)。
- 放入桶子：先建立 n + 1 個空桶子，O(n)。不同的數最多 n 個，每個數依出現次數放入 `buckets[frequency]`，O(n)。
- 收集答案：從次數 n 往下檢查到 1，最多檢查 n 個桶子；所有桶子中的數字合計最多 n 個，此段亦為 O(n)。
- 合計為數個 O(n) 相加，仍為 **O(n)**。
- 能做到 O(n) 的原因：出現次數必定介於 1 到 n，可直接以次數作為陣列下標，不需排序。

**空間 O(n)**

- 雜湊表 `count` 最多存放 n 種數字。
- `buckets` 有 n + 1 個桶子，內含的數字合計最多 n 個。
- `result` 最多 k 個，且 k 不超過 n。
- 合計為 **O(n)**。

### 可讀性版

C#、Python、C++ 的寫法與效能版相同，時間 **O(n)**、空間 **O(n)**。僅 C 版不同：

**時間：C 版 O(n log n)**

- C 版先以 `qsort` 將 `nums` 排序，使相同的數相鄰，排序約需 n log n 次比較。log n 為 n 反覆除以 2 直到剩 1 所需的次數，n = 10⁵ 時約為 17。
- 接著走訪一次，計算每種數字的次數，O(n)。
- 再將「數字與次數」依次數由大到小排序。不同的數字最多 n 種，此次排序最多亦為 O(n log n)。
- 合計為 **O(n log n)**。較效能版慢，因為使用了兩次排序，而效能版以桶子完全避開排序。

**空間：C 版 O(n)**

- 存放「數字與次數」的陣列 `frequencies` 最多 n 筆，為 **O(n)**，與效能版同一等級。
