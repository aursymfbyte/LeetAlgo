# 283. 移動零

- 難度：簡單
- 連結：https://leetcode.com/problems/move-zeroes/

## 題目

給你一個整數陣列 `nums`，請把所有的 `0` 移到陣列尾端，同時保持非零元素原本的相對順序。

必須直接在原陣列上修改（原地操作），不能另外複製一份陣列。函式不需要回傳值。

## 範例

**範例 1：**

```text
輸入：nums = [0,1,0,3,12]
輸出：[1,3,12,0,0]
解釋：非零的 1、3、12 照原本順序排在前面，兩個 0 移到最後。
```

**範例 2：**

```text
輸入：nums = [0]
輸出：[0]
解釋：只有一個 0，陣列不變。
```

## 提示

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 進階

你能盡量減少操作（寫入陣列）的總次數嗎？
