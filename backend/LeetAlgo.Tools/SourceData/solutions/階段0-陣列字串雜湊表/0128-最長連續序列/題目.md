# 128. 最長連續序列

- 難度：中等
- 連結：https://leetcode.com/problems/longest-consecutive-sequence/

## 題目

給你一個沒有排序的整數陣列 `nums`，請找出由「數值連續的整數」組成的最長序列，回傳它的長度。這些數不需要在原陣列中相鄰，只要數值能連成 `x, x+1, x+2, ...` 就算；重複的數字只算一次。

演算法的時間複雜度必須是 O(n)。

## 範例

**範例 1：**

```text
輸入：nums = [100,4,200,1,3,2]
輸出：4
解釋：1、2、3、4 可以連成最長的連續序列，長度是 4。
```

**範例 2：**

```text
輸入：nums = [0,3,7,2,5,8,4,6,0,1]
輸出：9
解釋：0 到 8 全部都有，長度是 9（重複的 0 只算一次）。
```

**範例 3：**

```text
輸入：nums = [1,0,1,2]
輸出：3
解釋：0、1、2 連成長度 3 的序列。
```

## 提示

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
