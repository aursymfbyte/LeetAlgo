# 242. 有效的字母異位詞

- 難度：簡單
- 連結：https://leetcode.com/problems/valid-anagram/

## 題目

給你兩個字串 `s` 和 `t`，判斷 `t` 是不是 `s` 的字母異位詞：也就是 `t` 能不能由 `s` 的字母重新排列而成（每個字母出現的次數都要一樣）。是就回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：s = "anagram", t = "nagaram"
輸出：true
解釋：兩個字串都是 3 個 a、1 個 g、1 個 m、1 個 n、1 個 r，只是順序不同。
```

**範例 2：**

```text
輸入：s = "rat", t = "car"
輸出：false
解釋：s 有 t，但 t 沒有；t 有 c，但 s 沒有。
```

## 提示

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` 和 `t` 只包含小寫英文字母
