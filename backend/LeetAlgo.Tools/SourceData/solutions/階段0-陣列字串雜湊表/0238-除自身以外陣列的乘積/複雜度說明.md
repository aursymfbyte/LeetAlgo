### 時間 O(n)

n 為陣列 `nums` 的長度。

- 第一趟由左至右走訪 n 次，每次將 `left_product` 寫入 `answer[i]`，再乘上 `nums[i]`，皆為固定步數。
- 第二趟由右至左同樣走訪 n 次，每次將 `right_product` 乘入 `answer[i]`，再乘上 `nums[i]`。
- 合計約 2n 步。複雜度只看資料量增加時步數的成長趨勢，常數倍不影響，因此 2n 仍記作 **O(n)**。

暴力解：對每個位置將其他 n − 1 個數相乘一次，為 O(n²)。n = 10⁵ 時約 100 億次，此寫法約 20 萬次。

### 空間 O(1)（不算答案陣列）

- 除答案陣列 `answer` 外，僅使用 `left_product`、`right_product` 與迴圈變數，數量固定，與 n 無關，為 **O(1)**。
- `answer` 為題目要求回傳的結果，任何方法都必須配置，慣例上不計入額外空間。
- 直覺寫法：另外配置「左側乘積」與「右側乘積」兩個長度 n 的陣列，空間為 O(n)。此寫法將左側乘積直接寫入 `answer`、右側乘積以單一變數邊走邊算，因而省下這些空間。
