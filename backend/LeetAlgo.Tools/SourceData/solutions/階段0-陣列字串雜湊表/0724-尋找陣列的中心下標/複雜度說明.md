### 時間 O(n)

n 為陣列 `nums` 的長度。

- 先將整個陣列加總一次得到 `total`，n 步。
- 再由左至右走訪一次，最多 n 次。每次以 `total - left_sum - num` 算出右側和並與左側比較，再將 `num` 加入 `left_sum`，皆為固定步數。
- 合計最多 2n 步，常數倍不影響成長趨勢，為 **O(n)**。

直覺寫法：對每個位置重新加總左側與右側，每個位置 O(n)，總計 O(n²)。

### 空間 O(1)

- 額外使用的只有 `total`、`left_sum`、`right_sum` 幾個變數，數量固定，與 n 無關，為 **O(1)**。
- 右側和由總和減出，不需另外配置陣列存放每個位置的左右和。
