# 724. 尋找陣列的中心下標

- 難度：簡單
- 連結：https://leetcode.com/problems/find-pivot-index/

## 題目

給你一個整數陣列 `nums`，請找出它的「中心下標」。

中心下標是指：這個下標左邊所有數的總和，等於右邊所有數的總和（都不包含這個下標本身的數）。如果下標在最左邊，左邊沒有任何數，左側總和就當作 `0`；最右邊的下標也一樣，右側總和當作 `0`。

如果有好幾個中心下標，回傳最靠左的那一個；如果不存在，回傳 `-1`。

## 範例

**範例 1：**

```text
輸入：nums = [1,7,3,6,5,6]
輸出：3
解釋：下標 3 的左邊是 1 + 7 + 3 = 11，右邊是 5 + 6 = 11，兩邊相等。
```

**範例 2：**

```text
輸入：nums = [1,2,3]
輸出：-1
解釋：沒有任何一個下標能讓左右兩邊總和相等。
```

**範例 3：**

```text
輸入：nums = [2,1,-1]
輸出：0
解釋：下標 0 的左邊沒有數，總和是 0；右邊是 1 + (-1) = 0，兩邊相等。
```

## 提示

- `1 <= nums.length <= 10^4`
- `-1000 <= nums[i] <= 1000`

註：這題和第 1991 題（Find the Middle Index in Array）相同。
