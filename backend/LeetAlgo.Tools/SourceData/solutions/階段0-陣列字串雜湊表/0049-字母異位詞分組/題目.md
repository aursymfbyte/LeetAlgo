# 49. 字母異位詞分組

- 難度：中等
- 連結：https://leetcode.com/problems/group-anagrams/

## 題目

給你一個字串陣列 `strs`，請把互為字母異位詞的字串分在同一組。字母異位詞是指用完全相同的字母（每個字母出現次數也相同）重新排列而成的字串。

回傳所有的分組，組與組之間、以及組內字串的順序都不限。

## 範例

**範例 1：**

```text
輸入：strs = ["eat","tea","tan","ate","nat","bat"]
輸出：[["bat"],["nat","tan"],["ate","eat","tea"]]
解釋：
- "ate"、"eat"、"tea" 都由 a、e、t 組成，是同一組。
- "nat"、"tan" 都由 a、n、t 組成，是同一組。
- "bat" 找不到其他由 a、b、t 組成的字串，自己一組。
```

**範例 2：**

```text
輸入：strs = [""]
輸出：[[""]]
解釋：只有一個空字串，自己一組。
```

**範例 3：**

```text
輸入：strs = ["a"]
輸出：[["a"]]
解釋：只有一個字串，自己一組。
```

## 提示

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 只包含小寫英文字母
