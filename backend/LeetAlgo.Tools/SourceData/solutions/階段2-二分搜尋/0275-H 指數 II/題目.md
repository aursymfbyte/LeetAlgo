# 275. H 指數 II

- 難度：中等
- 連結：https://leetcode.com/problems/h-index-ii/

## 題目

給你一個整數陣列 `citations`，`citations[i]` 是某位研究者第 `i` 篇論文被引用的次數，而且陣列已經由小到大排好序。請回傳這位研究者的 h 指數。

h 指數的定義：最大的整數 `h`，使得這位研究者「至少有 `h` 篇論文，每篇都被引用至少 `h` 次」。

演算法的時間複雜度必須是對數時間 O(log n)。

## 範例

**範例 1：**

```text
輸入：citations = [0,1,3,5,6]
輸出：3
解釋：共 5 篇論文，引用次數分別是 0、1、3、5、6。
引用至少 3 次的論文有 3 篇（3、5、6），但引用至少 4 次的只有 2 篇，所以 h 指數是 3。
```

**範例 2：**

```text
輸入：citations = [1,2,100]
輸出：2
解釋：引用至少 2 次的有 2 篇（2、100），引用至少 3 次的只有 1 篇，所以 h 指數是 2。
```

## 提示

- `n == citations.length`
- `1 <= n <= 10^5`
- `0 <= citations[i] <= 1000`
- `citations` 依遞增順序排列
