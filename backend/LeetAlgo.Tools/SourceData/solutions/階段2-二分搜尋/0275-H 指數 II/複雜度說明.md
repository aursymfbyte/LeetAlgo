### 時間 O(log n)

n 為論文篇數，即 `citations` 的長度。

- 二分搜尋的對象不是陣列中的某個數，而是答案 h。h 的可能值為 0 到 n，範圍從開區間 (0, n + 1) 開始，約 n 個候選值。
- 每一圈檢查候選值 `mid` 是否成立，只需判斷 `citations[n - mid] >= mid` 一個條件，為 O(1)。
- 每檢查一次，候選範圍減半；n 個候選值縮至空約需 log₂n 次。log₂n 指 2 需自乘幾次才等於 n。
- 總計 **O(log n)**。

例如 n = 10⁵ 時約需檢查 17 次。若從 h = n 往下逐一嘗試，最壞需 n 次，為 O(n)。

### 空間 O(1)

- 僅使用 `n`、`left`、`right`、`mid` 幾個整數，為 **O(1)**。
