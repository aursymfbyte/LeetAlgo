# 153. 尋找旋轉排序陣列中的最小值

- 難度：中等
- 連結：https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/

## 題目

有一個長度為 `n`、由小到大排序且元素互不相同的陣列，被「旋轉」了 1 到 `n` 次。旋轉一次的意思是把最後一個元素搬到最前面：`[a[0], a[1], ..., a[n-1]]` 會變成 `[a[n-1], a[0], a[1], ..., a[n-2]]`。

例如 `[0,1,2,4,5,6,7]` 旋轉 4 次會變成 `[4,5,6,7,0,1,2]`；旋轉 7 次則回到 `[0,1,2,4,5,6,7]`。

給你旋轉後的陣列 `nums`，請回傳其中的最小值。演算法的時間複雜度必須是 O(log n)。

## 範例

**範例 1：**

```text
輸入：nums = [3,4,5,1,2]
輸出：1
解釋：原本是 [1,2,3,4,5]，旋轉了 3 次。
```

**範例 2：**

```text
輸入：nums = [4,5,6,7,0,1,2]
輸出：0
解釋：原本是 [0,1,2,4,5,6,7]，旋轉了 4 次。
```

**範例 3：**

```text
輸入：nums = [11,13,15,17]
輸出：11
解釋：原本是 [11,13,15,17]，旋轉 4 次剛好轉回原樣。
```

## 提示

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的整數互不相同
- `nums` 原本是遞增排序，並旋轉了 1 到 `n` 次
