### 時間 O(log n)

n 為陣列 `nums` 的長度。

- 程式只有一個二分搜尋的 `while` 迴圈，範圍從開區間 (-1, n - 1) 開始，約 n 個位置。
- 每一圈將 `nums[mid]` 與最後一個數 `nums[n - 1]` 比較一次，即可判斷最小值位於 `mid` 左側或右側，範圍減半。
- n 個位置持續減半至範圍為空約需 log₂n 次。log₂n 指 2 需自乘幾次才等於 n，例如 n = 5000 時約為 13。
- 每圈僅一次比較，為 O(1)，總計 **O(log n)**。

直覺寫法：從頭到尾掃描一遍尋找最小值需 O(n)，題目要求 O(log n)。

### 空間 O(1)

- 僅使用 `n`、`left`、`right`、`mid` 幾個整數，與陣列長度無關，為 **O(1)**。
