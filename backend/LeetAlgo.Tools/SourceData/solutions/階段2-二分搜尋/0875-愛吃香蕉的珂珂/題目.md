# 875. 愛吃香蕉的珂珂

- 難度：中等
- 連結：https://leetcode.com/problems/koko-eating-bananas/

## 題目

珂珂面前有 `n` 堆香蕉，第 `i` 堆有 `piles[i]` 根。守衛離開了，會在 `h` 小時後回來。

珂珂要先決定一個吃香蕉的速度 `k`（每小時幾根）。每個小時她會挑一堆，從那堆吃掉 `k` 根；如果那堆不到 `k` 根，她就把那堆吃完，這個小時剩下的時間不會再去吃別堆。

她想吃得越慢越好，但一定要在守衛回來前把所有香蕉吃完。請回傳能在 `h` 小時內吃完所有香蕉的最小整數速度 `k`。

## 範例

**範例 1：**

```text
輸入：piles = [3,6,7,11], h = 8
輸出：4
解釋：速度 4 時，四堆分別要 1、2、2、3 小時，共 8 小時，剛好來得及；速度 3 則需要 10 小時，來不及。
```

**範例 2：**

```text
輸入：piles = [30,11,23,4,20], h = 5
輸出：30
解釋：只有 5 小時、5 堆，每小時都得吃完一整堆，所以速度至少要等於最大那堆的 30。
```

**範例 3：**

```text
輸入：piles = [30,11,23,4,20], h = 6
輸出：23
解釋：速度 23 時，30 那堆要 2 小時，其他堆各 1 小時，共 6 小時；速度 22 則要 7 小時。
```

## 提示

- `1 <= piles.length <= 10^4`
- `piles.length <= h <= 10^9`
- `1 <= piles[i] <= 10^9`
