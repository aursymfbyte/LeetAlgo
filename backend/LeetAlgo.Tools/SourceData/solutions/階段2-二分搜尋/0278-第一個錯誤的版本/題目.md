# 278. 第一個錯誤的版本

- 難度：簡單
- 連結：https://leetcode.com/problems/first-bad-version/

## 題目

你負責的產品有 `n` 個版本，編號 `1, 2, ..., n`。每個版本都是在前一版的基礎上開發的，所以只要某個版本壞掉，它之後的所有版本也都是壞的。已知最新版（第 `n` 版）是壞的，請找出「第一個」壞掉的版本。

這是互動式題目：你看不到哪一版是壞的，只能呼叫系統提供的 API `bool isBadVersion(version)`，它會告訴你第 `version` 版是不是壞的（C# 是父類別 `VersionControl` 提供的 `IsBadVersion(version)`）。

請實作 `firstBadVersion(n)` 回傳第一個壞版本的編號，並且盡量減少呼叫 API 的次數。

## 範例

**範例 1：**

```text
輸入：n = 5, bad = 4
輸出：4
解釋：bad 是評測系統內部設定的答案，你的程式看不到它。
一種可能的呼叫過程：
isBadVersion(3) -> false
isBadVersion(5) -> true
isBadVersion(4) -> true
第 3 版是好的、第 4 版是壞的，所以第一個壞版本是 4。
```

**範例 2：**

```text
輸入：n = 1, bad = 1
輸出：1
解釋：只有一個版本，而且它是壞的。
```

## 提示

- `1 <= bad <= n <= 2^31 - 1`
