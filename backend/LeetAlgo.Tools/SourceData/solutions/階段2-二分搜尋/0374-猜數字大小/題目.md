# 374. 猜數字大小

- 難度：簡單
- 連結：https://leetcode.com/problems/guess-number-higher-or-lower/

## 題目

系統從 `1` 到 `n` 之間選了一個數字 `pick`（整場遊戲都不會變），你要把它猜出來。

這是互動式題目：你看不到 `pick`，只能呼叫系統提供的 API `int guess(int num)`（C# 是父類別 `GuessGame` 提供的 `guess(num)`），它會依照你猜的數字回傳：

- `-1`：你猜得太大了（`num > pick`）
- `1`：你猜得太小了（`num < pick`）
- `0`：猜中了（`num == pick`）

請實作 `guessNumber(n)`，回傳系統選的數字。

## 範例

**範例 1：**

```text
輸入：n = 10, pick = 6
輸出：6
解釋：pick 是評測系統內部設定的答案，你要透過 guess() 找出它是 6。
```

**範例 2：**

```text
輸入：n = 1, pick = 1
輸出：1
解釋：範圍裡只有 1 這個數。
```

**範例 3：**

```text
輸入：n = 2, pick = 1
輸出：1
解釋：在 1 和 2 之間，系統選的是 1。
```

## 提示

- `1 <= n <= 2^31 - 1`
- `1 <= pick <= n`
