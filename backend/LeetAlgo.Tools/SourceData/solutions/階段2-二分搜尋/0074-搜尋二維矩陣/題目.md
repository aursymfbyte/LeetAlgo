# 74. 搜尋二維矩陣

- 難度：中等
- 連結：https://leetcode.com/problems/search-a-2d-matrix/

## 題目

給你一個 `m x n` 的整數矩陣 `matrix`，它有兩個性質：

- 每一列（橫的一排）都是非遞減排序。
- 每一列的第一個數，都比上一列的最後一個數大。

再給你一個整數 `target`，如果 `target` 在矩陣中就回傳 `true`，否則回傳 `false`。

演算法的時間複雜度必須是 O(log(m * n))。

## 範例

**範例 1：**

```text
輸入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
輸出：true
解釋：矩陣長這樣
   1   3   5   7
  10  11  16  20
  23  30  34  60
3 在第一列，所以回傳 true。
```

**範例 2：**

```text
輸入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
輸出：false
解釋：同一個矩陣裡找不到 13。
```

## 提示

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j], target <= 10^4`
