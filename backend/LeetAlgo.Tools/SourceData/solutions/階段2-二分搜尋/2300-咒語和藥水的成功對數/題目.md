# 2300. 咒語和藥水的成功對數

- 難度：中等
- 連結：https://leetcode.com/problems/successful-pairs-of-spells-and-potions/

## 題目

給你兩個正整數陣列 `spells`（長度 `n`）和 `potions`（長度 `m`），`spells[i]` 是第 `i` 個咒語的強度，`potions[j]` 是第 `j` 瓶藥水的強度。另外給你一個整數 `success`。

一個咒語和一瓶藥水的強度相乘，如果結果「大於等於」`success`，這一對就算成功。

請回傳一個長度為 `n` 的整數陣列 `pairs`，其中 `pairs[i]` 是能和第 `i` 個咒語組成成功組合的藥水數量。

## 範例

**範例 1：**

```text
輸入：spells = [5,1,3], potions = [1,2,3,4,5], success = 7
輸出：[4,0,3]
解釋：
- 咒語 5：乘上各藥水得到 [5,10,15,20,25]，有 4 個 >= 7。
- 咒語 1：得到 [1,2,3,4,5]，沒有任何一個 >= 7。
- 咒語 3：得到 [3,6,9,12,15]，有 3 個 >= 7。
```

**範例 2：**

```text
輸入：spells = [3,1,2], potions = [8,5,8], success = 16
輸出：[2,0,2]
解釋：
- 咒語 3：得到 [24,15,24]，有 2 個 >= 16。
- 咒語 1：得到 [8,5,8]，沒有任何一個 >= 16。
- 咒語 2：得到 [16,10,16]，有 2 個 >= 16。
```

## 提示

- `n == spells.length`
- `m == potions.length`
- `1 <= n, m <= 10^5`
- `1 <= spells[i], potions[i] <= 10^5`
- `1 <= success <= 10^10`
