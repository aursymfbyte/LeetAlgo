# 35. 搜尋插入位置

- 難度：簡單
- 連結：https://leetcode.com/problems/search-insert-position/

## 題目

給你一個由小到大排好序、元素互不相同的整數陣列 `nums`，以及目標值 `target`。如果 `target` 在陣列裡，回傳它的下標；如果不在，回傳「把它插進去之後陣列仍然有序」時它應該放的下標。

演算法的時間複雜度必須是 O(log n)。

## 範例

**範例 1：**

```text
輸入：nums = [1,3,5,6], target = 5
輸出：2
解釋：5 就在下標 2。
```

**範例 2：**

```text
輸入：nums = [1,3,5,6], target = 2
輸出：1
解釋：2 不在陣列裡，它應該插在 1 和 3 之間，也就是下標 1。
```

**範例 3：**

```text
輸入：nums = [1,3,5,6], target = 7
輸出：4
解釋：7 比所有數都大，要放在最後面，下標是 4。
```

## 提示

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 的元素互不相同，且依遞增順序排列
- `-10^4 <= target <= 10^4`
