# 34. 在排序陣列中查找元素的第一個和最後一個位置

- 難度：中等
- 連結：https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/

## 題目

給你一個非遞減排序（可能有重複數字）的整數陣列 `nums`，以及目標值 `target`。請找出 `target` 在陣列中第一次出現和最後一次出現的下標，回傳 `[開始下標, 結束下標]`。

如果 `target` 不在陣列裡，回傳 `[-1, -1]`。

演算法的時間複雜度必須是 O(log n)。

## 範例

**範例 1：**

```text
輸入：nums = [5,7,7,8,8,10], target = 8
輸出：[3,4]
解釋：8 出現在下標 3 和 4。
```

**範例 2：**

```text
輸入：nums = [5,7,7,8,8,10], target = 6
輸出：[-1,-1]
解釋：陣列裡沒有 6。
```

**範例 3：**

```text
輸入：nums = [], target = 0
輸出：[-1,-1]
解釋：空陣列裡什麼都找不到。
```

## 提示

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是非遞減陣列
- `-10^9 <= target <= 10^9`
