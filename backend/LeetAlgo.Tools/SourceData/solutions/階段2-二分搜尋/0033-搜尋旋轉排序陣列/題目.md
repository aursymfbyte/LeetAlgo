# 33. 搜尋旋轉排序陣列

- 難度：中等
- 連結：https://leetcode.com/problems/search-in-rotated-sorted-array/

## 題目

有一個由小到大排序、元素互不相同的整數陣列。在交給你之前，它「可能」在某個未知的位置 `k`（`1 <= k < nums.length`）被向左旋轉過，變成 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`。例如 `[0,1,2,4,5,6,7]` 在 `k = 3` 旋轉後是 `[4,5,6,7,0,1,2]`。

給你旋轉後的陣列 `nums` 和整數 `target`，如果 `target` 在陣列中就回傳它的下標，否則回傳 `-1`。

演算法的時間複雜度必須是 O(log n)。

## 範例

**範例 1：**

```text
輸入：nums = [4,5,6,7,0,1,2], target = 0
輸出：4
解釋：0 在下標 4。
```

**範例 2：**

```text
輸入：nums = [4,5,6,7,0,1,2], target = 3
輸出：-1
解釋：陣列裡沒有 3。
```

**範例 3：**

```text
輸入：nums = [1], target = 0
輸出：-1
解釋：唯一的元素是 1，不是 0。
```

## 提示

- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 中的值互不相同
- `nums` 是遞增陣列，可能經過旋轉
- `-10^4 <= target <= 10^4`
