### 時間 O(log n)

n 為陣列 `nums` 的長度。

- 程式只有一個二分搜尋的 `while` 迴圈，範圍從開區間 (-1, n - 1) 開始，約 n 個位置。
- 每一圈僅比較 `nums[mid]` 與右側的 `nums[mid + 1]`，依此判斷目前為上坡或下坡，即可捨棄一半範圍。
- n 個位置持續減半至範圍為空約需 log₂n 次。log₂n 指 2 需自乘幾次才等於 n，例如 log₂1024 = 10。
- 每圈僅一次比較，為 O(1)，總計 **O(log n)**。

直覺寫法：由左至右尋找第一個大於右側的數，最壞需走完整個陣列，為 O(n)。

### 空間 O(1)

- 僅使用 `left`、`right`、`mid` 三個整數，為 **O(1)**。
