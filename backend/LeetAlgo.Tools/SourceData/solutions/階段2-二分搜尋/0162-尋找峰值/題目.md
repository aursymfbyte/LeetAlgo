# 162. 尋找峰值

- 難度：中等
- 連結：https://leetcode.com/problems/find-peak-element/

## 題目

「峰值」是指比左右兩個鄰居都嚴格大的元素。給你一個下標從 0 開始的整數陣列 `nums`，請找出任意一個峰值並回傳它的下標；如果有好幾個峰值，回傳其中哪一個都可以。

可以把陣列兩端外面想成負無限大，也就是 `nums[-1] = nums[n] = -∞`，所以陣列頭尾的元素只要比它唯一的鄰居大，就算峰值。

演算法的時間複雜度必須是 O(log n)。

## 範例

**範例 1：**

```text
輸入：nums = [1,2,3,1]
輸出：2
解釋：nums[2] = 3 比左邊的 2 和右邊的 1 都大，是峰值。
```

**範例 2：**

```text
輸入：nums = [1,2,1,3,5,6,4]
輸出：5
解釋：下標 1 的 2 和下標 5 的 6 都是峰值，回傳 1 或 5 都算對。
```

## 提示

- `1 <= nums.length <= 1000`
- `-2^31 <= nums[i] <= 2^31 - 1`
- 對所有合法的 `i`，`nums[i] != nums[i + 1]`
