# 704. 二分搜尋

- 難度：簡單
- 連結：https://leetcode.com/problems/binary-search/

## 題目

給你一個由小到大排好序、而且沒有重複數字的整數陣列 `nums`，以及一個整數 `target`。請在 `nums` 裡找 `target`：找得到就回傳它的下標，找不到就回傳 `-1`。

演算法的時間複雜度必須是 O(log n)。

## 範例

**範例 1：**

```text
輸入：nums = [-1,0,3,5,9,12], target = 9
輸出：4
解釋：9 在陣列中，位置是下標 4。
```

**範例 2：**

```text
輸入：nums = [-1,0,3,5,9,12], target = 2
輸出：-1
解釋：陣列裡沒有 2，所以回傳 -1。
```

## 提示

- `1 <= nums.length <= 10^4`
- `-10^4 < nums[i], target < 10^4`
- `nums` 中的整數都不相同
- `nums` 依遞增順序排列
