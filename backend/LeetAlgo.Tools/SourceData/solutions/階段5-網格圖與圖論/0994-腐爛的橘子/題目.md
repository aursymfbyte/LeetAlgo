# 994. 腐爛的橘子

- 難度：中等
- 連結：https://leetcode.com/problems/rotting-oranges/

## 題目

給你一個 `m x n` 的網格 `grid`，每格的值代表：

- `0`：空格
- `1`：新鮮橘子
- `2`：已經爛掉的橘子

每過一分鐘，所有和爛橘子上下左右相鄰的新鮮橘子都會跟著爛掉。

請回傳讓網格裡不再有任何新鮮橘子所需的最少分鐘數。如果有新鮮橘子永遠不會爛掉，回傳 `-1`。

## 範例

**範例 1：**

```text
輸入：grid = [[2,1,1],[1,1,0],[0,1,1]]
輸出：4
解釋：
  第 0 分鐘   第 1 分鐘   第 2 分鐘   第 3 分鐘   第 4 分鐘
  2 1 1      2 2 1      2 2 2      2 2 2      2 2 2
  1 1 0      2 1 0      2 2 0      2 2 0      2 2 0
  0 1 1      0 1 1      0 1 1      0 2 1      0 2 2
爛掉的範圍每分鐘往外擴一圈，到第 4 分鐘右下角那顆也爛了。
```

**範例 2：**

```text
輸入：grid = [[2,1,1],[0,1,1],[1,0,1]]
輸出：-1
解釋：左下角 (2, 0) 的新鮮橘子上方和右方都是空格，沒有任何爛橘子能從上下左右碰到它，所以它永遠不會爛。
```

**範例 3：**

```text
輸入：grid = [[0,2]]
輸出：0
解釋：一開始就沒有新鮮橘子，不需要等待，答案是 0。
```

## 提示

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10`
- `grid[i][j]` 為 `0`、`1` 或 `2`
