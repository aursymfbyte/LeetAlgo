# 210. 課程表 II

- 難度：中等
- 連結：https://leetcode.com/problems/course-schedule-ii/

## 題目

你總共要修 `numCourses` 門課，編號 `0` 到 `numCourses - 1`。給你陣列 `prerequisites`，其中 `prerequisites[i] = [ai, bi]` 表示想修課程 `ai`，必須先修完課程 `bi`。

例如 `[0, 1]` 代表要先修課程 `1` 才能修課程 `0`。

請回傳一種能把所有課程修完的修課順序。合法的順序可能不只一種，回傳任何一種都可以。如果不可能修完所有課程，回傳空陣列。

## 範例

**範例 1：**

```text
輸入：numCourses = 2, prerequisites = [[1,0]]
輸出：[0,1]
解釋：共 2 門課，課程 1 要先修課程 0，所以順序是先 0 後 1。
```

**範例 2：**

```text
輸入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
輸出：[0,2,1,3]
解釋：
        0
       / \
      1   2
       \ /
        3
課程 1 和 2 都要先修 0，課程 3 要等 1 和 2 都修完。
所以 0 一定最先、3 一定最後，中間 1 和 2 的先後不限：[0,1,2,3] 和 [0,2,1,3] 都是正確答案。
```

**範例 3：**

```text
輸入：numCourses = 1, prerequisites = []
輸出：[0]
解釋：只有一門課，也沒有先修條件，直接修它就好。
```

## 提示

- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= numCourses * (numCourses - 1)`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `ai != bi`
- 所有 `[ai, bi]` 配對都不重複
