# 1466. 重新規劃路線

- 難度：中等
- 連結：https://leetcode.com/problems/reorder-routes-to-make-all-paths-lead-to-the-city-zero/

## 題目

有 `n` 座城市，編號 `0` 到 `n - 1`，之間有 `n - 1` 條道路，任兩座城市之間恰好只有一條路線可走（也就是這些道路構成一棵樹）。因為道路太窄，去年交通部把每條路都改成單行道。

道路用 `connections` 表示，`connections[i] = [ai, bi]` 代表一條從城市 `ai` 開往城市 `bi` 的單行道。

今年首都（城市 `0`）要舉辦大型活動，大家都想前往城市 `0`。請把部分道路的方向反轉，讓每座城市都能開到城市 `0`，回傳最少需要反轉幾條路。

題目保證反轉之後一定能讓所有城市到達城市 `0`。

## 範例

**範例 1：**

```text
輸入：n = 6, connections = [[0,1],[1,3],[2,3],[4,0],[4,5]]
輸出：3
解釋：
  原本的單行道：0 → 1，1 → 3，2 → 3，4 → 0，4 → 5
  0 → 1、1 → 3、4 → 5 這三條都是朝遠離 0 的方向開，必須反轉成 1 → 0、3 → 1、5 → 4。
  2 → 3 和 4 → 0 本來就朝著 0 的方向，不用改；反轉完 2 可以走 2 → 3 → 1 → 0 到達。共反轉 3 條。
```

**範例 2：**

```text
輸入：n = 5, connections = [[1,0],[1,2],[3,2],[3,4]]
輸出：2
解釋：
  原本的單行道：1 → 0，1 → 2，3 → 2，3 → 4
  需要反轉 1 → 2 變成 2 → 1，反轉 3 → 4 變成 4 → 3，共 2 條。
  之後 4 → 3 → 2 → 1 → 0 全部通往城市 0。
```

**範例 3：**

```text
輸入：n = 3, connections = [[1,0],[2,0]]
輸出：0
解釋：兩條路本來就都開往城市 0，不需要反轉。
```

## 提示

- `2 <= n <= 5 * 10^4`
- `connections.length == n - 1`
- `connections[i].length == 2`
- `0 <= ai, bi <= n - 1`
- `ai != bi`
