# 127. 單字接龍

- 難度：困難
- 連結：https://leetcode.com/problems/word-ladder/

## 題目

給你起始單字 `beginWord`、目標單字 `endWord` 和字典 `wordList`。一條「轉換序列」是一串單字 `beginWord -> s1 -> s2 -> ... -> sk`，必須滿足：

- 序列中每兩個相鄰的單字，只能剛好差一個字母。
- 對於 `1 <= i <= k`，每個 `si` 都要在 `wordList` 裡（`beginWord` 本身不必在字典中）。
- 最後一個單字 `sk` 必須等於 `endWord`。

請回傳從 `beginWord` 到 `endWord` 的最短轉換序列共包含幾個單字（包含頭尾）；如果不存在這樣的序列，回傳 `0`。

## 範例

**範例 1：**

```text
輸入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
輸出：5
解釋：其中一條最短的序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog"，
每一步只改一個字母，總共 5 個單字。
```

**範例 2：**

```text
輸入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
輸出：0
解釋：目標單字 "cog" 不在字典裡，序列的最後一個字一定要在字典中，所以不可能轉換成功。
```

## 提示

- `1 <= beginWord.length <= 10`
- `endWord.length == beginWord.length`
- `1 <= wordList.length <= 5000`
- `wordList[i].length == beginWord.length`
- `beginWord`、`endWord` 和 `wordList[i]` 都只包含小寫英文字母
- `beginWord != endWord`
- `wordList` 中的單字都不重複
