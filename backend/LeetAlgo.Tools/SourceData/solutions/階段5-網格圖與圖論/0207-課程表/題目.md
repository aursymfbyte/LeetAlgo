# 207. 課程表

- 難度：中等
- 連結：https://leetcode.com/problems/course-schedule/

## 題目

你總共要修 `numCourses` 門課，編號 `0` 到 `numCourses - 1`。給你陣列 `prerequisites`，其中 `prerequisites[i] = [ai, bi]` 表示想修課程 `ai`，必須先修完課程 `bi`。

例如 `[0, 1]` 代表要先修課程 `1` 才能修課程 `0`。

如果有辦法把所有課程都修完，回傳 `true`；否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：numCourses = 2, prerequisites = [[1,0]]
輸出：true
解釋：共 2 門課。修課程 1 之前要先修課程 0，所以先修 0 再修 1 就能全部修完。
```

**範例 2：**

```text
輸入：numCourses = 2, prerequisites = [[1,0],[0,1]]
輸出：false
解釋：共 2 門課。修課程 1 要先修完課程 0，修課程 0 又要先修完課程 1，
兩門課互相卡住，哪一門都沒辦法先開始，所以不可能修完。
```

## 提示

- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `prerequisites[i]` 中所有的配對都不重複
