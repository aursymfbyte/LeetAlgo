### 時間 O(n + m)

n 為課程數 `numCourses`，m 為先修條件 `prerequisites` 的筆數，即圖的邊數。

- 建圖：m 筆先修條件各處理一次，加入 `next_courses` 並更新 `in_degree`，共 m 次。建立 n 個空清單與入度陣列需 n 次。
- 找出入度為 0 的課程放入佇列：掃描 n 門課。
- 拓撲排序主迴圈：每門課最多進出佇列一次（入度只會減到 0 一次），共 n 次；每門課出佇列時走訪其後續課程清單，所有清單總長恰為 m 條邊，因此每條邊只處理一次。
- 總和為 n + m 的常數倍，為 **O(n + m)**。

### 空間 O(n + m)

- `next_courses`：n 個清單，共存放 m 個課程編號，為 O(n + m)。
- `in_degree` 與佇列 `queue` 最多各 n 個元素，為 O(n)。
- 合計 **O(n + m)**。
