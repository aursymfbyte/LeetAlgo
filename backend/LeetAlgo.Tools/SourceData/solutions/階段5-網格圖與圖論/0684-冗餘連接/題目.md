# 684. 冗餘連接

- 難度：中等
- 連結：https://leetcode.com/problems/redundant-connection/

## 題目

這題裡的「樹」指的是連通而且沒有環的無向圖。

有一張圖原本是一棵有 `n` 個節點（編號 `1` 到 `n`）的樹，後來又多加了一條邊。這條新邊的兩個端點是 `1` 到 `n` 中兩個不同的節點，而且原本兩點之間並沒有邊。

圖用長度為 `n` 的陣列 `edges` 表示，`edges[i] = [ai, bi]` 代表節點 `ai` 和 `bi` 之間有一條邊。

請找出一條邊，把它刪掉之後剩下的圖會變回一棵有 `n` 個節點的樹。如果有好幾條邊都可以刪，回傳在 `edges` 中最後出現的那一條。

## 範例

**範例 1：**

```text
輸入：edges = [[1,2],[1,3],[2,3]]
輸出：[2,3]
解釋：
    1
   / \
  2 ─ 3
三條邊形成一個環，刪掉任一條都能變回樹，其中最後出現的是 [2,3]。
```

**範例 2：**

```text
輸入：edges = [[1,2],[2,3],[3,4],[1,4],[1,5]]
輸出：[1,4]
解釋：
  5 ─ 1 ─ 2
      |   |
      4 ─ 3
環是 1-2-3-4-1，刪掉環上的 [1,2]、[2,3]、[3,4]、[1,4] 任一條都可以，
其中在輸入中最後出現的是 [1,4]。邊 [1,5] 不在環上，刪掉會讓節點 5 斷開。
```

## 提示

- `n == edges.length`
- `3 <= n <= 1000`
- `edges[i].length == 2`
- `1 <= ai < bi <= edges.length`
- `ai != bi`
- 沒有重複的邊
- 給定的圖是連通的
