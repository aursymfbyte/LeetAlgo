# 1926. 迷宮中離入口最近的出口

- 難度：中等
- 連結：https://leetcode.com/problems/nearest-exit-from-entrance-in-maze/

## 題目

給你一個 `m x n` 的迷宮矩陣 `maze`（下標從 0 開始），`'.'` 是可以走的空格、`'+'` 是牆。另外給你入口座標 `entrance = [entrancerow, entrancecol]`，也就是你一開始站的位置。

每一步可以往上、下、左、右移動一格，不能走進牆，也不能走出迷宮範圍。「出口」指的是位在迷宮邊界上的空格；但入口本身就算在邊界上，也不算出口。

請回傳從入口走到最近出口的最少步數；如果沒有任何出口走得到，回傳 `-1`。

## 範例

**範例 1：**

```text
輸入：maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]
輸出：1
解釋：
  + + . +
  . . E +      （E 是入口 (1,2)）
  + + + .
邊界上的空格有 (1,0)、(0,2)、(2,3) 三個出口。
往左走 2 步可到 (1,0)；往上走 1 步可到 (0,2)；(2,3) 被牆擋住到不了。
最近的是 (0,2)，只要 1 步。
```

**範例 2：**

```text
輸入：maze = [["+","+","+"],[".",".","."],["+","+","+"]], entrance = [1,0]
輸出：2
解釋：
  + + +
  E . .        （E 是入口 (1,0)）
  + + +
入口雖然在邊界上，但不算出口，唯一的出口是 (1,2)，往右走 2 步到達。
```

**範例 3：**

```text
輸入：maze = [[".","+"]], entrance = [0,0]
輸出：-1
解釋：除了入口之外沒有其他空格，找不到出口。
```

## 提示

- `maze.length == m`
- `maze[i].length == n`
- `1 <= m, n <= 100`
- `maze[i][j]` 為 `'.'` 或 `'+'`
- `entrance.length == 2`
- `0 <= entrancerow < m`
- `0 <= entrancecol < n`
- `entrance` 一定是空格
