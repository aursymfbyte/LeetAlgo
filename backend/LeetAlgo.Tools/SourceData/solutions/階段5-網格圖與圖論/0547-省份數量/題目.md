# 547. 省份數量

- 難度：中等
- 連結：https://leetcode.com/problems/number-of-provinces/

## 題目

有 `n` 座城市，有些城市之間有直接相連，有些沒有。連線具有傳遞性：如果城市 a 和 b 直接相連、b 和 c 直接相連，那麼 a 和 c 就算間接相連。

「省份」是一群彼此直接或間接相連的城市，而且群組外沒有任何城市和它們相連。

給你一個 `n x n` 的矩陣 `isConnected`：若第 `i` 座和第 `j` 座城市直接相連，`isConnected[i][j] = 1`，否則為 `0`。請回傳省份的總數。

## 範例

**範例 1：**

```text
輸入：isConnected = [[1,1,0],[1,1,0],[0,0,1]]
輸出：2
解釋：
  城市 0 ── 城市 1        城市 2
城市 0 和 1 相連成一個省份，城市 2 自己是一個省份，共 2 個。
```

**範例 2：**

```text
輸入：isConnected = [[1,0,0],[0,1,0],[0,0,1]]
輸出：3
解釋：
  城市 0        城市 1        城市 2
三座城市彼此都不相連，各自成為一個省份，共 3 個。
```

## 提示

- `1 <= n <= 200`
- `n == isConnected.length`
- `n == isConnected[i].length`
- `isConnected[i][j]` 為 `1` 或 `0`
- `isConnected[i][i] == 1`
- `isConnected[i][j] == isConnected[j][i]`
