### 時間 O(n²)

n 為城市數，`isConnected` 為 n × n 的鄰接矩陣（第 i 列第 j 行為 1 代表城市 i 與 j 相連）。

- `visited` 設為 `True` 後不會再改回，且只有未走訪的城市才會被 `visit`，因此每座城市只被 `visit` 一次，共 n 次。
- 每次 `visit` 一座城市，需檢查矩陣中該列的 n 格，才能得知與哪些城市相連。
- DFS 合計為 n 座城市 × 每座 n 格 = n²。外層走訪每座城市的迴圈僅 n 次，小於 n²。
- 結論為 **O(n²)**。以鄰接矩陣存圖時，讀完整個矩陣即需 n²，已為下限。

### 空間 O(n)

- 額外配置的只有長度 n 的 `visited` 陣列。
- DFS 以遞迴實作，呼叫堆疊（尚未返回的函式呼叫所保存的記錄）最深為 n 層，例如所有城市連成一條鏈 1–2–3–…–n。
- 輸入矩陣由題目提供，不計入額外空間。
- 合計 **O(n)**。
