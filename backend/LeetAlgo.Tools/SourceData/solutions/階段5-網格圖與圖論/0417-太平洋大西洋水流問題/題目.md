# 417. 太平洋大西洋水流問題

- 難度：中等
- 連結：https://leetcode.com/problems/pacific-atlantic-water-flow/

## 題目

有一座 `m x n` 的長方形島嶼，被切成一格一格。給你整數矩陣 `heights`，`heights[r][c]` 是座標 `(r, c)` 那格的海拔高度。

島的上邊和左邊緊鄰太平洋，下邊和右邊緊鄰大西洋。下雨時，雨水可以從一格流到上下左右的相鄰格，條件是相鄰格的高度小於或等於目前這格。位在島嶼邊緣、緊鄰某個海洋的格子，水可以直接流進那個海洋。

請找出所有「雨水既能流到太平洋、也能流到大西洋」的格子，以 `[r, c]` 的形式放進串列回傳（順序不限）。

## 範例

**範例 1：**

```text
輸入：heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]
輸出：[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
解釋：
            太平洋（上、左）
         1  2  2  3  5
         3  2  3  4  4
         2  4  5  3  1
         6  7  1  4  5
         5  1  1  2  4
            大西洋（下、右）
以 (2,2) 高度 5 為例：往上走 (1,2) 高度 3、(0,2) 高度 2，一路不升高，到達上邊流進太平洋；
往右走 (2,3) 高度 3、(2,4) 高度 1，一樣不升高，到達右邊流進大西洋。
(0,4) 在右上角，同時碰到上邊和右邊，兩個海洋都能直接流入。
(3,0)、(4,0)、(3,1) 等格子也都能找到分別通往兩個海洋的路徑，其餘格子至少有一個海洋到不了。
```

**範例 2：**

```text
輸入：heights = [[1]]
輸出：[[0,0]]
解釋：只有一格，它同時緊鄰四個方向的邊，兩個海洋都能流到。
```

## 提示

- `m == heights.length`
- `n == heights[r].length`
- `1 <= m, n <= 200`
- `0 <= heights[r][c] <= 10^5`
