# 130. 被圍繞的區域

- 難度：中等
- 連結：https://leetcode.com/problems/surrounded-regions/

## 題目

給你一個 `m x n` 的字元矩陣 `board`，每格是 `'X'` 或 `'O'`。

- 上下左右相鄰的 `'O'` 會連成同一個「區域」。
- 如果一個區域裡沒有任何一格位在棋盤的邊緣（第一列、最後一列、第一欄、最後一欄），這個區域就算被 `'X'` 完全包圍。

請把所有被包圍的區域「佔領」：也就是把這些區域裡的 `'O'` 全部改成 `'X'`。只要有任何一格碰到邊緣的區域則保持不變。

要直接在原本的 `board` 上修改，函式不需要回傳任何東西。

## 範例

**範例 1：**

```text
輸入：board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
輸出：[["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
解釋：
  X X X X        X X X X
  X O O X   →    X X X X
  X X O X        X X X X
  X O X X        X O X X
中間那塊 'O'（三格）四周都是 'X'，沒有碰到邊緣，所以被改成 'X'。
左下角的 'O' 在最後一列，位在邊緣上，不算被包圍，維持 'O'。
```

**範例 2：**

```text
輸入：board = [["X"]]
輸出：[["X"]]
解釋：棋盤裡沒有 'O'，什麼都不用改。
```

## 提示

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 為 `'X'` 或 `'O'`
