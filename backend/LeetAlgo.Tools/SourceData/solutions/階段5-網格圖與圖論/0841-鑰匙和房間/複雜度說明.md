### 時間 O(n + k)

n 為房間數，k 為所有房間中的鑰匙總數（各 `rooms[i]` 長度的總和）。

- 只有尚未進入的房間才會被 `visit`，進入時立即標記，因此每個房間最多被 `visit` 一次，共 n 次。
- 每次 `visit` 一個房間，走訪該房間的所有鑰匙。由於每個房間只進入一次，所有鑰匙合計最多被檢查 k 次。
- 另外建立 `visited` 陣列、最後檢查是否每間都已進入，各需 n 步。
- 合計 **O(n + k)**。寫成 n + k 而非 n，是因為一個房間可能有多把鑰匙，鑰匙總數可能大於房間數。

### 空間 O(n)

- `visited` 陣列長度 n。
- DFS 以遞迴實作，呼叫堆疊（尚未返回的函式呼叫所保存的記錄）最深為 n 層，例如房間 0 只有房間 1 的鑰匙、房間 1 只有房間 2 的鑰匙，依此串接。
- 合計 **O(n)**。
