# 841. 鑰匙和房間

- 難度：中等
- 連結：https://leetcode.com/problems/keys-and-rooms/

## 題目

有 `n` 個房間，編號 `0` 到 `n - 1`。一開始只有房間 `0` 沒上鎖，其他房間都鎖著，沒有對應的鑰匙就進不去。你的目標是走遍所有房間。

每進入一個房間，你可能會在裡面找到幾把鑰匙，每把鑰匙上寫著它能打開的房間編號，你可以把鑰匙都帶走拿去開其他房間。

給你陣列 `rooms`，`rooms[i]` 是進入房間 `i` 時能拿到的鑰匙編號集合。如果能進入所有房間就回傳 `true`，否則回傳 `false`。

## 範例

**範例 1：**

```text
輸入：rooms = [[1],[2],[3],[]]
輸出：true
解釋：
房間 0 拿到鑰匙 1 → 進房間 1 拿到鑰匙 2 → 進房間 2 拿到鑰匙 3 → 進房間 3。
四個房間都進去過了，所以回傳 true。
```

**範例 2：**

```text
輸入：rooms = [[1,3],[3,0,1],[2],[0]]
輸出：false
解釋：房間 2 的鑰匙只放在房間 2 裡面，從外面永遠拿不到，所以進不了房間 2。
```

## 提示

- `n == rooms.length`
- `2 <= n <= 1000`
- `0 <= rooms[i].length <= 1000`
- `1 <= sum(rooms[i].length) <= 3000`
- `0 <= rooms[i][j] < n`
- `rooms[i]` 裡的數字都不重複
