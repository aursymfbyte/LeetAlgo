### 時間 O(n² + m)

n 為節點數，m 為邊的數量（`times` 的長度）。

- 建圖：先建立 n × n 的鄰接矩陣並全部填入無限大，需 n² 步；再將 m 條邊逐一填入，需 m 步。
- Dijkstra 主迴圈最多執行 n 輪，每輪做兩件事：
  - 檢查 n 個節點，選出尚未確定且距離最小的 `closest`，需 n 步。
  - 以 `closest` 更新所有節點的距離，即矩陣的一整列，同為 n 步。
  - 每輪 2n 步，n 輪共 2n²。
- 最後找出最大距離需 n 步。
- 總和：n² + m + 2n² + n，保留最大項為 **O(n² + m)**。m 單獨列出，是因為讀入邊的步驟與 m 有關。

本題 n 最多 100，n² 僅 1 萬，因此不使用堆積（heap）優化版，以「每輪掃描一次找最小值」即足夠快。

### 空間 O(n²)

- 鄰接矩陣 `graph` 為 n × n，佔 n² 格，為最大的部分。
- `distance` 與 `done` 各 n 格。
- 合計 **O(n²)**。
