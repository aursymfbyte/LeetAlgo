# 743. 網路延遲時間

- 難度：中等
- 連結：https://leetcode.com/problems/network-delay-time/

## 題目

有一個網路包含 `n` 個節點，編號 `1` 到 `n`。給你陣列 `times`，每個元素 `times[i] = (ui, vi, wi)` 是一條有向邊：訊號從來源節點 `ui` 傳到目標節點 `vi` 需要花 `wi` 單位時間。

現在從節點 `k` 發出一個訊號。請回傳讓全部 `n` 個節點都收到訊號所需的最少時間；如果有任何節點永遠收不到，回傳 `-1`。

## 範例

**範例 1：**

```text
輸入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
輸出：2
解釋：
  1 ←(1)─ 2 ─(1)→ 3 ─(1)→ 4
從節點 2 出發，時間 1 時節點 1 和 3 收到；時間 2 時節點 4 經由 3 收到。
最晚收到的是節點 4，所以答案是 2。
```

**範例 2：**

```text
輸入：times = [[1,2,1]], n = 2, k = 1
輸出：1
解釋：從節點 1 出發，經過 1 單位時間節點 2 收到，全部收到。
```

**範例 3：**

```text
輸入：times = [[1,2,1]], n = 2, k = 2
輸出：-1
解釋：邊只有 1 → 2 這個方向，從節點 2 出發的訊號傳不到節點 1。
```

## 提示

- `1 <= k <= n <= 100`
- `1 <= times.length <= 6000`
- `times[i].length == 3`
- `1 <= ui, vi <= n`
- `ui != vi`
- `0 <= wi <= 100`
- 所有 `(ui, vi)` 配對都不重複（沒有重邊）
