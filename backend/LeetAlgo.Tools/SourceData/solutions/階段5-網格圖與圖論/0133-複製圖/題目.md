# 133. 複製圖

- 難度：中等
- 連結：https://leetcode.com/problems/clone-graph/

## 題目

給你一張連通無向圖中某個節點的參考，請回傳這張圖的深拷貝（完整複製一份全新的圖）。

圖中每個節點包含一個整數值 `val` 和一個鄰居串列 `neighbors`：

```text
class Node {
    public int val;
    public List<Node> neighbors;
}
```

深拷貝的意思是：新圖裡的每個節點都必須是新建立的物件，值和鄰居關係要和原圖完全一樣，但不能直接引用原圖的任何節點。

測資格式說明：為了方便，每個節點的值就等於它的編號（從 1 開始），第 1 個節點 `val = 1`、第 2 個節點 `val = 2`，依此類推。測資用鄰接串列 `adjList` 描述整張圖，`adjList[i]` 列出第 `i + 1` 個節點的所有鄰居編號。傳給你的節點一定是 `val = 1` 的那個，你要回傳它的複本。

## 範例

**範例 1：**

```text
輸入：adjList = [[2,4],[1,3],[2,4],[1,3]]
輸出：[[2,4],[1,3],[2,4],[1,3]]
解釋：圖有 4 個節點，連成一個正方形的環：
  1 ── 2
  |    |
  4 ── 3
節點 1 的鄰居是 2 和 4；節點 2 的鄰居是 1 和 3；
節點 3 的鄰居是 2 和 4；節點 4 的鄰居是 1 和 3。
複製出來的圖結構完全相同。
```

**範例 2：**

```text
輸入：adjList = [[]]
輸出：[[]]
解釋：只有一個節點 val = 1，沒有任何鄰居。
```

**範例 3：**

```text
輸入：adjList = []
輸出：[]
解釋：空圖，沒有任何節點，傳進來的節點是空值，回傳空值即可。
```

## 提示

- 圖中節點數在 `[0, 100]` 範圍內
- `1 <= Node.val <= 100`
- 每個節點的 `Node.val` 都不重複
- 圖中沒有重複的邊，也沒有自環
- 圖是連通的，從給定節點出發可以走到所有節點
