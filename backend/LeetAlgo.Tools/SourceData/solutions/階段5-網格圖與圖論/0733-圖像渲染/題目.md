# 733. 圖像渲染

- 難度：簡單
- 連結：https://leetcode.com/problems/flood-fill/

## 題目

給你一張用 `m x n` 整數矩陣 `image` 表示的圖片，`image[i][j]` 是該像素的顏色值。另外給你三個整數 `sr`、`sc`、`color`，要從像素 `image[sr][sc]` 開始做「油漆桶填色」。

填色規則如下：

- 先把起點像素改成 `color`。
- 接著看起點上下左右四個相鄰像素，只要它的顏色和「起點原本的顏色」一樣，就也改成 `color`。
- 對每個剛被改色的像素重複同樣的動作，一路往外擴散。
- 當再也找不到和起點原本顏色相同、又跟已改色區域相鄰的像素時就停止。

回傳填色後的圖片。

## 範例

**範例 1：**

```text
輸入：image = [[1,1,1],[1,1,0],[1,0,1]], sr = 1, sc = 1, color = 2
輸出：[[2,2,2],[2,2,0],[2,0,1]]
解釋：
起點是正中間 (1, 1)，原本顏色是 1。
  1 1 1        2 2 2
  1 1 0   →    2 2 0
  1 0 1        2 0 1
所有能沿著上下左右、只踩顏色 1 的格子走到的位置都變成 2。
右下角的 1 只跟起點區域斜著相鄰，走不到，所以維持 1。
```

**範例 2：**

```text
輸入：image = [[0,0,0],[0,0,0]], sr = 0, sc = 0, color = 0
輸出：[[0,0,0],[0,0,0]]
解釋：起點本來就是顏色 0，和要塗的顏色相同，所以圖片完全不變。
```

## 提示

- `m == image.length`
- `n == image[i].length`
- `1 <= m, n <= 50`
- `0 <= image[i][j], color < 2^16`
- `0 <= sr < m`
- `0 <= sc < n`
